原版版本

除了 Forge 整合包之外，启动器还可以直接安装和游玩原版（未经修改的） Minecraft 版本。

浏览版本

原版版本界面会列出可用的 Minecraft 正式版和快照。 每个条目都会显示版本号和发布日期。选择一个版本即可查看其详细信息。

安装与启动

  1. 从列表中选择一个 Minecraft 版本。
  2. 点击安装，下载该版本的游戏客户端、库文件和资源文件。
  3. 安装完成后，点击开始游戏即可启动。启动器会自动完成所有文件验证 和运行时设置。
注意

原版版本使用与设置中 相同的内存和 JVM 设置。如果某个版本运行不佳，请尝试调整 内存分配或 JVM 预设。

运行时管理

不同的 Minecraft 版本可能需要不同的 Java 运行时。启动器会自动 为每个版本下载并管理正确的运行时——例如，Minecraft 1.17+ 需要 Java 17 或更高版本，而较旧的版本使用 Java 8。

您无需手动安装 Java。有关运行时处理方式的更多详情，请参阅 运行时管理。

提示

在安装大型整合包之前，原版版本是测试您的系统是否满足基本要求的 好方法。
