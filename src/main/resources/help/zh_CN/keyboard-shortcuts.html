键盘快捷键

启动器为您最常用的操作提供了一小组键盘快捷键。 在 macOS 上，修饰键为 ⌘ Command；在 Windows 和 Linux 上为 Ctrl。 下表将修饰键写作 ⌘/Ctrl，以同时涵盖两者。

全局导航

除登录、启动进度和游戏内控制台窗口外，所有界面均可使用—— 这些界面特意不响应导航快捷键，以免您在操作中途 意外离开。

快捷键操作
⌘/Ctrl + ,打开设置（通用惯例）
⌘/Ctrl + L打开“浏览”界面（安装与管理）
⌘/Ctrl + E打开整合包编辑器
⌘/Ctrl + Shift + M返回主菜单（主页）
F1 / ⌘/Ctrl + ?打开帮助窗口，并显示当前界面对应的主题
为什么“主页”使用 Cmd+Shift+M？

单独的 ⌘ + M 是 macOS 的“最小化窗口”系统快捷键—— 启动器不会覆盖它。⌘/Ctrl + Shift + M 可在所有平台上 避开这一冲突。

系统菜单栏（macOS）

macOS 系统菜单栏还额外提供：

快捷键操作
⌘ + R刷新整合包列表（“浏览”菜单 → 刷新整合包列表）

主菜单

快捷键操作
Enter启动上次选择的整合包
F5刷新可用的整合包（与导航栏中的刷新图标相同）
⌘/Ctrl + F跳转到搜索框

浏览

快捷键操作
⌘/Ctrl + F跳转到搜索框

整合包编辑器

快捷键操作
⌘/Ctrl + S保存当前打开的清单
⌘/Ctrl + N新建清单

整合包详情窗口

快捷键操作
Esc关闭详情窗口
提示

每个界面右上角的帮助按钮（?）是通过点击打开本页或其他帮助主题的 便捷方式。将鼠标悬停在其图标上，即可看到与屏幕阅读器朗读内容 相同的提示信息。
