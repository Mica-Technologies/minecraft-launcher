语言与本地化

Mica Minecraft Launcher 的界面支持 17 种语言，并会在首次启动时 自动选择合适的语言。您也可以随时在“设置”中手动指定，覆盖 自动检测到的语言。

启动器如何选择语言

每次启动时，启动器都会按以下顺序确定当前使用的 语言：

  1. 您保存的手动设置（如果您在 设置 → 外观 → 语言中设置过）。此项始终优先。
  2. 操作系统的语言，通过 标准 JVM 区域设置检测。在 Windows 上，这是您的“区域 / 语言” 设置；在 macOS 上是“系统设置 → 语言与地区”； 在 Linux 上是 LANG / LC_* 环境变量。
  3. 英语（美国），作为后备语言：当 平台报告的区域设置不对应任何语言（例如 POSIX 或 C），或您的操作系统语言不在我们提供翻译的 17 种语言 之中时使用。
更改语言需重启后生效

在“设置”中切换语言会立即更新偏好设置， 但已经显示的界面会继续使用之前的语言， 直到启动器重新启动。更改下拉菜单时，“设置”页面本身也会 提醒您这一点。

手动指定语言

  1. 从导航栏打开设置 （或按 Ctrl+, / Cmd+,）。
  2. 切换到外观选项卡。
  3. 从语言下拉菜单中选择一种语言。 第一项（“使用操作系统语言”）会恢复上文所述的 自动检测，并在括号中显示操作系统将解析为 哪种语言。
  4. 点击保存。重新启动启动器，即可看到新语言 应用到所有界面。

支持的语言

启动器提供了全球使用人数最多的 17 种语言 以及英语的翻译：

  • 阿拉伯语（عربي）
  • 简体中文（简体中文）
  • 繁体中文（繁體中文）
  • 荷兰语（Nederlands）
  • 英语（源语言）
  • 法语（Français）
  • 德语（Deutsch）
  • 印地语（हिंदी）
  • 意大利语（Italiano）
  • 日语（日本語）
  • 韩语（한국어）
  • 波兰语（Polski）
  • 巴西葡萄牙语（Português do Brasil）
  • 俄语（Русский）
  • 西班牙语（Español）
  • 瑞典语（Svenska）
  • 土耳其语（Türkçe）

每种语言都以其 BCP-47 标签标识（例如 fr-FR、 pt-BR、zh-CN）。该列表位于启动器源代码中的 SupportedLocales.ENTRIES；对应的 属性文件 DisplayStrings_<tag>.properties 位于 src/main/resources/lang/ 下。

翻译质量与问题反馈

英语以外语言的翻译由一个脚本生成， 该脚本使用 Google Translate 翻译英文源资源包，然后 对参数占位符进行后处理，确保 {0} 之类的内容 在翻译后保持完整。生成的译文质量不错，但并不完美 — 尤其是简短的界面标签（单个词的按钮、单个名词），有时会 丢失其在英语中的上下文。

如果您发现翻译不当，最好的方式是在 GitHub 上提交 issue，并附上键名（例如 browse.filter.type.label）、 您的区域设置、当前显示的内容以及建议的修改。 手动修改的译文在下次重新生成时会被保留，因为 该脚本默认只填补缺失的键。

添加新语言

如果您的语言不在上面的列表中，而您希望贡献 翻译，贡献流程如下：

  1. 在 SupportedLocales.ENTRIES （Java）和 tools/i18n/translate-locales.js（Node）中的 TARGET_LOCALES 里添加新条目。
  2. 运行 cd tools/i18n && npm run translate — 脚本会根据英文源文件生成初始的 DisplayStrings_<tag>.properties。
  3. 审阅生成的文件，手动修正读起来不自然的内容， 然后提交 pull request。

tools/i18n/translate-locales.js 脚本是增量式的： 重新运行时只会翻译目标文件中尚不存在的键， 因此在之后每次启动器更新时，手动修正的内容都会被保留。
