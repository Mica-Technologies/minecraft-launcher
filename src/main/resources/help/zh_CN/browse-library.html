浏览

“浏览”界面是您安装和管理内容的地方。在这里，您可以从公共清单安装新的整合包， 安装纯原版 Minecraft 版本，安装空白的 Forge / NeoForge / Fabric 起步整合包，编辑已有的整合包，以及卸载不再需要的内容。

卡片与筛选栏

每个条目都以一张大卡片显示，包含图标、徽章、名称、标签（加载器 / Minecraft 版本）、 一行状态信息以及操作按钮。顶部的筛选栏用于缩小显示范围。

  • 搜索 — 按卡片标题进行自由文本匹配。输入时即时更新 （带有短暂的防抖延迟，避免布局频繁刷新）。
  • 类型 — 全部、整合包，或某个版本目录： 原版（正式版 / 快照 / 远古 Beta 版 / 远古 Alpha 版）以及 Forge / NeoForge / Fabric 版本。 加载器版本筛选项特意不包含在“全部”中——合并后的列表 会有数千个条目，并不是“显示全部内容”的搜索想要的结果。
  • 状态 — 全部、已安装或可安装。“可安装”显示您 尚未安装的内容；“已安装”显示已在磁盘上的内容。
  • 排序 — 默认、名称（A–Z / Z–A）、发布日期、上次游玩、游玩最多、 最近更新。依赖游玩 / 更新历史的排序方式（上次游玩、游玩最多、 最近更新）会把非整合包条目排到最后，而不是混在其中 造成混淆。

已安装的整合包

已在磁盘上的整合包卡片会显示两个按钮：

  • 卸载 — 询问是否同时删除安装文件夹。“卸载（保留文件）” 会保留您的世界、配置和模组，即使启动器已不再记录 该整合包——如果您打算以后重新安装同一个整合包，这会很有用。
  • 编辑 — 在该整合包的本地清单上打开整合包编辑器。 更改会写入磁盘，并在下次启动时生效。
提示

右键点击已安装的整合包卡片，可打开与主菜单相同的右键菜单： 打开整合包文件夹、打开模组文件夹、创建桌面快捷方式、查看游玩统计，以及 卸载。

可安装的整合包

来自公共清单、但您尚未拥有的整合包卡片会显示安装按钮。 点击后会下载清单并安装该整合包，在下次重建列表时，该卡片会移入“已安装” 分组。安装进行期间您仍可继续使用筛选器—— 正在安装的卡片会一直固定在网格顶部，直到安装完成。

原版版本

Mojang 完整的正式版 / 快照 / Beta / Alpha 版本目录。每张卡片都会将对应的 Minecraft 版本安装为一个合成的空白整合包，您可以直接从主菜单开始游戏。远古 Beta 版和 Alpha 版同样可以运行——启动器会自动为每个版本 获取合适的 Java 运行时。

Forge / NeoForge / Fabric 版本

加载器版本筛选项会列出各项目版本服务所公布的每一个版本： Forge promotions、NeoForge Maven 元数据以及 Fabric meta API。在其中某个版本上点击“安装”， 会在您的配置文件夹下写入一个合成的“空白整合包”清单，并将其注册到 启动器中——因此其表现与任何其他已安装的整合包相同：

  • 会显示在主菜单的大卡片中；
  • 可以在整合包编辑器中编辑（因此您可以在其上添加模组，打造自己的整合包）；
  • 可以像其他整合包一样卸载；
  • 与普通整合包共用同一套自动更新机制。
注意

当启动器在本地缓存了各项目的官方图标时，卡片会显示这些图标。 首次打开某个加载器筛选项时，会先显示品牌配色的占位图，同时在后台下载 真正的图标——缓存后，再次访问即可立即显示。

通过 URL 添加

底部栏的从 URL 添加按钮接受一个指向托管的 installable.json 清单的直接 URL，并以与“可安装”整合包卡片相同的方式进行安装。 此功能适用于在公共清单之外分发的整合包——粘贴链接、点击按钮， 启动器会在开始安装前下载并校验清单的元数据。

整合包编辑器

底部栏的整合包编辑器按钮会以空白清单打开 整合包编辑器，让您从零开始构建 新的整合包——设置加载器（Forge / NeoForge / Fabric / 原版）、Minecraft 版本、 模组列表等。也可以通过现有整合包卡片上的编辑 按钮在该整合包上打开编辑器。

生成托管清单

底部栏的生成托管清单按钮会为编辑器中当前的整合包创建一个 installable.json，可直接托管到任意 Web 服务器或文件分享服务上。任何拿到该 URL 的人都可以通过“从 URL 添加” 安装您的整合包。

分页

较长的列表会分页显示。使用分页栏（位于卡片上方）中的上一页 / 下一页按钮 在页面之间切换，并通过每页 下拉菜单设置每页数量——24、48、72 或 96。默认值 48 足以在一页内显示常见的已安装 游戏库；调到 96 则可让加载器版本筛选结果在单页内 滚动浏览。
