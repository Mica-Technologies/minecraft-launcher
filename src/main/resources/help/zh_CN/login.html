登录

Mica Minecraft Launcher 使用官方 Microsoft 身份验证来验证您的 Minecraft 账户。这与官方 Minecraft 启动器使用的登录流程相同。

工作原理

  1. 在登录界面上点击登录。浏览器窗口会打开 Microsoft 登录页面。
  2. 输入您的 Microsoft 账户凭据并确认登录。
  3. 验证通过后，浏览器窗口会关闭，启动器随即进入 主界面。

令牌缓存

成功登录后，您的身份验证令牌会使用基于本机生成的密钥， 以 AES-256-GCM 加密缓存在本地。这意味着：

  • 大约 4 小时内您无需再次登录。
  • 缓存的令牌经过加密，并与您的这台电脑绑定——无法转移到其他地方或在其他地方重复使用。
  • 缓存过期后，启动器会提示您重新登录。

登录问题排查

需要连接互联网

首次登录需要有效的互联网连接。在完全离线的模式下， 启动器无法完成身份验证。

如果您登录时遇到问题：

  • 浏览器没有打开 — 请检查系统中是否已配置默认浏览器。
  • 登录超时 — 请检查网络连接后重试。
  • 无法识别账户 — 请确认您使用的是拥有 Minecraft 的 Microsoft 账户。
  • 反复提示登录 — 缓存的令牌可能已过期。闲置 4 小时后出现这种情况属于正常现象。

如果问题持续存在，请参阅故障排除。
