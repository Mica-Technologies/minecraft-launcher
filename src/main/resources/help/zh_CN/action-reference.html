操作参考

启动器中的每一项整合包操作都至少可以从一个主要入口找到；当您已经在查看某张卡片时， 还可以通过右键菜单中的同名项目快速执行。本页列出每项操作所在的位置，免得您四处寻找。

主要入口

入口包含的内容
主菜单中的大卡片 每个整合包的主要按钮：开始游戏 和 网站。 点击卡片会打开详情窗口。
整合包详情窗口 功能最全的单个整合包界面：快捷操作磁贴 （打开文件夹 / 模组 / 配置 / 截图 / 资源包 / 光影 / 桌面快捷方式 / 复制邀请链接 / 导出为 ZIP）、统计数据、更新日志、 世界、截图网格、光影 / 资源包列表、崩溃记录、 高级部分（验证），以及开始游戏 / 网站操作按钮。
“浏览”界面中的卡片 根据条目类型（整合包 / 原版 / 加载器版本）显示 安装 / 卸载 / 编辑。
右键菜单 无需打开详情窗口，即可从任意整合包卡片快速执行常用的快捷操作。 与详情窗口共用同一套处理逻辑。
设置 启动器全局偏好设置：账户、游戏 / 运行时、外观、高级、 网络、安全、系统、Discord、RGB、关于。

提示

几乎每一项针对单个整合包的操作，都可以在该整合包卡片的右键菜单中找到快捷入口。 如果您发现自己总是要先打开详情窗口才能进入同一个文件夹， 不妨直接在主菜单中右键点击该卡片——同样的项目只需一次点击即可到达。
