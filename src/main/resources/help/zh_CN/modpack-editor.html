整合包编辑器

整合包编辑器是一个内置工具，用于创建和编辑整合包的 JSON 定义文件。 它提供结构化的界面，并支持校验、集成搜索和差异跟踪。

工具栏

  • 新建 — 从模板创建空白的整合包定义。
  • 打开文件 — 从磁盘加载现有的 JSON 定义。
  • 打开 URL — 从远程 URL 获取并加载定义。
  • 保存 — 将当前定义写入本地文件。
  • 校验 — 检查定义中的错误（缺少字段、无效 URL、哈希值不匹配）。
  • 对比 — 将当前状态与上次保存的版本进行比较，查看更改了哪些内容。

元数据字段

顶部区域包含整合包的核心信息：名称、版本、简介、作者、 Minecraft 版本和 Forge 版本。Forge 版本选择器可让您浏览 所选 Minecraft 版本可用的 Forge 构建版本。

文件选项卡

文件按类别分布在以下选项卡中：

模组放在 mods/ 文件夹中的 Forge 模组 JAR 文件。
配置模组的配置文件，放在 config/ 中。
资源资源包及其他资源文件。
光影适用于 OptiFine 或 Iris 的光影包。
初始文件仅在首次安装时复制的文件（例如默认的 options.txt）。

每个文件条目都包含下载 URL 和 SHA-1 哈希值。编辑器可以通过下载文件并计算其校验和， 自动计算哈希值。

Modrinth 搜索

使用集成的 Modrinth 搜索可按名称查找模组。选择一个结果即可自动 为正确的版本填写下载 URL 和哈希值字段。

提升版本号

提升版本按钮会递增整合包的版本号，便于 发布启动器能够自动检测到的更新。

URL 检查

编辑器可以验证所有文件下载 URL 是否可访问，帮助您在发布前 发现失效的链接。

提示

请在保存前使用校验，以便尽早发现问题。校验器会检查 必填字段、URL 是否有效以及哈希值格式是否正确。
