设置

在设置界面中，您可以自定义内存分配、外观、JVM 行为、网络 配置等。更改会自动保存。

游戏内存

最小内存分配给游戏 JVM 的初始堆大小。除非整合包另有要求，通常保留默认值（512 MB）即可。
最大内存游戏可使用的内存上限。大多数整合包在 4 - 8 GB 时表现最佳。分配超出系统可用量的内存可能导致运行不稳定。
提示

一条实用的经验法则：最大内存不要超过系统总内存的一半。 例如，在 16 GB 内存的电脑上，6 - 8 GB 是合理的上限。

JVM 预设

预先配置好的 JVM 参数组，会追加到游戏启动命令中。有关每个预设的作用、 您可能想要添加哪些自定义参数，以及预设选择与内存分配之间的关系， 请参阅 JVM 预设中的详细说明。

Performance (Aikar's Flags)推荐。经过优化的垃圾回收参数，在 Minecraft 社区中被广泛使用。对大多数整合包而言整体性能最佳。
Low Memory面向内存有限的系统的保守参数。以牺牲部分吞吐量为代价降低 GC 开销。
Debug启用 JVM 调试输出，包括 GC 日志。适用于诊断崩溃或性能问题。
None不添加额外参数——使用 JVM 的默认值。仅当您清楚自己在做什么，或整合包有此要求时才使用。

网络 / 代理

如果您的网络要求使用代理（常见于公司或学校网络），请在此配置代理。

HTTP 代理标准 Web 代理。请输入网络管理员提供的主机和端口。
SOCKS 代理较低层级的代理协议。仅当您的网络明确要求使用 SOCKS 时才选择此项。
注意

大多数用户可以将代理设置留空。只有在受限网络中下载或 身份验证失败时，才需要配置这些设置。

恶意软件扫描

启动器内置了一个扫描程序，会检查下载的 JAR 文件中是否含有 fractureiser 的特征——这是一种于 2023 年通过被篡改的模组传播的 Minecraft 专属恶意软件。 扫描会在每次启动游戏前自动运行。

重置与运行时选项

重置启动器将所有设置恢复为默认值并清除缓存数据。此操作无法撤消。
运行时管理打开运行时管理界面，查看、验证或移除已安装的 Java 运行时。
警告

重置启动器会移除所有设置、缓存的令牌和整合包状态。 磁盘上的整合包文件会被保留，但您需要重新添加它们。

导入 / 导出设置

使用导出设置将当前配置保存到文件，使用导入设置 加载之前保存的配置。这在多台电脑之间共享设置， 或在重置后恢复一份已知可用的配置时非常有用。
