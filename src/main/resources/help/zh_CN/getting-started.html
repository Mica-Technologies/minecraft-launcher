入门

欢迎使用 Mica Minecraft Launcher——一款跨平台的 Minecraft Forge 整合包启动器， 只需一次点击即可轻松安装、更新和游玩整合包。

快速上手

  1. 使用您的 Microsoft 账户登录。启动器使用官方 Microsoft 身份验证来确认您拥有 Minecraft。详情请参阅登录。
  2. 选择一个整合包：从主界面左侧的列表中选择。 如果尚未安装任何整合包，请使用 浏览添加一个。
  3. 点击“开始游戏”，启动器会自动下载所有必需的文件， 安装正确的 Forge 版本，验证文件完整性，然后启动游戏。

启动器为您处理的工作

  • 下载和更新整合包文件（模组、配置、资源）
  • 为每个整合包安装正确的 Forge 版本
  • 管理 Java 运行时——无需手动安装 JDK
  • 通过 SHA-1 哈希校验验证文件完整性
  • 扫描下载的文件中是否含有已知恶意软件
提示

留意每个界面上的 ? 按钮——它会打开与您当前所在界面 相关的帮助内容。

  • 故障排除 — 常见问题及解决方法
