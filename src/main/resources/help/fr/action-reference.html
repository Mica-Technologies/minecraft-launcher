Référence des actions

Chaque action liée aux modpacks est accessible depuis au moins un emplacement de référence, complété par un raccourci dans le menu contextuel pour un accès rapide lorsque vous avez déjà une carte sous les yeux. Cette page indique où se trouve chaque action, pour vous éviter de la chercher.

Emplacements de référence

EmplacementCe que vous y trouvez
Cartes vedettes du menu principal Boutons principaux Jouer et Site web pour chaque pack. Un clic sur la carte ouvre la fenêtre de détails.
Fenêtre de détails du modpack L'emplacement le plus complet pour chaque pack : tuiles Actions rapides (Ouvrir le dossier / Mods / Configuration / Captures d'écran / Packs de ressources / Shaders / Raccourci sur le bureau / Copier le lien d'invitation / Exporter au format ZIP), Statistiques, Historique des mises à jour, Mondes, grille des captures d'écran, listes des packs de shaders et de ressources, Historique des plantages, section Avancé (vérification) et boutons d'action Jouer / Site web.
Cartes de l'écran Parcourir Installer / Désinstaller / Modifier selon le type d'entrée (modpack / vanilla / version de chargeur).
Menu contextuel (clic droit) Accès rapide aux Actions rapides courantes depuis n'importe quelle carte de pack, sans ouvrir la fenêtre de détails. Il utilise exactement les mêmes actions que la fenêtre.
Paramètres Préférences globales du lanceur : compte, jeu / runtime, apparence, avancé, réseau, sécurité, système, Discord, RVB, À propos.

Astuce

Presque toutes les actions propres à un pack disposent d'un raccourci dans le menu contextuel de sa carte. Si vous passez sans cesse par la fenêtre de détails simplement pour atteindre le même dossier, essayez plutôt de faire un clic droit sur la carte dans le menu principal : les mêmes éléments s'y trouvent à un clic.
