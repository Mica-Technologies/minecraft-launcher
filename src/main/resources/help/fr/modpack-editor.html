Éditeur de modpack

L'éditeur de modpacks est un outil intégré qui permet de créer et de modifier les fichiers JSON de définition des modpacks. Il offre une interface structurée avec validation, recherche intégrée et suivi des différences.

Barre d'outils

  • Nouveau — crée une définition de modpack vierge à partir d'un modèle.
  • Ouvrir le fichier — charge une définition JSON existante depuis le disque.
  • Ouvrir l'URL — récupère et charge une définition depuis une URL distante.
  • Enregistrer — écrit la définition actuelle dans un fichier local.
  • Valider — recherche les erreurs dans la définition (champs manquants, URL invalides, hash non concordants).
  • Différences — compare l'état actuel à la dernière version enregistrée pour voir ce qui a changé.

Champs de métadonnées

La section supérieure contient les informations principales du modpack : nom, version, description, auteur, version de Minecraft et version de Forge. Le sélecteur de version de Forge vous permet de parcourir les builds de Forge disponibles pour la version de Minecraft sélectionnée.

Onglets de fichiers

Les fichiers sont classés dans des onglets par catégorie :

ModsFichiers JAR de mods Forge placés dans le dossier mods/.
ConfigurationsFichiers de configuration des mods, placés dans config/.
RessourcesPacks de ressources et autres éléments.
ShadersPacks de shaders pour OptiFine ou Iris.
Fichiers initiauxFichiers copiés uniquement lors de la première installation (par ex. un options.txt par défaut).

Chaque entrée de fichier comprend une URL de téléchargement et un hash SHA-1. L'éditeur peut calculer automatiquement les hash en téléchargeant le fichier et en calculant sa somme de contrôle.

Recherche Modrinth

Utilisez la recherche Modrinth intégrée pour trouver des mods par leur nom. Sélectionnez un résultat pour remplir automatiquement les champs d'URL de téléchargement et de hash avec la bonne version.

Incrémentation de la version

Le bouton Incrémenter la version augmente le numéro de version du modpack, ce qui facilite la publication de mises à jour que le lanceur détectera automatiquement.

Vérification des URL

L'éditeur peut vérifier que toutes les URL de téléchargement des fichiers sont accessibles, ce qui vous aide à repérer les liens cassés avant la publication.

Astuce

Utilisez Valider avant d'enregistrer pour détecter les problèmes au plus tôt. Le validateur vérifie les champs obligatoires, la validité des URL et le format des hash.
