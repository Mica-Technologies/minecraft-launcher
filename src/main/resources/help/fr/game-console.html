Console du jeu

La console du jeu affiche en temps réel la sortie du processus Minecraft, notamment les messages du journal, les avertissements, les erreurs et les rapports de plantage.

Activer la console

La fenêtre de la console s'affiche à côté du jeu lorsque l'option Console en jeu est activée dans les Paramètres, sous Options avancées. Lorsqu'elle est désactivée, le jeu s'exécute sans console visible.

Fonctionnalités de la console

  • Sortie en temps réel — les lignes du journal du jeu apparaissent au fur et à mesure de leur production.
  • Forcer l'arrêt du jeu — met fin de force au processus Minecraft si le jeu ne répond plus. À n'utiliser qu'en dernier recours.
  • Copier — copie le contenu de la console dans le presse-papiers pour le partager ou l'analyser.

Rapports de plantage

Lorsque le jeu plante, la console détecte automatiquement le plantage et met en évidence le rapport de plantage correspondant. Vous pouvez :

  • consulter le rapport de plantage complet directement dans la console ;
  • utiliser le bouton Copier pour copier le texte du rapport de plantage afin de le transmettre aux auteurs du modpack ou aux canaux d'assistance.
Remarque

L'affichage de la console est tronqué pour limiter l'utilisation de la mémoire lors des longues sessions de jeu. Pour obtenir le journal complet, non tronqué, consultez les fichiers journaux sur le disque.

Emplacement des fichiers journaux

Les journaux complets du jeu sont écrits dans le répertoire logs/ du modpack. Vous pouvez accéder rapidement à ce dossier en faisant un clic droit sur le modpack dans l'Écran principal puis en sélectionnant Ouvrir le dossier d'installation.

Astuce

Si vous signalez un plantage, joignez à la fois le rapport de plantage et le fichier journal le plus récent : le journal contient souvent un contexte que le rapport de plantage seul ne fournit pas.
