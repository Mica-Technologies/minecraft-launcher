Gestion des environnements Java

Mica Minecraft Launcher gère automatiquement les runtimes Java : vous n'avez jamais besoin d'installer ni de configurer Java vous-même.

Pourquoi les runtimes sont importants

Minecraft et Forge nécessitent des versions précises de Java pour fonctionner correctement. Des modpacks et des versions de Minecraft différents peuvent nécessiter des runtimes Java différents :

  • Minecraft 1.16 et versions antérieures — Java 8
  • Minecraft 1.17 à 1.20 — Java 17
  • Minecraft 1.21 et versions ultérieures — Java 21 ou version ultérieure

Le lanceur détecte le runtime requis par chaque modpack ou version vanilla et le télécharge automatiquement au premier lancement.

Téléchargements automatiques

Lorsque vous lancez un modpack ou une version vanilla pour la première fois, le lanceur vérifie si le runtime requis est déjà installé. Si ce n'est pas le cas, il télécharge la bonne version depuis les serveurs de distribution de Mojang ou de Liberica. Ce téléchargement n'a lieu qu'une seule fois par version de runtime.

Remarque

Les runtimes téléchargés pèsent généralement entre 40 et 80 Mo et sont stockés dans le répertoire de données du lanceur, séparément de toute installation de Java présente sur votre système.

Consulter les runtimes installés

Ouvrez les Paramètres et cliquez sur Gestion des runtimes pour afficher la liste de tous les runtimes Java installés, avec leur version, leur chemin et les modpacks qui les utilisent.

Supprimer les runtimes inutilisés

Si vous avez supprimé les modpacks qui utilisaient une version de Java donnée, vous pouvez supprimer le runtime correspondant pour libérer de l'espace disque. Sélectionnez un runtime dans l'écran de gestion et cliquez sur Supprimer.

Avertissement

Si vous supprimez un runtime encore nécessaire à un modpack installé, le lanceur le retéléchargera au prochain lancement de ce modpack.

Résoudre les problèmes de runtime

Si un modpack ne parvient pas à se lancer en raison d'erreurs liées à Java, essayez ce qui suit :

  1. Ouvrez la Gestion des runtimes et supprimez le runtime utilisé par le modpack concerné.
  2. Relancez le modpack : le lanceur retéléchargera une copie neuve.
  3. Si le problème persiste, consultez Dépannage pour d'autres étapes.
