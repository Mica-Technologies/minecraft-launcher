Raccourcis clavier

Le lanceur propose un petit ensemble de raccourcis clavier pour les actions que vous effectuez le plus souvent. Sous macOS, la touche de modification est ⌘ Commande ; sous Windows et Linux, il s'agit de Ctrl. Les raccourcis ci-dessous indiquent la touche de modification sous la forme ⌘/Ctrl pour couvrir les deux cas.

Navigation globale

Disponibles sur tous les écrans, sauf Connexion, la progression du lancement et la fenêtre de la console en jeu : ces écrans n'acceptent volontairement aucun raccourci de navigation, pour que vous ne les quittiez pas par inadvertance au milieu d'une opération.

RaccourciAction
⌘/Ctrl + ,Ouvrir les Paramètres (convention universelle)
⌘/Ctrl + LOuvrir l'écran Parcourir (installation et gestion)
⌘/Ctrl + EOuvrir l'Éditeur de modpacks
⌘/Ctrl + Shift + MRevenir au menu principal (Accueil)
F1 / ⌘/Ctrl + ?Ouvrir la fenêtre d'aide sur la rubrique de l'écran actuel
Pourquoi Cmd+Shift+M pour l'Accueil ?

La combinaison simple ⌘ + M est le raccourci système macOS « Réduire la fenêtre » : le lanceur évite de le remplacer. ⌘/Ctrl + Shift + M contourne ce conflit sur toutes les plateformes.
