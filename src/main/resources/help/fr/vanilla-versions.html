Versions vanilla

En plus des modpacks Forge, le lanceur peut installer et lancer directement des versions vanilla (sans mods) de Minecraft.

Parcourir les versions

L'écran des versions vanilla affiche la liste des versions stables et des snapshots de Minecraft disponibles. Chaque entrée indique le numéro de version et la date de sortie. Sélectionnez une version pour afficher ses détails.

Installation et lancement

  1. Sélectionnez une version de Minecraft dans la liste.
  2. Cliquez sur Installer pour télécharger le client du jeu, les bibliothèques et les ressources de cette version.
  3. Une fois l'installation terminée, cliquez sur Jouer pour lancer le jeu. Le lanceur se charge automatiquement de toute la vérification des fichiers et de la configuration du runtime.
Remarque

Les versions vanilla utilisent les mêmes réglages de mémoire et de JVM que ceux définis dans les Paramètres. Si une version fonctionne mal, essayez d'ajuster votre allocation de RAM ou votre préréglage JVM.

Gestion des runtimes

Différentes versions de Minecraft peuvent nécessiter différents runtimes Java. Le lanceur télécharge et gère automatiquement le runtime adapté à chaque version : par exemple, Minecraft 1.17 et versions ultérieures nécessitent Java 17 ou une version ultérieure, tandis que les versions plus anciennes utilisent Java 8.

Vous n'avez pas besoin d'installer Java manuellement. Consultez Gestion des environnements Java pour en savoir plus sur la gestion des runtimes.

Astuce

Les versions vanilla sont un bon moyen de vérifier si votre système répond à la configuration minimale avant d'installer des modpacks plus volumineux.
