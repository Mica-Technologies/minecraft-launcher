Connexion

Mica Minecraft Launcher utilise l'authentification officielle de Microsoft pour vérifier votre compte Minecraft. Il s'agit du même processus de connexion que celui du lanceur Minecraft officiel.

Fonctionnement

  1. Cliquez sur Se connecter sur l'écran de connexion. Une fenêtre de navigateur s'ouvre sur la page de connexion Microsoft.
  2. Saisissez les identifiants de votre compte Microsoft et approuvez la connexion.
  3. Une fois l'authentification réussie, la fenêtre du navigateur se ferme et le lanceur passe à l'Écran principal.

Mise en cache du jeton

Après une connexion réussie, votre jeton d'authentification est mis en cache localement grâce à un chiffrement AES-256-GCM utilisant une clé dérivée de la machine. Cela signifie que :

  • vous n'aurez pas besoin de vous reconnecter pendant environ 4 heures ;
  • le jeton en cache est chiffré et lié à votre machine : il ne peut être ni transféré ni réutilisé ailleurs ;
  • une fois le cache expiré, le lanceur vous invite à vous reconnecter.

Résoudre les problèmes de connexion

Connexion Internet requise

Une connexion Internet active est nécessaire pour la première connexion. Le lanceur ne peut pas vous authentifier en mode entièrement hors ligne.

Si vous avez du mal à vous connecter :

  • Le navigateur ne s'ouvre pas — vérifiez qu'un navigateur par défaut est configuré sur votre système.
  • La connexion expire — vérifiez votre connexion Internet et réessayez.
  • Compte non reconnu — assurez-vous d'utiliser le compte Microsoft qui possède Minecraft.
  • Demandes de connexion répétées — le jeton en cache a peut-être expiré. C'est normal après 4 heures d'inactivité.

Si le problème persiste, consultez Dépannage.
