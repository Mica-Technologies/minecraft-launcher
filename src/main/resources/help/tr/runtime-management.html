Çalışma Zamanı Yönetimi

Mica Minecraft Launcher, Java çalışma ortamlarını otomatik olarak yönetir; böylece Java'yı hiçbir zaman kendiniz yüklemeniz veya yapılandırmanız gerekmez.

Çalışma Ortamları Neden Önemlidir

Minecraft ve Forge'un düzgün çalışması için belirli Java sürümleri gerekir. Farklı mod paketleri ve Minecraft sürümleri farklı Java çalışma ortamlarına ihtiyaç duyabilir:

  • Minecraft 1.16 ve öncesi — Java 8
  • Minecraft 1.17 - 1.20 — Java 17
  • Minecraft 1.21+ — Java 21 veya üstü

Başlatıcı, her mod paketinin veya vanilla sürümünün hangi çalışma ortamını gerektirdiğini algılar ve ilk başlatmada bunu otomatik olarak indirir.

Otomatik İndirmeler

Bir mod paketini veya vanilla sürümünü ilk kez başlattığınızda başlatıcı, gerekli çalışma ortamının zaten yüklü olup olmadığını kontrol eder. Yüklü değilse doğru sürümü Mojang'ın veya Liberica'nın dağıtım sunucularından indirir. Bu, her çalışma ortamı sürümü için tek seferlik bir indirmedir.

Not

Çalışma ortamı indirmeleri genellikle 40 - 80 MB boyutundadır ve sisteminizdeki herhangi bir Java kurulumundan ayrı olarak başlatıcının veri dizininde saklanır.

Yüklü Çalışma Ortamlarını Görüntüleme

Ayarlar'ı açın ve sürümleri, yolları ve hangi mod paketlerinin kullandığı dahil tüm yüklü Java çalışma ortamlarının listesini görmek için Çalışma Ortamı Yönetimi'ne tıklayın.

Kullanılmayan Çalışma Ortamlarını Silme

Belirli bir Java sürümünü kullanan mod paketlerini kaldırdıysanız disk alanı açmak için ilgili çalışma ortamını silebilirsiniz. Yönetim ekranında bir çalışma ortamı seçin ve Sil'e tıklayın.

Uyarı

Yüklü bir mod paketinin hâlâ ihtiyaç duyduğu bir çalışma ortamını silerseniz başlatıcı, o mod paketinin bir sonraki başlatılışında onu yeniden indirir.

Çalışma Ortamı Sorunlarını Giderme

Bir mod paketi Java ile ilgili hatalar nedeniyle başlatılamıyorsa şunları deneyin:

  1. Çalışma Ortamı Yönetimi'ni açın ve sorunlu mod paketinin kullandığı çalışma ortamını silin.
  2. Mod paketini yeniden başlatın; başlatıcı yeni bir kopyasını indirir.
  3. Sorun devam ederse ek adımlar için Sorun Giderme konusuna bakın.
