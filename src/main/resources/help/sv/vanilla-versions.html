Vanilla-versioner

Utöver Forge-modpaket kan startprogrammet installera och spela vanilla-versioner (utan mods) av Minecraft direkt.

Bläddra bland versioner

Skärmen för vanilla-versioner visar en lista över tillgängliga Minecraft-utgåvor och snapshots. Varje post visar versionsnumret och utgivningsdatumet. Välj en version för att se dess detaljer.

Installera och starta

  1. Välj en Minecraft-version i listan.
  2. Klicka på Installera för att ladda ner spelklienten, biblioteken och tillgångarna för den versionen.
  3. När den är installerad klickar du på Spela för att starta. Startprogrammet sköter all filverifiering och konfiguration av körmiljön automatiskt.
Obs

Vanilla-versioner använder samma minnes- och JVM-inställningar som du har konfigurerat i Inställningar. Om en version fungerar dåligt, prova att justera RAM-tilldelningen eller JVM-förinställningen.

Körmiljöhantering

Olika Minecraft-versioner kan kräva olika Java-körmiljöer. Startprogrammet laddar automatiskt ner och hanterar rätt körmiljö för varje version – till exempel kräver Minecraft 1.17+ Java 17 eller senare, medan äldre versioner använder Java 8.

Du behöver inte installera Java manuellt. Se Körmiljöhantering för mer information om hur körmiljöer hanteras.

Tips

Vanilla-versioner är ett bra sätt att testa om ditt system uppfyller grundkraven innan du installerar större modpaket.
