Språk och lokalisering

Mica Minecraft Launcher visar sitt gränssnitt på 17 språk och väljer rätt språk automatiskt vid första starten. Du kan också åsidosätta det identifierade språket när som helst i Inställningar.

Så väljer startprogrammet språk

Varje gång du startar startprogrammet bestäms det aktiva språket i den här ordningen:

  1. Ditt sparade val, om du har angett ett under Inställningar → Utseende → Språk. Det vinner alltid.
  2. Operativsystemets språk, som identifieras via JVM:ens standardlokal. På Windows är det din inställning för Region / Språk; på macOS är det Systeminställningar → Språk och region; på Linux är det miljövariablerna LANG / LC_*.
  3. Engelska (USA) som reserv om plattformen rapporterar en lokal utan språk (t.ex. POSIX eller C), eller om ditt systemspråk inte är något av de 17 som vi levererar översättningar för.
Språkbytet gäller efter omstart

När du ändrar valet i Inställningar uppdateras inställningen direkt, men skärmar som redan visas fortsätter att använda det tidigare språket tills startprogrammet startas om. Inställningssidan påminner dig om detta när du ändrar listrutan.

Välja språk manuellt

  1. Öppna Inställningar från navigeringsfältet (eller tryck på Ctrl+, / Cmd+,).
  2. Gå till fliken Utseende.
  3. Välj ett språk i listrutan Språk. Det första alternativet (”Använd operativsystemets språk”) återställer den automatiska identifiering som beskrivs ovan och visar inom parentes vilket språk operativsystemet skulle ge.
  4. Klicka på Spara. Starta om startprogrammet för att se det nya språket på alla skärmar.

Språk som stöds

Startprogrammet levereras med översättningar till världens 17 mest talade språk plus engelska:

  • Arabiska (عربي)
  • Kinesiska, förenklad (简体中文)
  • Kinesiska, traditionell (繁體中文)
  • Nederländska (Nederlands)
  • Engelska (källspråk)
  • Franska (Français)
  • Tyska (Deutsch)
  • Hindi (हिंदी)
  • Italienska (Italiano)
  • Japanska (日本語)
  • Koreanska (한국어)
  • Polska (Polski)
  • Portugisiska, brasiliansk (Português do Brasil)
  • Ryska (Русский)
  • Spanska (Español)
  • Svenska (Svenska)
  • Turkiska (Türkçe)

Varje språk identifieras med sin BCP-47-tagg (t.ex. fr-FR, pt-BR, zh-CN). Listan finns i SupportedLocales.ENTRIES i startprogrammets källkod; egenskapsfilerna ligger bredvid som DisplayStrings_<tag>.properties under src/main/resources/lang/.

Översättningskvalitet & rapportera problem

Översättningar till andra språk än engelska genereras av ett skript som anropar Google Translate med det engelska källpaketet och sedan efterbearbetar parameterplatshållare så att till exempel {0} överlever översättningen oförändrade. Resultatet är bra men inte perfekt — framför allt kan korta gränssnittsetiketter (knappar med ett ord, enstaka substantiv) ibland förlora sammanhang som de hade på engelska.

Om du hittar en dålig översättning är det bästa att öppna ett ärende på GitHub med nyckelns namn (t.ex. browse.filter.type.label), din lokal, den nuvarande texten och ett förslag på rättelse. Handredigerade rättelser finns kvar efter nästa generering eftersom skriptet som standard bara fyller i nycklar som saknas.

Lägga till ett nytt språk

Om ditt språk inte finns i listan ovan och du vill bidra med en översättning går det till så här:

  1. Lägg till en ny post i SupportedLocales.ENTRIES (Java) och TARGET_LOCALES i tools/i18n/translate-locales.js (Node).
  2. Kör cd tools/i18n && npm run translate — skriptet genererar den första DisplayStrings_<tag>.properties från den engelska källan.
  3. Granska den genererade filen, rätta för hand allt som låter konstigt och öppna sedan en pull request.

Skriptet tools/i18n/translate-locales.js är inkrementellt: när det körs igen översätts bara nycklar som inte redan finns i målfilen, så handgjorda rättelser bevaras vid varje senare uppdatering av startprogrammet.
