Bläddra

Skärmen Bläddra är där du installerar och hanterar. Härifrån kan du installera nya modpaket från det offentliga manifestet, installera rena vanilla-versioner av Minecraft, installera tomma startpaket för Forge / NeoForge / Fabric, redigera paket du redan har och avinstallera sådant du inte längre vill ha.

Kort & filterfältet

Varje post visas som ett stort kort med logotyp, märke, namn, etiketter (modladdare / Minecraft-version), en statusrad och åtgärdsknappar. Filterfältet högst upp används för att begränsa visningen.

  • Sök – fritextsökning mot korttitlarna. Uppdateras medan du skriver (med en kort fördröjning så att layouten inte ritas om hela tiden).
  • Typ – Alla, Modpaket eller någon av versionskatalogerna: Vanilla (Utgåvor / Snapshots / Old Beta / Old Alpha) och versioner av Forge / NeoForge / Fabric. Filtren för modladdarversioner ingår avsiktligt inte i ”Alla” – den sammanslagna listan skulle bli tusentals poster och är inte vad en ”visa allt”-sökning är ute efter.
  • Status – Alla, Installerad eller Tillgänglig. ”Tillgänglig” visar sådant du inte har installerat än; ”Installerad” visar det som redan finns på disken.
  • Sortera – Standard, Namn (A–Z / Z–A), Utgivningsdatum, Senast spelade, Mest spelade, Nyligen uppdaterade. Sorteringar som bygger på spel- eller uppdateringshistorik (Senast spelade, Mest spelade, Nyligen uppdaterade) placerar poster som inte är modpaket längst ned i stället för att blanda in dem på ett förvirrande sätt.

Installerade modpaket

Kort för paket som redan finns på disken visar två knappar:

  • Avinstallera – frågar om installationsmappen också ska tas bort. ”Avinstallera (behåll filer)” behåller dina världar, konfigurationer och mods även om startprogrammet inte längre känner till paketet – praktiskt om du tänker installera samma paket igen senare.
  • Redigera – öppnar Modpaketredigerare med paketets lokala manifest. Ändringarna skrivs till disk och gäller från nästa start.
Tips

Högerklicka på ett installerat modpakets kort för att få samma snabbmeny som i huvudmenyn: öppna paketmappen, öppna mods-mappen, skapa en skrivbordsgenväg, visa spelstatistik och avinstallera.

Tillgängliga modpaket

Kort från det offentliga manifestet som du ännu inte har visar knappen Installera. När du klickar på den hämtas manifestet, modpaketet installeras och kortet flyttas till gruppen Installerad vid nästa uppdatering av vyn. Du kan fortsätta använda filtren medan en installation pågår – kortet som installeras ligger kvar högst upp i rutnätet tills installationen är klar.

Vanilla-versioner

Mojangs fullständiga katalog med utgåvor / snapshots / betor / alfor. Varje kort installerar exakt den Minecraft-versionen som ett syntetiskt tomt modpaket som du kan spela direkt från huvudmenyn. Gamla betor och alfor går också att köra – startprogrammet hämtar automatiskt rätt Java-körmiljö för varje version.

Versioner av Forge / NeoForge / Fabric

Filtren för modladdarversioner visar varje version som respektive projekts versionstjänst publicerar: Forge-promotions, NeoForges Maven-metadata och Fabrics meta-API. Om du klickar på Installera för någon av dessa skrivs ett syntetiskt manifest för ett ”tomt modpaket” till din konfigurationsmapp och registreras i startprogrammet – så resultatet fungerar som vilket annat installerat modpaket som helst:

  • det visas bland huvudmenyns stora kort;
  • det kan redigeras i Modpaketredigerare (så att du kan lägga till mods ovanpå och bygga ditt eget paket);
  • det kan avinstalleras som vilket annat paket som helst;
  • det använder samma mekanism för automatiska uppdateringar som ett vanligt modpaket.
Obs

Korten visar respektive projekts officiella logotyp när startprogrammet har den sparad lokalt. Vid första besöket i ett modladdarfilter visas en platshållare i varumärkets färg medan de riktiga logotyperna laddas ner i bakgrunden – när de väl är sparade går senare besök direkt.

Lägg till via URL

Knappen Lägg till från URL i nedre fältet tar en direkt URL till ett publicerat installable.json-manifest och installerar det på samma sätt som korten för tillgängliga paket. Använd den för modpaket som distribueras utanför det offentliga manifestet – klistra in länken, klicka på knappen, så hämtas och valideras manifestets metadata innan installationen börjar.

Modpaketredigerare

Knappen Modpaketredigerare i nedre fältet öppnar Modpaketredigerare med ett tomt manifest så att du kan bygga ett nytt paket från grunden – ange modladdare (Forge / NeoForge / Fabric / vanilla), Minecraft-version, modlista osv. Redigeraren kan också öppnas för ett befintligt paket via knappen Redigera på dess kort.

Generera manifest för webbhotell

Knappen Generera manifest för webbhotell i nedre fältet skapar en installable.json för det modpaket som för närvarande är öppet i redigeraren, redo att publiceras på valfri webbserver eller fildelningstjänst. Alla som har den resulterande URL:en kan installera ditt paket via Lägg till från URL.

Sidindelning

Långa listor delas upp i sidor. Använd knapparna Föreg / Nästa i sidfältet (ovanför korten) för att växla mellan sidor och listrutan Per sida för att ange sidstorleken – 24, 48, 72 eller 96. Standardvärdet 48 räcker för ett typiskt installerat bibliotek på en sida; med 96 går det att bläddra igenom modladdarfiltren på en enda sida.
