Åtgärdsreferens

Varje modpaketåtgärd i startprogrammet kan nås från minst en primär plats, med en kopia i snabbmenyn för snabb åtkomst när du redan tittar på ett kort. Den här sidan beskriver var varje åtgärd finns så att du slipper leta.

Primära platser

PlatsVad som finns här
Huvudmenyns stora kort Primära knappar för Spela + Webbplats för varje paket. Ett klick på kortet öppnar detaljfönstret.
Modpaketets detaljfönster Den mest omfattande platsen per paket: rutor under Snabbåtgärder (Öppna mapp / Mods / Konfiguration / Skärmdumpar / Resurspaket / Shaders / Skrivbordsgenväg / Kopiera inbjudningslänk / Exportera som ZIP), Statistik, Uppdateringslogg, Världar, rutnät med Skärmdumpar, listor över Shader-paket / Resurspaket, Kraschhistorik, avsnittet Avancerat (verifiering) samt åtgärdsknapparna Spela / Webbplats.
Kort på skärmen Bläddra Installera / Avinstallera / Redigera beroende på postens typ (modpaket / vanilla / version av modladdare).
Snabbmeny (högerklick) Snabb åtkomst till de vanligaste Snabbåtgärderna från valfritt paketkort utan att öppna detaljfönstret. Använder exakt samma funktioner som detaljfönstret.
Inställningar Inställningar för hela startprogrammet: konto, spel / körmiljö, utseende, avancerat, nätverk, säkerhet, system, Discord, RGB, Om.

Tips

Nästan varje åtgärd per paket har en genväg i snabbmenyn på paketets kort. Om du gång på gång klickar dig igenom detaljfönstret bara för att nå samma mapp, prova att högerklicka på kortet i huvudmenyn – samma alternativ finns bara ett klick bort.
