Körmiljöhantering

Mica Minecraft Launcher hanterar Java-körmiljöer automatiskt, så du behöver aldrig installera eller konfigurera Java själv.

Varför körmiljöer spelar roll

Minecraft och Forge kräver specifika Java-versioner för att fungera korrekt. Olika modpaket och Minecraft-versioner kan behöva olika Java-körmiljöer:

  • Minecraft 1.16 och äldre – Java 8
  • Minecraft 1.17 - 1.20 – Java 17
  • Minecraft 1.21+ – Java 21 eller senare

Startprogrammet avgör vilken körmiljö varje modpaket eller vanilla-version behöver och laddar ner den automatiskt vid första starten.

Automatiska nedladdningar

När du startar ett modpaket eller en vanilla-version för första gången kontrollerar startprogrammet om den nödvändiga körmiljön redan är installerad. Om inte laddas rätt version ner från Mojangs eller Libericas distributionsservrar. Varje körmiljöversion laddas bara ner en gång.

Obs

Nedladdade körmiljöer är oftast 40–80 MB och lagras i startprogrammets datakatalog, åtskilda från eventuella Java-installationer i systemet.

Visa installerade körmiljöer

Öppna Inställningar och klicka på Hantera körmiljöer för att se en lista över alla installerade Java-körmiljöer, inklusive version, sökväg och vilka modpaket som använder dem.

Ta bort oanvända körmiljöer

Om du har tagit bort modpaket som använde en viss Java-version kan du ta bort motsvarande körmiljö för att frigöra diskutrymme. Välj en körmiljö på hanteringsskärmen och klicka på Ta bort.

Varning

Om du tar bort en körmiljö som fortfarande behövs av ett installerat modpaket laddar startprogrammet ner den igen nästa gång modpaketet startas.

Felsöka körmiljöer

Om ett modpaket inte startar och visar Java-relaterade fel kan du prova följande:

  1. Öppna Hantera körmiljöer och ta bort körmiljön som det berörda modpaketet använder.
  2. Starta modpaketet igen – startprogrammet laddar ner en ny kopia.
  3. Om problemet kvarstår, se Felsökning för fler steg.
