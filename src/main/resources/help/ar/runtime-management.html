إدارة بيئات التشغيل

يدير Mica Minecraft Launcher بيئات تشغيل Java تلقائيًا، فلن تحتاج أبدًا إلى تثبيت Java أو إعدادها بنفسك.

لماذا تهمّ بيئات التشغيل

يتطلب Minecraft وForge إصدارات محددة من Java ليعملا بشكل صحيح. وقد تحتاج حزم التعديلات وإصدارات Minecraft المختلفة إلى بيئات تشغيل Java مختلفة:

  • Minecraft 1.16 وما قبله — Java 8
  • Minecraft 1.17 - 1.20 — Java 17
  • Minecraft 1.21+ — Java 21 أو أحدث

يكتشف المشغّل بيئة التشغيل التي تتطلبها كل حزمة تعديلات أو كل إصدار أساسي، وينزّلها تلقائيًا عند التشغيل الأول.

التنزيلات التلقائية

عند تشغيل حزمة تعديلات أو إصدار أساسي لأول مرة، يتحقق المشغّل مما إذا كانت بيئة التشغيل المطلوبة مثبّتة بالفعل. وإن لم تكن، ينزّل الإصدار الصحيح من خوادم التوزيع الخاصة بـ Mojang أو Liberica. ويجري هذا التنزيل مرة واحدة فقط لكل إصدار من بيئة التشغيل.

ملاحظة

يبلغ حجم تنزيلات بيئات التشغيل عادةً 40 - 80 MB، وتُخزَّن في مجلد بيانات المشغّل، بمعزل عن أي تثبيت لـ Java على نظامك.

عرض بيئات التشغيل المثبّتة

افتح الإعدادات وانقر على إدارة بيئات التشغيل لعرض قائمة بجميع بيئات تشغيل Java المثبّتة، بما في ذلك إصدارها ومسارها وحزم التعديلات التي تستخدمها.

حذف بيئات التشغيل غير المستخدمة

إذا أزلت حزم تعديلات كانت تستخدم إصدارًا معيّنًا من Java، فيمكنك حذف بيئة التشغيل المقابلة لتحرير مساحة على القرص. اختر بيئة تشغيل في شاشة الإدارة وانقر على حذف.

تحذير

إذا حذفت بيئة تشغيل لا تزال حزمة تعديلات مثبّتة تحتاج إليها، فسيعيد المشغّل تنزيلها عند التشغيل التالي لتلك الحزمة.

استكشاف مشكلات بيئات التشغيل وإصلاحها

إذا فشل تشغيل حزمة تعديلات بسبب أخطاء متعلقة بـ Java، فجرّب ما يلي:

  1. افتح «إدارة بيئات التشغيل» واحذف بيئة التشغيل التي تستخدمها حزمة التعديلات المتأثرة.
  2. شغّل حزمة التعديلات مجددًا — سينزّل المشغّل نسخة جديدة.
  3. إذا استمرت المشكلة، فراجع استكشاف الأخطاء وإصلاحها للاطلاع على خطوات إضافية.
