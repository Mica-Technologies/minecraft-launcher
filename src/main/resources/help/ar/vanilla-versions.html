الإصدارات الأساسية

إلى جانب حزم تعديلات Forge، يستطيع المشغّل تثبيت إصدارات Minecraft الأساسية (دون تعديلات) وتشغيلها مباشرةً.

استعراض الإصدارات

تعرض شاشة الإصدارات الأساسية قائمة بإصدارات Minecraft الرسمية ولقطات Snapshot المتاحة. يظهر في كل إدخال رقم الإصدار وتاريخ إصداره. اختر إصدارًا لعرض تفاصيله.

التثبيت والتشغيل

  1. اختر إصدار Minecraft من القائمة.
  2. انقر على تثبيت لتنزيل عميل اللعبة والمكتبات والأصول الخاصة بهذا الإصدار.
  3. بعد التثبيت، انقر على العب للتشغيل. يتولّى المشغّل تلقائيًا التحقق من جميع الملفات وإعداد بيئة التشغيل.
ملاحظة

تستخدم الإصدارات الأساسية إعدادات الذاكرة وJVM نفسها المضبوطة في الإعدادات. إذا كان أداء إصدار ما ضعيفًا، فجرّب تعديل مقدار الذاكرة RAM المخصّصة أو إعداد JVM المسبق.

إدارة بيئات التشغيل

قد تتطلب إصدارات Minecraft المختلفة بيئات تشغيل Java مختلفة. يقوم المشغّل تلقائيًا بتنزيل بيئة التشغيل الصحيحة لكل إصدار وإدارتها — فعلى سبيل المثال، يتطلب Minecraft 1.17+ الإصدار Java 17 أو أحدث، بينما تستخدم الإصدارات الأقدم Java 8.

لا تحتاج إلى تثبيت Java يدويًا. راجع إدارة بيئات التشغيل لمزيد من التفاصيل حول كيفية التعامل مع بيئات التشغيل.

تلميح

الإصدارات الأساسية طريقة جيدة لاختبار ما إذا كان نظامك يلبّي المتطلبات الأساسية قبل تثبيت حزم التعديلات الأكبر.
