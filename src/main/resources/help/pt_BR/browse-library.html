Explorar

A tela Explorar é onde você instala e gerencia tudo. Aqui você pode instalar novos modpacks do manifesto público, instalar versões puras do Minecraft vanilla, instalar modpacks iniciais vazios de Forge / NeoForge / Fabric, editar os modpacks que já tem e desinstalar o que não quiser mais.

Cards & a barra de filtros

Cada entrada aparece como um card de destaque com logotipo, selo, nome, chips (loader / versão do Minecraft), uma linha de status e botões de ação. A barra de filtros no topo é como você restringe a visualização.

  • Pesquisar — busca de texto livre nos títulos dos cards. É atualizada enquanto você digita (com um pequeno atraso para não ficar refazendo o layout).
  • Tipo — Todos, Modpacks ou um dos catálogos de versões: Vanilla (Releases / Snapshots / Old Beta / Old Alpha) e versões de Forge / NeoForge / Fabric. Os filtros de versões de loader não estão incluídos em "Todos" de propósito — a lista combinada teria milhares de entradas e não é o que uma busca do tipo "mostrar tudo" pretende.
  • Status — Todos, Instalados ou Disponíveis. "Disponíveis" mostra o que você ainda não instalou; "Instalados" mostra o que já está no disco.
  • Ordenar — Padrão, Nome (A–Z / Z–A), Data de lançamento, Jogado pela última vez, Mais jogados, Atualizados recentemente. As ordenações que dependem do histórico de jogo / atualização (Jogado pela última vez, Mais jogados, Atualizados recentemente) mandam as entradas que não são modpacks para o final, em vez de misturá-las de forma confusa.

Modpacks instalados

Os cards de modpacks que já estão no disco mostram dois botões:

  • Desinstalar — pergunta se a pasta de instalação também deve ser excluída. "Desinstalar (manter arquivos)" preserva seus mundos, configurações e mods, mesmo que o launcher deixe de conhecer o modpack — útil se você pretende reinstalar o mesmo modpack mais tarde.
  • Editar — abre o Editor de modpacks no manifesto local do modpack. As alterações são gravadas no disco e valem a partir da próxima inicialização.
Dica

Clique com o botão direito no card de um modpack instalado para abrir o mesmo menu de contexto do menu principal: abrir a pasta do modpack, abrir a pasta de mods, criar um atalho na área de trabalho, ver as estatísticas de jogo e desinstalar.

Modpacks disponíveis

Os cards do manifesto público que você ainda não tem mostram um botão Instalar. Clicar nele baixa o manifesto, instala o modpack e move o card para o grupo de instalados na próxima atualização da lista. Você pode continuar usando os filtros enquanto uma instalação está em andamento — o card em andamento fica fixado no topo da grade até a instalação terminar.

Versões vanilla

O catálogo completo da Mojang de releases / snapshots / betas / alphas. Cada card instala exatamente essa versão do Minecraft como um modpack sintético vazio que você pode jogar direto do menu principal. Betas e alphas antigas também funcionam — o launcher baixa automaticamente o runtime Java adequado para cada versão.

Versões de Forge / NeoForge / Fabric

Os filtros de versões de loader mostram todas as versões anunciadas pelo serviço de versões de cada projeto: as promoções do Forge, os metadados Maven do NeoForge e a API meta do Fabric. Clicar em Instalar em uma delas grava um manifesto sintético de "modpack vazio" na sua pasta de configuração e o registra no launcher — assim, o resultado se comporta como qualquer outro modpack instalado:

  • aparece nos cards de destaque do menu principal;
  • pode ser editado no Editor de modpacks (para você adicionar mods e montar seu próprio modpack);
  • pode ser desinstalado como qualquer outro modpack;
  • usa o mesmo mecanismo de atualização automática de um modpack normal.
Observação

Os cards mostram o logotipo oficial de cada projeto quando o launcher já o tem em cache local. Na primeira visita a um filtro de loader, aparece um marcador de posição nas cores da marca enquanto os logotipos reais são baixados em segundo plano — depois de armazenados em cache, as visitas seguintes são instantâneas.

Adicionar por URL

O botão Adicionar por URL da barra inferior recebe uma URL direta para um manifesto installable.json hospedado e o instala da mesma forma que os cards de modpacks disponíveis. Use-o para modpacks distribuídos fora do manifesto público — cole o link, clique no botão e os metadados do manifesto são baixados e validados antes de a instalação começar.

Editor de modpacks

O botão Editor de modpacks da barra inferior abre o Editor de modpacks com um manifesto em branco para você montar um modpack novo do zero — defina o loader (Forge / NeoForge / Fabric / vanilla), a versão do Minecraft, a lista de mods etc. O Editor também pode ser aberto em um modpack existente pelo botão Editar do card dele.

Gerar manifesto de hospedagem

O botão Gerar manifesto de hospedagem da barra inferior cria um installable.json para o modpack que está aberto no editor, pronto para ser hospedado em qualquer servidor web ou serviço de compartilhamento de arquivos. Qualquer pessoa com a URL resultante pode instalar seu modpack por Adicionar por URL.

Paginação

Listas longas são paginadas. Use os botões Anterior / Próximo na barra de paginação (acima dos cards) para trocar de página e o menu suspenso Por página para definir o tamanho da página — 24, 48, 72 ou 96. O padrão de 48 cabe em uma página para a biblioteca instalada típica; aumentar para 96 mantém os filtros de versões de loader navegáveis em uma única página.
