Gerenciamento de runtimes

O Mica Minecraft Launcher gerencia os runtimes Java automaticamente, então você nunca precisa instalar nem configurar o Java por conta própria.

Por que os runtimes importam

O Minecraft e o Forge exigem versões específicas do Java para funcionar corretamente. Modpacks e versões do Minecraft diferentes podem precisar de runtimes Java diferentes:

  • Minecraft 1.16 e anteriores — Java 8
  • Minecraft 1.17 - 1.20 — Java 17
  • Minecraft 1.21+ — Java 21 ou posterior

O launcher detecta qual runtime cada modpack ou versão vanilla exige e o baixa automaticamente na primeira execução.

Downloads automáticos

Quando você inicia um modpack ou uma versão vanilla pela primeira vez, o launcher verifica se o runtime necessário já está instalado. Se não estiver, ele baixa a versão correta dos servidores de distribuição da Mojang ou da Liberica. É um download único por versão de runtime.

Observação

Os downloads de runtime costumam ter de 40 a 80 MB e ficam armazenados na pasta de dados do launcher, separados de qualquer instalação do Java no seu sistema.

Ver os runtimes instalados

Abra Configurações e clique em Gerenciar runtimes para ver uma lista de todos os runtimes Java instalados, com a versão, o caminho e quais modpacks os usam.

Excluir runtimes não usados

Se você removeu modpacks que usavam uma determinada versão do Java, pode excluir o runtime correspondente para liberar espaço em disco. Selecione um runtime na tela de gerenciamento e clique em Excluir.

Aviso

Excluir um runtime que ainda é necessário para um modpack instalado faz o launcher baixá-lo de novo na próxima vez que esse modpack for iniciado.

Solução de problemas de runtimes

Se um modpack não iniciar por causa de erros relacionados ao Java, tente o seguinte:

  1. Abra o Gerenciamento de runtimes e exclua o runtime usado pelo modpack afetado.
  2. Inicie o modpack de novo — o launcher vai baixar uma cópia nova.
  3. Se o problema continuar, veja Solução de problemas para mais etapas.
