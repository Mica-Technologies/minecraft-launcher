Primeiros passos

Boas-vindas ao Mica Minecraft Launcher — um launcher multiplataforma de modpacks de Minecraft Forge que facilita instalar, atualizar e jogar modpacks com um único clique.

Início rápido

  1. Faça login com sua conta da Microsoft. O launcher usa a autenticação oficial da Microsoft para verificar se você tem o Minecraft. Veja Login para mais detalhes.
  2. Selecione um modpack na lista do lado esquerdo da Tela principal. Se ainda não houver modpacks instalados, use Explorar para adicionar um.
  3. Clique em Jogar e o launcher vai baixar automaticamente todos os arquivos necessários, instalar a versão correta do Forge, verificar a integridade dos arquivos e iniciar o jogo.

O que o launcher faz por você

  • Baixa e atualiza os arquivos do modpack (mods, configurações, recursos)
  • Instala a versão correta do Forge para cada modpack
  • Gerencia os runtimes Java — não é preciso instalar um JDK manualmente
  • Verifica a integridade dos arquivos com checagens de hash SHA-1
  • Examina os arquivos baixados em busca de malware conhecido
