Referência de ações

Toda ação de modpack no launcher pode ser acessada por pelo menos um local principal, com uma cópia no menu de contexto para acesso rápido quando você já está olhando para um card. Esta página documenta onde cada ação fica, para que você não precise procurar.

Locais principais

LocalO que fica aqui
Cards de destaque do menu principal Botões principais Jogar + Site de cada modpack. Clicar no card abre a janela de detalhes.
Janela de detalhes do modpack O local mais completo de cada modpack: blocos de Ações rápidas (Abrir pasta / Mods / Configuração / Capturas de tela / Pacotes de recursos / Shaders / Atalho na área de trabalho / Copiar link de convite / Exportar como ZIP), Estatísticas, Histórico de atualizações, Mundos, grade de Capturas de tela, listas de Shader packs / Pacotes de recursos, Histórico de travamentos, seção Avançado (verificação) e os botões de ação Jogar / Site.
Cards da tela Explorar Instalar / Desinstalar / Editar conforme o tipo da entrada (modpack / vanilla / versão de loader).
Menu de contexto (clique com o botão direito) Acesso rápido às Ações rápidas mais comuns a partir de qualquer card de modpack, sem abrir a janela de detalhes. Usa exatamente as mesmas funções da janela.
Configurações Preferências gerais do launcher: conta, jogo / runtime, aparência, avançado, rede, segurança, sistema, Discord, RGB, Sobre.

Dica

Quase toda ação de um modpack tem um atalho no menu de contexto do card do modpack. Se você se pega abrindo a janela de detalhes repetidamente só para chegar à mesma pasta, experimente clicar com o botão direito no card no menu principal — os mesmos itens ficam a um clique de distância.
