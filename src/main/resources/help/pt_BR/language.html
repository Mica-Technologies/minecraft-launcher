Idioma e localização

O Mica Minecraft Launcher exibe sua interface em 17 idiomas e escolhe o certo automaticamente na primeira execução. Você também pode substituir o idioma detectado a qualquer momento em Configurações.

Como o launcher escolhe um idioma

Sempre que você inicia o launcher, ele define o idioma ativo nesta ordem:

  1. A sua escolha salva, se você tiver definido uma em Configurações → Aparência → Idioma. Ela sempre tem prioridade.
  2. O idioma do seu sistema operacional, detectado pela localidade padrão da JVM. No Windows, é a sua configuração de Região / Idioma; no macOS, é Ajustes do Sistema → Idioma e Região; no Linux, é o ambiente LANG / LC_*.
  3. Inglês (Estados Unidos) como alternativa se a plataforma informar uma localidade sem idioma (por exemplo, POSIX ou C) ou se o idioma do seu sistema não estiver entre os 17 para os quais oferecemos tradução.
A mudança de idioma vale após reiniciar

Trocar o idioma em Configurações atualiza a preferência imediatamente, mas as telas que já estão abertas continuam no idioma anterior até o launcher ser reiniciado. A própria página de Configurações avisa sobre isso quando você muda o menu suspenso.

Definir um idioma manualmente

  1. Abra Configurações pela barra de navegação (ou pressione Ctrl+, / Cmd+,).
  2. Vá para a aba Aparência.
  3. Escolha um idioma no menu suspenso Idioma. A primeira opção ("Usar o idioma do sistema") restaura a detecção automática descrita acima e mostra entre parênteses qual idioma o sistema escolheria.
  4. Clique em Salvar. Reinicie o launcher para ver o novo idioma aplicado em todas as telas.

Idiomas compatíveis

O launcher inclui traduções para os 17 idiomas mais falados do mundo, além do inglês:

  • Árabe (عربي)
  • Chinês simplificado (简体中文)
  • Chinês tradicional (繁體中文)
  • Holandês (Nederlands)
  • Inglês (idioma de origem)
  • Francês (Français)
  • Alemão (Deutsch)
  • Hindi (हिंदी)
  • Italiano (Italiano)
  • Japonês (日本語)
  • Coreano (한국어)
  • Polonês (Polski)
  • Português do Brasil (Português do Brasil)
  • Russo (Русский)
  • Espanhol (Español)
  • Sueco (Svenska)
  • Turco (Türkçe)

Cada idioma é identificado por sua tag BCP-47 (por exemplo, fr-FR, pt-BR, zh-CN). A lista fica em SupportedLocales.ENTRIES no código-fonte do launcher; os arquivos de propriedades ficam ao lado, como DisplayStrings_<tag>.properties, em src/main/resources/lang/.

Qualidade da tradução & relato de problemas

As traduções para idiomas além do inglês são geradas por um script que chama o Google Tradutor sobre o pacote de origem em inglês e depois trata os marcadores de parâmetros para que itens como {0} passem intactos pela tradução. O resultado é bom, mas não perfeito — em especial, rótulos curtos da interface (botões de uma palavra, substantivos isolados) às vezes perdem o contexto que tinham em inglês.

Se você encontrar uma tradução ruim, o melhor caminho é abrir uma issue no GitHub com o nome da chave (por exemplo, browse.filter.type.label), sua localidade, o texto atual e uma correção sugerida. Correções feitas à mão sobrevivem à próxima geração porque o script, por padrão, só preenche as chaves que faltam.

Adicionar um novo idioma

Se o seu idioma não está na lista acima e você quer contribuir com uma tradução, o caminho é este:

  1. Adicione uma nova entrada em SupportedLocales.ENTRIES (Java) e em TARGET_LOCALES no tools/i18n/translate-locales.js (Node).
  2. Execute cd tools/i18n && npm run translate — o script vai gerar o DisplayStrings_<tag>.properties inicial a partir da origem em inglês.
  3. Revise o arquivo gerado, corrija à mão o que soar estranho e abra um pull request.

O script tools/i18n/translate-locales.js é incremental: executá-lo de novo só traduz as chaves que ainda não existem no arquivo de destino, então as correções feitas à mão são preservadas a cada atualização do launcher.
