Editor de modpacks

O editor de modpacks é uma ferramenta integrada para criar e editar os arquivos JSON de definição de modpacks. Ele oferece uma interface estruturada com validação, pesquisa integrada e acompanhamento de diferenças.

Barra de ferramentas

  • Novo — cria uma definição de modpack em branco a partir de um modelo.
  • Abrir arquivo — carrega uma definição JSON existente do disco.
  • Abrir URL — busca e carrega uma definição de uma URL remota.
  • Salvar — grava a definição atual em um arquivo local.
  • Validar — verifica se a definição tem erros (campos ausentes, URLs inválidas, hashes divergentes).
  • Comparar — compara o estado atual com a última versão salva para mostrar o que mudou.

Campos de metadados

A seção superior contém as informações principais do modpack: nome, versão, descrição, autor, versão do Minecraft e versão do Forge. O seletor de versão do Forge permite procurar as builds do Forge disponíveis para a versão do Minecraft selecionada.

Abas de arquivos

Os arquivos ficam organizados em abas por categoria:

ModsJARs de mods do Forge colocados na pasta mods/.
ConfiguraçõesArquivos de configuração dos mods, colocados em config/.
RecursosPacotes de recursos e outros recursos.
ShadersShader packs para OptiFine ou Iris.
Arquivos iniciaisArquivos copiados só na primeira instalação (por exemplo, um options.txt padrão).

Cada arquivo inclui uma URL de download e um hash SHA-1. O editor pode calcular os hashes automaticamente baixando o arquivo e computando a soma de verificação.

Pesquisa no Modrinth

Use a pesquisa integrada do Modrinth para encontrar mods pelo nome. Selecione um resultado para preencher automaticamente a URL de download e o hash com a versão correta.

Incremento de versão

Os botões de incremento de versão aumentam o número da versão do modpack, facilitando a publicação de atualizações que o launcher detecta automaticamente.

Verificação de URLs

O editor pode verificar se todas as URLs de download dos arquivos estão acessíveis, ajudando você a encontrar links quebrados antes de publicar.

Dica

Use Validar antes de salvar para encontrar problemas cedo. O validador verifica os campos obrigatórios, se as URLs são válidas e se os hashes estão no formato correto.
