Versões vanilla

Além dos modpacks de Forge, o launcher pode instalar e jogar diretamente versões do Minecraft vanilla (sem mods).

Navegar pelas versões

A tela de versões vanilla mostra uma lista das releases e snapshots do Minecraft disponíveis. Cada entrada mostra o número da versão e a data de lançamento. Selecione uma versão para ver os detalhes dela.

Instalar e iniciar

  1. Selecione uma versão do Minecraft na lista.
  2. Clique em Instalar para baixar o cliente do jogo, as bibliotecas e os recursos dessa versão.
  3. Depois de instalada, clique em Jogar para iniciar. O launcher cuida automaticamente de toda a verificação de arquivos e da configuração do runtime.
Observação

As versões vanilla usam as mesmas configurações de memória e da JVM definidas em Configurações. Se uma versão rodar mal, tente ajustar a alocação de RAM ou a predefinição da JVM.

Gerenciamento de runtimes

Versões diferentes do Minecraft podem exigir runtimes Java diferentes. O launcher baixa e gerencia automaticamente o runtime correto para cada versão — por exemplo, o Minecraft 1.17+ exige o Java 17 ou posterior, enquanto as versões mais antigas usam o Java 8.

Você não precisa instalar o Java manualmente. Veja Gerenciamento de runtimes para mais detalhes sobre como os runtimes são tratados.

Dica

As versões vanilla são uma boa forma de testar se o seu sistema atende aos requisitos básicos antes de instalar modpacks maiores.
