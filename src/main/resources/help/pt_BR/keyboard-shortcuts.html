Atalhos de teclado

O launcher oferece um pequeno conjunto de atalhos de teclado para as ações que você mais usa. No macOS o modificador é ⌘ Command; no Windows e no Linux é Ctrl. Os atalhos abaixo mostram o modificador como ⌘/Ctrl para cobrir os dois casos.

Navegação global

Disponíveis em todas as telas, exceto Login, Progresso da inicialização e a janela do console do jogo — essas telas não aceitam atalhos de navegação de propósito, para que você não saia sem querer no meio de um processo.

AtalhoAção
⌘/Ctrl + ,Abrir Configurações (convenção universal)
⌘/Ctrl + LAbrir a tela Explorar (instalar & gerenciar)
⌘/Ctrl + EAbrir o Editor de modpacks
⌘/Ctrl + Shift + MVoltar ao menu principal (Início)
F1 / ⌘/Ctrl + ?Abrir a janela de Ajuda no tópico da tela atual
Por que Cmd+Shift+M para Início?

O simples ⌘ + M é o atalho de sistema "Minimizar janela" do macOS — o launcher evita substituí-lo. ⌘/Ctrl + Shift + M evita o conflito em todas as plataformas.

Dica

O botão de ajuda (?) no canto superior direito de cada tela é a forma de abrir esta página ou qualquer outro tópico de ajuda com o mouse. Passe o cursor sobre o ícone e você verá a mesma dica que o leitor de tela anuncia.
