Aktionsreferenz

Jede Modpack-Aktion im Launcher ist über mindestens eine zentrale Stelle erreichbar, dazu gibt es ein Duplikat im Kontextmenü für den schnellen Zugriff, wenn Sie ohnehin gerade eine Karte vor sich haben. Diese Seite dokumentiert, wo sich jede Aktion befindet, damit Sie nicht suchen müssen.

Zentrale Stellen

StelleWas sich hier befindet
Hero-Karten im Hauptmenü Primäre Schaltflächen Spielen + Website pro Modpack. Ein Klick öffnet das Detailfenster.
Modpack-Detailfenster Die umfangreichste Ansicht pro Modpack: Kacheln unter Schnellaktionen (Ordner öffnen / Mods / Konfiguration / Screenshots / Ressourcenpakete / Shader / Desktop-Verknüpfung / Einladungslink kopieren / Als ZIP exportieren), Statistiken, Update-Verlauf, Welten, Screenshot-Raster, Listen für Shaderpacks / Ressourcenpakete, Absturzverlauf, Abschnitt Erweitert (Überprüfung) sowie die Aktionsschaltflächen Spielen / Website.
Karten im Bildschirm Durchsuchen Installieren / Deinstallieren / Bearbeiten je nach Art des Eintrags (Modpack / Vanilla / Loader-Version).
Kontextmenü (Rechtsklick) Schneller Zugriff auf die gängigen Schnellaktionen von jeder Modpack-Karte aus, ohne das Detailfenster zu öffnen. Verwendet dieselben Funktionen wie das Detailfenster.
Einstellungen Launcher-weite Einstellungen: Konto, Spiel / Laufzeitumgebung, Darstellung, Erweitert, Netzwerk, Sicherheit, System, Discord, RGB, Über.

Tipp

Für fast jede Aktion pro Modpack gibt es eine Abkürzung im Kontextmenü der Modpack-Karte. Wenn Sie sich immer wieder durch das Detailfenster klicken, nur um denselben Ordner zu erreichen, klicken Sie stattdessen mit der rechten Maustaste auf die Karte im Hauptmenü — dieselben Einträge sind dort nur einen Klick entfernt.
