Vanilla-Versionen

Neben Forge-Modpacks kann der Launcher auch Vanilla-Versionen (ohne Mods) von Minecraft direkt installieren und spielen.

Versionen durchsuchen

Der Bildschirm für Vanilla-Versionen zeigt eine Liste verfügbarer Minecraft-Releases und Snapshots. Jeder Eintrag zeigt die Versionsnummer und das Veröffentlichungsdatum. Wählen Sie eine Version aus, um ihre Details zu sehen.

Installieren und Starten

  1. Wählen Sie eine Minecraft-Version aus der Liste aus.
  2. Klicken Sie auf Installieren, um den Spiel-Client, die Bibliotheken und die Assets für diese Version herunterzuladen.
  3. Klicken Sie nach der Installation auf Spielen, um das Spiel zu starten. Der Launcher übernimmt die gesamte Dateiüberprüfung und die Einrichtung der Laufzeitumgebung automatisch.
Hinweis

Vanilla-Versionen verwenden dieselben Arbeitsspeicher- und JVM-Einstellungen, die in den Einstellungen konfiguriert sind. Wenn eine Version schlecht läuft, passen Sie Ihre RAM-Zuweisung oder JVM-Voreinstellung an.

Laufzeitverwaltung

Verschiedene Minecraft-Versionen benötigen möglicherweise unterschiedliche Java-Laufzeitumgebungen. Der Launcher lädt die richtige Laufzeitumgebung für jede Version automatisch herunter und verwaltet sie — zum Beispiel benötigt Minecraft 1.17+ Java 17 oder neuer, während ältere Versionen Java 8 verwenden.

Sie müssen Java nicht manuell installieren. Weitere Details dazu, wie Laufzeitumgebungen gehandhabt werden, finden Sie unter Laufzeitverwaltung.

Tipp

Vanilla-Versionen eignen sich gut, um zu testen, ob Ihr System die grundlegenden Anforderungen erfüllt, bevor Sie größere Modpacks installieren.
