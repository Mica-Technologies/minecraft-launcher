Hauptbildschirm

Der Hauptbildschirm ist nach der Anmeldung Ihre Ausgangsbasis. Von hier aus können Sie installierte Modpacks durchsuchen, das Spiel starten und zu den Einstellungen oder zur Modpack-Verwaltung wechseln.

Modpack-Liste

Der linke Bereich zeigt alle installierten Modpacks. Jeder Eintrag zeigt den Namen des Modpacks und darunter den Zeitpunkt, an dem es zuletzt gespielt wurde. Wählen Sie ein Modpack aus, um seine Details im mittleren Bereich anzuzeigen.

Wenn für ein Modpack eine neuere Version verfügbar ist, erscheint neben seinem Namen ein grünes Abzeichen UPDATE. Das Update wird automatisch angewendet, wenn Sie das nächste Mal auf Spielen klicken.

Tipp

Klicken Sie mit der rechten Maustaste auf ein beliebiges Modpack in der Liste, um ein Kontextmenü mit weiteren Optionen zu öffnen:

  • Installationsordner öffnen — die lokalen Dateien auf dem Datenträger durchsuchen
  • Mods-Ordner öffnen — direkt zum Mods-Verzeichnis springen
  • Desktop-Verknüpfung erstellen — dieses Modpack direkt vom Desktop aus starten
  • Spielstatistik — Gesamtspielzeit und Sitzungsverlauf anzeigen

Mittlerer Bereich

Wenn Sie ein Modpack auswählen, werden im mittleren Bereich seine Beschreibung und ein Hintergrundbild angezeigt. Unten erscheinen zwei Hauptschaltflächen:

  • Spielen — lädt fehlende oder aktualisierte Dateien herunter und startet dann das Spiel.
  • Website — öffnet die Homepage des Modpacks in Ihrem Browser (sofern eine angegeben ist).

Navigation

  • Einstellungen — öffnet die Launcher-Einstellungen (Arbeitsspeicher, Design, JVM-Flags und mehr).
  • Durchsuchen — öffnet den Bildschirm zum Installieren & Verwalten von Modpacks, Vanilla-Versionen und Starter-Modpacks für Loader-Versionen.
Hinweis

Wenn Sie keine Modpacks installiert haben, fordert Sie der mittlere Bereich auf, eines über Durchsuchen hinzuzufügen.
