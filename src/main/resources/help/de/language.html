Sprache & Lokalisierung

Der Mica Minecraft Launcher stellt seine Oberfläche in 17 Sprachen dar und wählt beim ersten Start automatisch die passende aus. Sie können die erkannte Sprache außerdem jederzeit in den Einstellungen überschreiben.

Wie der Launcher eine Sprache auswählt

Bei jedem Start ermittelt der Launcher die aktive Sprache in dieser Reihenfolge:

  1. Ihre gespeicherte Auswahl, sofern Sie eine unter Einstellungen → Darstellung → Sprache festgelegt haben. Diese hat immer Vorrang.
  2. Die Sprache Ihres Betriebssystems, erkannt über das Standard-Gebietsschema der JVM. Unter Windows ist dies Ihre Einstellung für Region / Sprache; unter macOS Systemeinstellungen → Sprache & Region; unter Linux die Umgebungsvariablen LANG / LC_*.
  3. Englisch (Vereinigte Staaten) als Rückfalloption, wenn die Plattform ein Gebietsschema ohne Sprache meldet (z. B. POSIX oder C) oder wenn Ihre Betriebssystemsprache nicht zu den 17 Sprachen gehört, für die wir Übersetzungen ausliefern.
Eine Sprachänderung wird nach einem Neustart wirksam

Wenn Sie die Auswahl in den Einstellungen ändern, wird die Einstellung sofort gespeichert, aber bereits angezeigte Bildschirme zeigen weiterhin die vorherige Sprache, bis der Launcher neu gestartet wird. Die Einstellungsseite selbst weist Sie darauf hin, wenn Sie das Dropdown ändern.

Eine Sprache manuell festlegen

  1. Öffnen Sie die Einstellungen über die Navigationsleiste (oder drücken Sie Ctrl+, / Cmd+,).
  2. Wechseln Sie zum Tab Darstellung.
  3. Wählen Sie im Dropdown Sprache eine Sprache aus. Der erste Eintrag („Sprache des Betriebssystems verwenden“) stellt die oben beschriebene automatische Erkennung wieder her und zeigt in Klammern an, welche Sprache das Betriebssystem ergeben würde.
  4. Klicken Sie auf Speichern. Starten Sie den Launcher neu, damit die neue Sprache auf allen Bildschirmen angewendet wird.

Unterstützte Sprachen

Der Launcher liefert Übersetzungen für die 17 meistgesprochenen Sprachen der Welt sowie Englisch aus:

  • Arabisch (عربي)
  • Chinesisch, vereinfacht (简体中文)
  • Chinesisch, traditionell (繁體中文)
  • Niederländisch (Nederlands)
  • Englisch (Ausgangssprache)
  • Französisch (Français)
  • Deutsch (Deutsch)
  • Hindi (हिंदी)
  • Italienisch (Italiano)
  • Japanisch (日本語)
  • Koreanisch (한국어)
  • Polnisch (Polski)
  • Portugiesisch, brasilianisch (Português do Brasil)
  • Russisch (Русский)
  • Spanisch (Español)
  • Schwedisch (Svenska)
  • Türkisch (Türkçe)

Jede Sprache wird durch ihr BCP-47-Tag identifiziert (z. B. fr-FR, pt-BR, zh-CN). Die Liste befindet sich in SupportedLocales.ENTRIES im Quellcode des Launchers; die Property-Dateien liegen daneben als DisplayStrings_<tag>.properties unter src/main/resources/lang/.

Übersetzungsqualität & Melden von Problemen

Übersetzungen für andere Sprachen als Englisch werden von einem Skript erzeugt, das Google Translate auf das englische Quell-Bundle anwendet und anschließend Parameter-Platzhalter nachbearbeitet, sodass Dinge wie {0} die Übersetzung unverändert überstehen. Das Ergebnis ist gut, aber nicht perfekt — insbesondere kurze UI-Beschriftungen (Schaltflächen aus einem Wort, einzelne Substantive) verlieren manchmal den Kontext, den sie im Englischen hatten.

Wenn Sie eine schlechte Übersetzung entdecken, eröffnen Sie am besten ein Issue auf GitHub mit dem Schlüsselnamen (z. B. browse.filter.type.label), Ihrem Gebietsschema, der aktuellen Darstellung und einem Korrekturvorschlag. Von Hand bearbeitete Korrekturen bleiben bei der nächsten Neugenerierung erhalten, weil das Skript standardmäßig nur fehlende Schlüssel ergänzt.

Eine neue Sprache hinzufügen

Wenn Ihre Sprache nicht in der obigen Liste steht und Sie eine Übersetzung beisteuern möchten, gehen Sie so vor:

  1. Fügen Sie einen neuen Eintrag zu SupportedLocales.ENTRIES (Java) und TARGET_LOCALES in tools/i18n/translate-locales.js (Node) hinzu.
  2. Führen Sie cd tools/i18n && npm run translate aus — das Skript erzeugt die erste Fassung von DisplayStrings_<tag>.properties aus der englischen Quelle.
  3. Prüfen Sie die erzeugte Datei, korrigieren Sie von Hand alles, was sich seltsam liest, und eröffnen Sie dann einen Pull Request.

Das Skript tools/i18n/translate-locales.js arbeitet inkrementell: Bei einem erneuten Ausführen werden nur Schlüssel übersetzt, die in der Zieldatei noch nicht vorhanden sind, sodass Korrekturen von Hand bei jedem folgenden Launcher-Update erhalten bleiben.
