Laufzeitverwaltung

Der Mica Minecraft Launcher verwaltet Java-Laufzeitumgebungen automatisch, sodass Sie Java nie selbst installieren oder konfigurieren müssen.

Warum Laufzeitumgebungen wichtig sind

Minecraft und Forge benötigen bestimmte Java-Versionen, um korrekt zu laufen. Verschiedene Modpacks und Minecraft-Versionen benötigen möglicherweise unterschiedliche Java-Laufzeitumgebungen:

  • Minecraft 1.16 und älter — Java 8
  • Minecraft 1.17 - 1.20 — Java 17
  • Minecraft 1.21+ — Java 21 oder neuer

Der Launcher erkennt, welche Laufzeitumgebung jedes Modpack bzw. jede Vanilla-Version benötigt, und lädt sie beim ersten Start automatisch herunter.

Automatische Downloads

Wenn Sie ein Modpack oder eine Vanilla-Version zum ersten Mal starten, prüft der Launcher, ob die benötigte Laufzeitumgebung bereits installiert ist. Falls nicht, lädt er die richtige Version von den Distributionsservern von Mojang oder Liberica herunter. Dieser Download erfolgt pro Laufzeitversion nur einmal.

Hinweis

Laufzeit-Downloads sind in der Regel 40 - 80 MB groß und werden im Datenverzeichnis des Launchers gespeichert, getrennt von jeder Java-Installation auf Ihrem System.

Installierte Laufzeitumgebungen anzeigen

Öffnen Sie die Einstellungen und klicken Sie auf Laufzeitumgebungen verwalten, um eine Liste aller installierten Java-Laufzeitumgebungen zu sehen, einschließlich Version, Pfad und der Modpacks, die sie verwenden.

Nicht verwendete Laufzeitumgebungen löschen

Wenn Sie Modpacks entfernt haben, die eine bestimmte Java-Version verwendet haben, können Sie die zugehörige Laufzeitumgebung löschen, um Speicherplatz freizugeben. Wählen Sie im Verwaltungsbildschirm eine Laufzeitumgebung aus und klicken Sie auf Löschen.

Warnung

Wenn Sie eine Laufzeitumgebung löschen, die noch von einem installierten Modpack benötigt wird, lädt der Launcher sie beim nächsten Start dieses Modpacks erneut herunter.

Fehlerbehebung bei Laufzeitumgebungen

Wenn ein Modpack mit Java-bezogenen Fehlern nicht startet, versuchen Sie Folgendes:

  1. Öffnen Sie Laufzeitumgebungen verwalten und löschen Sie die Laufzeitumgebung, die das betroffene Modpack verwendet.
  2. Starten Sie das Modpack erneut — der Launcher lädt eine frische Kopie herunter.
  3. Wenn das Problem weiterhin besteht, finden Sie unter Fehlerbehebung weitere Schritte.
