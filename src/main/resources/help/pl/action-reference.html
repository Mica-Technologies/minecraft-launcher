Opis akcji

Każda akcja dotycząca modpacka jest dostępna w launcherze z co najmniej jednego głównego miejsca, a dodatkowo z menu kontekstowego, gdy masz już kartę przed oczami. Ta strona opisuje, gdzie znajduje się każda akcja, abyś nie musiał jej szukać.

Główne miejsca

MiejsceCo tu znajdziesz
Duże karty w menu głównym Główne przyciski Graj i Strona internetowa dla każdego modpacka. Kliknięcie karty otwiera okno szczegółów.
Okno szczegółów modpacka Najbogatsze miejsce dla pojedynczego modpacka: kafelki Szybkie akcje (Otwórz folder / Mody / Konfiguracja / Zrzuty ekranu / Paczki zasobów / Shadery / Skrót na pulpicie / Kopiuj link zaproszenia / Eksportuj jako ZIP), Statystyki, Historia aktualizacji, Światy, siatka Zrzuty ekranu, listy Paczki shaderów / Paczki zasobów, Historia awarii, sekcja Zaawansowane (weryfikacja) oraz przyciski akcji Graj / Strona internetowa.
Karty na ekranie Przeglądaj Zainstaluj / Odinstaluj / Edytuj w zależności od rodzaju pozycji (modpack / vanilla / wersja loadera).
Menu kontekstowe (prawy przycisk myszy) Szybki dostęp do typowych Szybkich akcji z dowolnej karty modpacka bez otwierania okna szczegółów. Korzysta z tych samych procedur co okno szczegółów.
Ustawienia Preferencje całego launchera: Konto, Gra / środowisko wykonawcze, Wygląd, Zaawansowane, Sieć, Bezpieczeństwo, System, Discord, RGB, O programie.

Wskazówka

Niemal każda akcja dotycząca modpacka ma skrót w menu kontekstowym jego karty (prawy przycisk myszy). Jeśli wielokrotnie przechodzisz przez okno szczegółów tylko po to, by dostać się do tego samego folderu, kliknij kartę w menu głównym prawym przyciskiem myszy — te same pozycje są tam o jedno kliknięcie.
