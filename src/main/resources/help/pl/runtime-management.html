Zarządzanie środowiskami wykonawczymi

Mica Minecraft Launcher automatycznie zarządza środowiskami wykonawczymi Java, więc nigdy nie musisz samodzielnie instalować ani konfigurować Javy.

Dlaczego środowiska wykonawcze są ważne

Minecraft i Forge wymagają do poprawnego działania określonych wersji Javy. Różne modpacki i wersje Minecrafta mogą potrzebować różnych środowisk wykonawczych Java:

  • Minecraft 1.16 i starsze — Java 8
  • Minecraft 1.17 - 1.20 — Java 17
  • Minecraft 1.21+ — Java 21 lub nowsza

Launcher wykrywa, jakiego środowiska wykonawczego wymaga każdy modpack lub wersja vanilla, i pobiera je automatycznie przy pierwszym uruchomieniu.

Automatyczne pobieranie

Gdy uruchamiasz modpack lub wersję vanilla po raz pierwszy, launcher sprawdza, czy wymagane środowisko wykonawcze jest już zainstalowane. Jeśli nie, pobiera właściwą wersję z serwerów dystrybucyjnych Mojang lub Liberica. Każda wersja środowiska wykonawczego jest pobierana tylko raz.

Uwaga

Pobierane środowiska wykonawcze zajmują zwykle 40 - 80 MB i są przechowywane w katalogu danych launchera, niezależnie od jakiejkolwiek instalacji Javy w Twoim systemie.

Przeglądanie zainstalowanych środowisk wykonawczych

Otwórz Ustawienia i kliknij Zarządzaj środowiskami wykonawczymi, aby zobaczyć listę wszystkich zainstalowanych środowisk wykonawczych Java wraz z ich wersją, ścieżką i modpackami, które z nich korzystają.

Usuwanie nieużywanych środowisk wykonawczych

Jeśli usunąłeś modpacki, które korzystały z określonej wersji Javy, możesz usunąć odpowiednie środowisko wykonawcze, aby zwolnić miejsce na dysku. Wybierz środowisko wykonawcze na ekranie zarządzania i kliknij Usuń.

Ostrzeżenie

Usunięcie środowiska wykonawczego, którego nadal potrzebuje zainstalowany modpack, sprawi, że launcher pobierze je ponownie przy następnym uruchomieniu tego modpacka.

Rozwiązywanie problemów ze środowiskami wykonawczymi

Jeśli modpack nie uruchamia się z powodu błędów związanych z Javą, spróbuj wykonać następujące kroki:

  1. Otwórz Zarządzanie środowiskami wykonawczymi i usuń środowisko wykonawcze używane przez problematyczny modpack.
  2. Uruchom modpack ponownie — launcher pobierze świeżą kopię.
  3. Jeśli problem nie ustąpi, zobacz Rozwiązywanie problemów, aby poznać dodatkowe kroki.
