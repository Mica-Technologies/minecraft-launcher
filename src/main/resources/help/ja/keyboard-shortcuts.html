キーボード ショートカット

ランチャーには、よく使う操作のためのキーボードショートカットがいくつか用意されています。 修飾キーは macOS では ⌘ Command、Windows と Linux では Ctrl です。 以下のショートカットでは、両方を表すために修飾キーを ⌘/Ctrl と表記しています。

全体のナビゲーション

ログイン、起動の進行状況、ゲーム内コンソールのウィンドウを除くすべての画面で使用できます。 これらの画面では、操作の途中で誤って別の画面に移動しないよう、あえてナビゲーションの ショートカットを受け付けません。

ショートカット操作
⌘/Ctrl + ,設定を開く（一般的な慣例）
⌘/Ctrl + Lブラウズ画面を開く（インストールと管理）
⌘/Ctrl + EMODパックエディターを開く
⌘/Ctrl + Shift + Mメインメニュー（ホーム）に戻る
F1 / ⌘/Ctrl + ?現在の画面のトピックでヘルプウィンドウを開く
ホームが Cmd+Shift+M なのはなぜ？

単独の ⌘ + M は macOS の「ウィンドウをしまう」システムショートカットであり、 ランチャーはこれを上書きしないようにしています。⌘/Ctrl + Shift + M なら、 どのプラットフォームでも競合を避けられます。

システムメニューバー（macOS）

macOS のシステムメニューバーでは、さらに次の操作も使えます:

ショートカット操作
⌘ + RMODパックの一覧を更新する（ブラウズメニュー → パック一覧を更新）

メインメニュー

ショートカット操作
Enter最後に選択した MODパックをプレイする
F5利用可能な MODパックを更新する（ナビゲーションバーの更新アイコンと同じ）
⌘/Ctrl + F検索欄に移動する

ブラウズ

ショートカット操作
⌘/Ctrl + F検索欄に移動する

MODパックエディター

ショートカット操作
⌘/Ctrl + S開いているマニフェストを保存する
⌘/Ctrl + N新しいマニフェストを作成する

MODパックの詳細画面

ショートカット操作
Esc詳細画面を閉じる
ヒント

どの画面にも右上にあるヘルプボタン（?）は、このページや他のヘルプトピックを クリックで開くための方法です。アイコンにマウスを重ねると、スクリーンリーダーが読み上げるものと 同じツールチップが表示されます。
