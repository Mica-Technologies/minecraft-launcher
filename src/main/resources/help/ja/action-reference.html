アクション リファレンス

ランチャーの MODパック操作は、どれも少なくとも 1 つの正規の画面から実行できます。さらに、 カードを見ているときにすばやく使えるよう、同じ操作が右クリックメニューにも用意されています。 このページでは、各操作がどこにあるかをまとめているので、探し回る必要はありません。

正規の操作画面

画面ここでできること
メインメニューのヒーローカード パックごとの主要な プレイ ボタンと ウェブサイト ボタン。 カードをクリックすると 詳細画面 が開きます。
MODパックの詳細画面 パックごとの操作が最も充実した画面です。クイックアクションのタイル （フォルダーを開く / MOD / 設定ファイル / スクリーンショット / リソースパック / シェーダー / デスクトップショートカット / 招待リンクをコピー / ZIP としてエクスポート）、統計、更新ログ、 ワールド、スクリーンショットのグリッド、シェーダーパック / リソースパックの一覧、クラッシュ履歴、 詳細セクション（検証）、そしてプレイ / ウェブサイトのボタンがあります。
ブラウズ画面のカード 項目の種類（MODパック / バニラ / ローダーのバージョン）に応じて インストール / アンインストール / 編集 が表示されます。
右クリックメニュー 詳細画面を開かなくても、任意のパックカードからよく使うクイックアクションにすばやく アクセスできます。処理はすべて詳細画面と共通です。
設定 ランチャー全体の設定: アカウント、ゲーム / ランタイム、外観、詳細、 ネットワーク、セキュリティ、システム、Discord、RGB、情報。

ヒント

パックごとの操作のほとんどは、パックのカードの右クリックメニューからも実行できます。 同じフォルダーを開くために何度も詳細画面を経由している場合は、メインメニューでカードを 右クリックしてみてください。同じ項目がワンクリックで使えます。
