設定

設定画面では、メモリの割り当て、外観、JVM の動作、ネットワークの構成などを カスタマイズできます。変更は自動で保存されます。

ゲームのメモリ

最小 RAMゲームの JVM に割り当てる初期ヒープサイズです。MODパックで特に指定がない限り、通常は既定値（512 MB）のままにしてください。
最大 RAMゲームが使用できるメモリの上限です。ほとんどの MODパックは 4～8 GB で最もよく動作します。システムに余裕がある以上に割り当てると、動作が不安定になることがあります。
ヒント

目安として、最大 RAM はシステムの合計メモリの半分以下に設定してください。 たとえば 16 GB のマシンなら、6～8 GB が妥当な上限です。

テーマ

Automatic（自動）オペレーティングシステムのライト / ダークモードの設定に従います。
Dark（ダーク）暗い背景に明るい文字 — 目に優しい配色です。
Light（ライト）明るい背景に暗い文字の、従来の配色です。
Blue + Gray寒色系のアクセントテーマです。
Orange + Purple暖色系のアクセントテーマです。

詳細オプション

デバッグモード問題の診断のため、ランチャーのコンソールに詳細なログを出力します。
ウィンドウのサイズ変更ランチャーのウィンドウを既定のサイズを超えて自由にサイズ変更できるようにします。
Discord 連携現在の MODパックを Discord Rich Presence のステータスとして表示します。
詳細ログセッション後の分析のため、詳しいログファイルをディスクに書き込みます。
ゲーム内コンソールMinecraft と並んで ゲームコンソール のウィンドウを開き、出力をリアルタイムで表示します。

JVM プリセット

ゲームの起動コマンドに追加される、あらかじめ設定された JVM フラグのセットです。各プリセットの役割、 追加するとよいカスタムフラグ、プリセットの選択と RAM の割り当ての関係について詳しくは、 JVM プリセット を参照してください。

Performance (Aikar's Flags)おすすめ。 Minecraft コミュニティで広く使われている、最適化されたガベージコレクションのフラグです。ほとんどの MODパックで全体的に最も良いパフォーマンスが得られます。
Low MemoryRAM が限られたシステム向けの控えめなフラグです。スループットを多少犠牲にして GC のオーバーヘッドを減らします。
DebugGC ログを含む JVM のデバッグ出力を有効にします。クラッシュやパフォーマンスの問題の診断に役立ちます。
None追加のフラグなし — JVM の既定値を使用します。内容を理解している場合や、MODパックが必要とする場合にのみ使用してください。

ネットワーク / プロキシ

ネットワークでプロキシが必要な場合（企業や学校のネットワークでよくあります）に設定します。

HTTP プロキシ標準的な Web プロキシです。ネットワーク管理者から提供されたホストとポートを入力してください。
SOCKS プロキシより低いレイヤーのプロキシプロトコルです。ネットワークで特に SOCKS が必要な場合に使用してください。
メモ

ほとんどのユーザーはプロキシ設定を空欄のままで問題ありません。制限のあるネットワークで ダウンロードや認証が失敗する場合にのみ設定してください。

マルウェアスキャン

ランチャーには、ダウンロードした JAR ファイルに fractureiser のシグネチャがないかを調べる組み込みのスキャナーがあります。fractureiser は、2023 年に改ざんされた MOD を通じて拡散した Minecraft 特有のマルウェアです。 スキャンはゲームを起動するたびに自動で実行されます。

リセットとランタイムのオプション

ランチャーをリセットすべての設定を既定値に戻し、キャッシュされたデータを消去します。この操作は元に戻せません。
ランタイム管理ランタイム管理 画面を開き、インストール済みの Java ランタイムを表示、検証、削除します。
警告

ランチャーをリセットすると、すべての設定、キャッシュされたトークン、MODパックの状態が削除されます。 ディスク上の MODパックのファイルは残りますが、MODパックを再度追加する必要があります。

設定のインポート / エクスポート

エクスポート で現在の設定をファイルに保存し、インポート で 以前に保存した設定を読み込みます。マシン間で設定を共有したり、リセット後に 正常に動作していた設定を復元したりするのに便利です。
