トラブルシューティング

このページでは、よくある問題とその解決方法を紹介します。ここに載っていない問題の場合は、 ランチャーのログでエラーの詳細を確認してください。

ダウンロードの失敗

ファイルのダウンロードに失敗する、または起動中に検証エラーが表示される。

  • インターネット接続を確認して、もう一度お試しください。
  • 企業や学校のネットワークを使っている場合は、 設定 のネットワーク / プロキシでプロキシを設定してください。
  • もう一度起動してみてください — 一時的なネットワークエラーは、再試行で解消することがよくあります。
  • 特定のファイルが毎回失敗する場合は、そのダウンロード URL が壊れている可能性があります。MODパックの作者に報告してください。

オフライン表示

ランチャーがインターネット接続を検出できないと、各メイン画面のヘルプボタンの横に赤い オフライン チップが 表示されます。オフラインの間は:

  • ファイルがすべてダウンロード済みの MODパックは、引き続き起動できます。
  • インストール、アップデート、MODパックエディターのバージョン選択ダイアログは、失敗するか 古いデータを表示します。
  • ブラウズ 画面の利用可能なパックと ローダーのバージョンのフィルターは、ネットワークが復旧するまで空になります。
  • 既存のトークン（起動の合間もディスクにキャッシュされます）が有効である限り、 認証には影響しません。

表示は画面を移動したときに更新されます。ネットワークが復旧したら、 別の画面に切り替えて戻るとチップが更新されます。

ゲームのクラッシュ

ゲームは起動するが、すぐにクラッシュする、またはプレイ中にクラッシュする。

  • 設定で ゲームコンソール を有効にすると、クラッシュの出力をリアルタイムで確認できます。
  • MODパックの crash-reports/ フォルダーにあるクラッシュレポートで、具体的なエラーの詳細を確認してください。
  • 設定 で最大 RAM の割り当てを増やしてみてください — 多くの MODパックは少なくとも 4～6 GB を必要とします。
  • メイン画面で MODパックを右クリックして インストールフォルダーを開く を選び、 mods/ フォルダーを削除してから再起動すると、新しくダウンロードし直されます。
警告

RAM を割り当てすぎる（システムに余裕がある以上にする）と、少なすぎる場合と同じように クラッシュの原因になります。最大 RAM はシステムの合計メモリの半分以下にしてください。

ランチャーが読み込み中のまま止まる

ランチャーが固まったように見える、または進行状況バーが動かなくなる。

  • 数分待ってください — 大きな MODパックでは、特に初回起動時にファイルの検証に時間がかかることがあります。
  • ランチャーのログでエラーを確認してください（設定で詳細ログを有効にします）。
  • 最後の手段として、ランチャーをリセット（設定 にあります） を使い、クリーンな状態に戻してください。

オフラインモード

ランチャーは、認証とファイルのダウンロードにインターネット接続を必要とします。ただし、 MODパックのマニフェストとゲームファイルは、最初のダウンロードが成功した後はローカルにキャッシュされます。

  • 初期設定の後に接続が切れても、キャッシュされたファイルを使ってゲームを起動できる場合があります。
  • 認証トークンは約 4 時間キャッシュされます — トークンがまだ有効であれば、その間はオフラインでもプレイできます。

パフォーマンスの問題

ゲームは動作するが、FPS が低い、または頻繁にカクつく。

  • JVM プリセットを Performance (Aikar's Flags) に切り替えてください （設定 で変更できます）。
  • 十分な RAM を割り当てているか確認してください — ほとんどの MODパックでは少なくとも 4 GB が必要です。
  • プレイ中は、メモリを多く使う他のアプリケーションを閉じてください。
  • グラフィックドライバーが最新かどうか確認してください。

MOD やファイルが見つからない

ゲームは起動するが、MOD が足りない、または設定ファイルが正しくない。

  • ランチャーは起動のたびにファイルのハッシュを検証します。ファイルを手動で変更した場合は、MODパックの定義に合わせて再ダウンロードされます。
  • MODパック自体に MOD が含まれていない場合は、MODパックの作者に連絡してください。
  • MODパックを削除して再度追加すると、すべてを強制的に再ダウンロードできます。

認証の問題

サインインできない、または何度も再認証を求められる。

  • トークンの有効期限は約 4 時間です — 再認証は正常な動作です。
  • サインインが何度も失敗する場合は、ブラウザーの login.microsoftonline.com の Cookie を消去してみてください。
  • Microsoft アカウントに有効な Minecraft のライセンスがあることを確認してください。
  • 認証の流れについて詳しくは、ログイン を参照してください。
ヒント

問題を報告するときは、MODパックの名前とバージョン、オペレーティングシステム、 ランチャーのログファイル、クラッシュレポートがあればそれも必ず添えてください。問題の診断がずっと速くなります。
