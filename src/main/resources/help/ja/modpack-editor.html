Modpack エディター

MODパックエディターは、MODパックの JSON 定義ファイルを作成・編集するための組み込みツールです。 検証、検索との連携、差分の追跡を備えた、構造化されたインターフェースを提供します。

ツールバー

  • 新規 — テンプレートから空の MODパック定義を作成します。
  • ファイルを開く — ディスクから既存の JSON 定義を読み込みます。
  • URL を開く — リモートの URL から定義を取得して読み込みます。
  • 保存 — 現在の定義をローカルファイルに書き込みます。
  • 検証 — 定義にエラー（必須項目の不足、無効な URL、ハッシュの不一致）がないか確認します。
  • 差分 — 現在の状態を最後に保存したバージョンと比較し、変更点を表示します。

メタデータの項目

上部のセクションには、MODパックの基本情報（名前、バージョン、説明、作者、 Minecraft のバージョン、Forge のバージョン）があります。Forge のバージョンを選択 を使うと、 選択した Minecraft のバージョンで利用できる Forge のビルドを一覧から選べます。

ファイルのタブ

ファイルはカテゴリ別のタブに整理されています:

MODmods/ フォルダーに配置される Forge の MOD JAR。
設定MOD の設定ファイル。config/ に配置されます。
リソースリソースパックやその他のアセット。
シェーダーOptiFine または Iris 用のシェーダーパック。
初期ファイル初回インストール時にのみコピーされるファイル（例: 既定の options.txt）。

各ファイルの項目には、ダウンロード URL と SHA-1 ハッシュが含まれます。エディターはファイルをダウンロードして チェックサムを計算することで、ハッシュを自動計算 できます。

Modrinth を検索

組み込みの Modrinth 検索を使うと、名前で MOD を探せます。結果を選択すると、正しいバージョンの ダウンロード URL とハッシュの欄が自動で入力されます。

バージョンの引き上げ

バージョンを上げる ボタン（メジャー / マイナー / パッチ）は MODパックのバージョン番号を増やします。 ランチャーが自動で検出するアップデートを簡単に公開できます。

URL のチェック

エディターは、すべてのファイルのダウンロード URL にアクセスできるかを確認できます。公開前に リンク切れを見つけるのに役立ちます。

ヒント

保存する前に 検証 を使うと、問題を早めに見つけられます。検証では、 必須項目、有効な URL、正しいハッシュ形式をチェックします。
