はじめに

Mica Minecraft Launcher へようこそ。クロスプラットフォームの Minecraft Forge MODパックランチャーで、 ワンクリックで MODパックのインストール、アップデート、プレイができます。

クイックスタート

  1. Microsoft アカウントで サインイン します。ランチャーは Microsoft の公式 認証を使って Minecraft の所有を確認します。詳しくは ログイン を参照してください。
  2. MODパックを選択 します。 メイン画面 の左側の一覧から選んでください。まだ MODパックがインストールされていない場合は、 ブラウズ から追加してください。
  3. プレイをクリック すると、ランチャーが必要なファイルをすべて自動でダウンロードし、 正しい Forge のバージョンをインストールし、ファイルの整合性を検証してから、ゲームを起動します。

ランチャーが代わりに行うこと

  • MODパックのファイル（MOD、設定ファイル、リソース）のダウンロードとアップデート
  • 各 MODパックに適した Forge のバージョンのインストール
  • Java ランタイムの管理 — JDK を手動でインストールする必要はありません
  • SHA-1 ハッシュチェックによるファイルの整合性の検証
  • ダウンロードしたファイルに既知のマルウェアがないかのスキャン
ヒント

どの画面にも ? ボタンがあります。クリックすると、現在表示している画面に 対応したヘルプが開きます。

さらに詳しく

  • メイン画面 — ランチャー画面の操作方法
  • 設定 — メモリ、テーマ、JVM フラグなど
  • ブラウズ — MODパックの追加と削除
  • バニラ バージョン — MOD なしの Minecraft をプレイする
  • キーボード ショートカット — よく使う操作のキー
  • アクション リファレンス — MODパックの各操作がランチャーのどこにあるか
  • 言語とローカライズ — 自動検出、手動での変更、対応言語
  • トラブルシューティング — よくある問題と解決方法
