ブラウズ

ブラウズ画面は、インストールと管理を行うための画面です。ここでは、公開マニフェストから新しい MODパックを インストールしたり、MOD なしのバニラ Minecraft のバージョンをインストールしたり、空の Forge / NeoForge / Fabric スターターパックをインストールしたり、既存のパックを編集したり、不要になったものをアンインストールしたりできます。

カードとフィルターバー

各項目は、ロゴ、バッジ、名前、チップ（ローダー / Minecraft のバージョン）、ステータス行、 操作ボタンを備えたヒーローカードとして表示されます。上部のフィルターバーで表示を絞り込めます。

  • 検索 — カードのタイトルに対する自由入力の検索です。入力に合わせて結果が更新されます （レイアウトが頻繁に再描画されないよう、少し遅延させています）。
  • 種類 — すべて、MODパック、またはバージョンカタログのいずれか: バニラ（リリース / スナップショット / Old Beta / Old Alpha）と Forge / NeoForge / Fabric のバージョン。 ローダーのバージョンのフィルターは、意図的に「すべて」には含まれていません。合わせると 数千件にもなり、「全部見せて」という検索で求められるものではないためです。
  • 状態 — すべて、インストール済み、または利用可能。「利用可能」はまだ インストールしていないものを、「インストール済み」はすでにディスク上にあるものを表示します。
  • 並べ替え — 既定、名前（A-Z / Z-A）、リリース日、最終プレイ日時、プレイ時間順、 最近の更新順。プレイ履歴や更新履歴に基づく並べ替え（最終プレイ日時、プレイ時間順、 最近の更新順）では、MODパック以外の項目は混在させず、一番下にまとめて表示します。

インストール済みの MODパック

ディスク上にあるパックのカードには、2 つのボタンが表示されます:

  • アンインストール — インストールフォルダーも削除するかどうかを確認します。「アンインストール （ファイルは保持）」を選ぶと、ランチャーはパックを管理しなくなりますが、ワールド、設定、MOD は残ります。 後で同じパックを再インストールする予定がある場合に便利です。
  • 編集 — パックのローカルマニフェストを MODパックエディター で開きます。変更はディスクに書き込まれ、次回の起動時に反映されます。
ヒント

インストール済みの MODパックのカードを右クリックすると、メインメニューと同じメニューが表示されます。 パックのフォルダーを開く、mods フォルダーを開く、デスクトップショートカットを作成する、プレイ統計を表示する、 アンインストールする、といった操作ができます。

利用可能な MODパック

公開マニフェストに含まれ、まだインストールしていないパックのカードには インストール ボタンが表示されます。 クリックするとマニフェストをダウンロードして MODパックをインストールし、次回の再構築時にカードが インストール済みのグループに移動します。インストール中もフィルターを使い続けられます。 インストール中のカードは、完了するまでグリッドの先頭に固定されます。

バニラのバージョン

Mojang のリリース / スナップショット / ベータ / アルファの全カタログです。各カードは、その Minecraft のバージョンを空の仮想 MODパックとしてインストールし、メインメニューから直接プレイできるようにします。 古いベータやアルファも実行できます。ランチャーが各バージョンに適した Java ランタイムを 自動で取得します。

Forge / NeoForge / Fabric のバージョン

ローダーのバージョンのフィルターには、各プロジェクトのバージョンサービスが公開しているすべてのリリースが表示されます: Forge のプロモーション、NeoForge の maven メタデータ、Fabric の meta API です。これらのいずれかで「インストール」を クリックすると、設定フォルダーに仮想の「空の MODパック」マニフェストが書き込まれ、ランチャーに登録されます。 そのため、結果は他のインストール済み MODパックと同じように動作します:

  • メインメニューのヒーローカードに表示されます。
  • MODパックエディターで編集できます（MOD を追加して自分だけのパックを作れます）。
  • 他のパックと同じようにアンインストールできます。
  • 通常の MODパックと同じ自動アップデートの仕組みを使います。
メモ

ランチャーがローカルにキャッシュしている場合、カードには各プロジェクトの公式ロゴが表示されます。 ローダーのフィルターを初めて開いたときは、本物のロゴをバックグラウンドでダウンロードしている間、 ブランドカラーのプレースホルダーが表示されます。キャッシュされた後は、すぐに表示されます。

URL から追加

下部バーの URL から追加 ボタンは、ホストされている installable.json マニフェストへの直接 URL を受け取り、利用可能なパックのカードと同じ方法でインストールします。 公開マニフェスト以外で配布されている MODパックに使用してください。リンクを貼り付けてボタンをクリックすると、 インストールの開始前にマニフェストのメタデータがダウンロードされ、検証されます。

MODパックエディター

下部バーの MODパックエディター ボタンは、空のマニフェストで MODパックエディター を開きます。新しいパックを一から作成できます。 ローダー（Forge / NeoForge / Fabric / バニラ）、Minecraft のバージョン、MOD の一覧などを設定してください。 既存のパックのカードにある 編集 ボタンから、そのパックをエディターで開くこともできます。

ホスティング用マニフェストを生成

下部バーの ホスティング用マニフェストを生成 ボタンは、エディターで開いている MODパックの installable.json を作成します。任意の Web サーバーやファイル共有サービスでそのままホストできます。 生成された URL を知っている人なら誰でも、「URL から追加」であなたのパックをインストールできます。

ページ切り替え

長い一覧はページに分けて表示されます。ページ切り替えバー（カードの上）の 前へ / 次へ ボタンで ページを移動し、表示件数 ドロップダウンで 1 ページの件数を 24、48、72、96 から設定します。既定の 48 件なら、一般的なインストール済み ライブラリが 1 ページに収まります。96 件に増やすと、ローダーのバージョンのフィルターも 1 ページの中で スクロールして見られます。
