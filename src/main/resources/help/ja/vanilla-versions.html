バニラ バージョン

ランチャーでは、Forge の MODパックに加えて、バニラ（MOD なし）の Minecraft のバージョンを直接インストールしてプレイすることもできます。

バージョンの閲覧

バニラのバージョンの画面には、利用可能な Minecraft のリリースとスナップショットが一覧表示されます。 各項目にはバージョン番号とリリース日が表示されます。バージョンを選択すると詳細が表示されます。

インストールと起動

  1. 一覧から Minecraft のバージョンを選択します。
  2. インストール をクリックして、そのバージョンのゲームクライアント、ライブラリ、アセットをダウンロードします。
  3. インストールが完了したら、プレイ をクリックして起動します。ファイルの検証と ランタイムの準備は、すべてランチャーが自動で行います。
メモ

バニラのバージョンでも、設定 で構成した メモリと JVM の設定が使われます。動作が重い場合は、 RAM の割り当てや JVM プリセットを調整してみてください。

ランタイム管理

Minecraft のバージョンによって、必要な Java ランタイムが異なる場合があります。ランチャーは各バージョンに適した ランタイムを自動でダウンロードして管理します — たとえば Minecraft 1.17 以降は Java 17 以降が必要で、それより古いバージョンは Java 8 を使用します。

Java を手動でインストールする必要はありません。ランタイムの扱いについて詳しくは、 ランタイム管理 を 参照してください。

ヒント

大きな MODパックをインストールする前に、バニラのバージョンを使って、システムが基本的な要件を 満たしているかを確認するとよいでしょう。
