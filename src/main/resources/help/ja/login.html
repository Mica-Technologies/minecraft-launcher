ログイン

Mica Minecraft Launcher は Microsoft の公式認証 を使って Minecraft アカウントを確認します。公式の Minecraft ランチャーと同じサインインの流れです。

仕組み

  1. ログイン画面で サインイン をクリックします。ブラウザーのウィンドウで Microsoft のサインインページが開きます。
  2. Microsoft アカウントの資格情報を入力し、サインインを承認します。
  3. 認証が完了するとブラウザーのウィンドウが閉じ、ランチャーは メイン画面 に進みます。

トークンのキャッシュ

ログインに成功すると、認証トークンはマシン固有の鍵を使った AES-256-GCM 暗号化 でローカルにキャッシュされます。つまり:

  • 約 4 時間 は再度サインインする必要がありません。
  • キャッシュされたトークンは暗号化され、お使いのマシンに紐付けられています — 他の場所に移したり再利用したりすることはできません。
  • キャッシュの有効期限が切れると、ランチャーが再度サインインを求めます。

ログインの問題のトラブルシューティング

インターネット接続が必要です

最初のログインにはインターネット接続が必要です。完全なオフライン状態では、 ランチャーは認証できません。

サインインで問題が発生した場合:

  • ブラウザーが開かない — システムに既定のブラウザーが設定されているか確認してください。
  • サインインがタイムアウトする — インターネット接続を確認して、もう一度お試しください。
  • アカウントが認識されない — Minecraft を所有している Microsoft アカウントを使っているか確認してください。
  • 何度もサインインを求められる — キャッシュされたトークンの有効期限が切れた可能性があります。4 時間操作がなかった後は正常な動作です。

問題が解決しない場合は、トラブルシューティング を参照してください。
