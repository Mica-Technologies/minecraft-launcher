ランタイム管理

Mica Minecraft Launcher は Java ランタイムを自動で管理するため、Java を自分でインストールしたり 設定したりする必要はありません。

ランタイムが重要な理由

Minecraft と Forge を正しく実行するには、特定のバージョンの Java が必要です。MODパックや Minecraft のバージョンによって、必要な Java ランタイムが異なる場合があります:

  • Minecraft 1.16 以前 — Java 8
  • Minecraft 1.17～1.20 — Java 17
  • Minecraft 1.21 以降 — Java 21 以降

ランチャーは、各 MODパックやバニラのバージョンに必要なランタイムを検出し、初回起動時に 自動でダウンロードします。

自動ダウンロード

MODパックやバニラのバージョンを初めて起動すると、ランチャーは必要なランタイムがすでにインストールされているかを 確認します。インストールされていない場合は、Mojang または Liberica の配布サーバーから正しいバージョンを ダウンロードします。ダウンロードはランタイムのバージョンごとに 1 回だけです。

メモ

ランタイムのダウンロードは通常 40～80 MB で、ランチャーのデータディレクトリに保存されます。 システムにインストールされている Java とは別に管理されます。

インストール済みランタイムの表示

設定 を開いて ランタイム管理 をクリックすると、 インストール済みのすべての Java ランタイムが、バージョン、パス、使用している MODパックとともに 一覧表示されます。

使われていないランタイムの削除

特定の Java バージョンを使っていた MODパックを削除した場合は、対応するランタイムを削除して ディスク容量を空けられます。管理画面でランタイムを選択し、 削除 をクリックします。

警告

インストール済みの MODパックがまだ必要としているランタイムを削除すると、その MODパックを次に起動したときに ランチャーが再ダウンロードします。

ランタイムのトラブルシューティング

MODパックが Java 関連のエラーで起動に失敗する場合は、次を試してください:

  1. ランタイム管理を開き、該当する MODパックが使っているランタイムを削除します。
  2. MODパックをもう一度起動します — ランチャーが新しいコピーを再ダウンロードします。
  3. それでも問題が解決しない場合は、トラブルシューティング で その他の手順を確認してください。
