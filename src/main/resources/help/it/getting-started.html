Per iniziare

Benvenuto nel Mica Minecraft Launcher, un launcher multipiattaforma per modpack di Minecraft Forge che rende semplice installare, aggiornare e giocare ai modpack con un solo clic.

Avvio rapido

  1. Accedi con il tuo account Microsoft. Il launcher usa l'autenticazione ufficiale di Microsoft per verificare che tu possieda Minecraft. Per i dettagli, consulta Accesso.
  2. Seleziona un modpack dall'elenco sul lato sinistro della Schermata principale. Se non hai ancora installato nessun modpack, usa Sfoglia per aggiungerne uno.
  3. Fai clic su Gioca e il launcher scaricherà automaticamente tutti i file necessari, installerà la versione corretta di Forge, verificherà l'integrità dei file e avvierà il gioco.

Cosa gestisce il launcher al posto tuo

  • Download e aggiornamento dei file dei modpack (mod, configurazioni, risorse)
  • Installazione della versione corretta di Forge per ogni modpack
  • Gestione dei runtime Java: non serve installare manualmente un JDK
  • Verifica dell'integrità dei file tramite controlli hash SHA-1
  • Scansione dei file scaricati alla ricerca di malware noti
Suggerimento

Cerca il pulsante ? in ogni schermata: apre la guida contestuale per la schermata che stai visualizzando.
