Versioni vanilla

Oltre ai modpack Forge, il launcher può installare e avviare direttamente versioni di Minecraft vanilla (senza mod).

Sfogliare le versioni

La schermata delle versioni vanilla mostra un elenco delle release e degli snapshot di Minecraft disponibili. Ogni voce riporta il numero di versione e la data di pubblicazione. Seleziona una versione per vederne i dettagli.

Installazione e avvio

  1. Seleziona una versione di Minecraft dall'elenco.
  2. Fai clic su Installa per scaricare il client di gioco, le librerie e le risorse di quella versione.
  3. Una volta completata l'installazione, fai clic su Gioca per avviarla. Il launcher gestisce automaticamente la verifica di tutti i file e la configurazione del runtime.
Nota

Le versioni vanilla usano le stesse impostazioni di memoria e JVM configurate nelle Impostazioni. Se una versione funziona male, prova a regolare l'allocazione della RAM o il preset JVM.

Gestione runtime

Versioni diverse di Minecraft possono richiedere runtime Java diversi. Il launcher scarica e gestisce automaticamente il runtime corretto per ogni versione: ad esempio, Minecraft 1.17+ richiede Java 17 o successivo, mentre le versioni più vecchie usano Java 8.

Non è necessario installare Java manualmente. Consulta Gestione runtime per maggiori dettagli su come vengono gestiti i runtime.

Suggerimento

Le versioni vanilla sono un buon modo per verificare se il tuo sistema soddisfa i requisiti di base prima di installare modpack più grandi.
