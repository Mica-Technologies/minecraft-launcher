Editor di modpack

L'editor di modpack è uno strumento integrato per creare e modificare i file JSON di definizione dei modpack. Offre un'interfaccia strutturata con convalida, ricerca integrata e tracciamento delle differenze.

Barra degli strumenti

  • Nuovo: crea una definizione di modpack vuota a partire da un modello.
  • Apri file: carica dal disco una definizione JSON esistente.
  • Apri URL: scarica e carica una definizione da un URL remoto.
  • Salva: scrive la definizione corrente in un file locale.
  • Convalida: controlla la definizione alla ricerca di errori (campi mancanti, URL non validi, hash non corrispondenti).
  • Diff: confronta lo stato attuale con l'ultima versione salvata per vedere cosa è cambiato.

Campi dei metadati

La sezione superiore contiene le informazioni principali del modpack: nome, versione, descrizione, autore, versione di Minecraft e versione di Forge. Il selettore della versione di Forge ti permette di sfogliare le build di Forge disponibili per la versione di Minecraft selezionata.

Schede dei file

I file sono organizzati in schede per categoria:

ModJAR delle mod Forge inseriti nella cartella mods/.
ConfigurazioniFile di configurazione delle mod, inseriti in config/.
RisorseResource pack e altre risorse.
ShaderShader pack per OptiFine o Iris.
File inizialiFile copiati solo alla prima installazione (ad es. il file options.txt predefinito).

Ogni voce di file include un URL di download e un hash SHA-1. L'editor può calcolare automaticamente gli hash scaricando il file e calcolandone il checksum.

Ricerca su Modrinth

Usa la ricerca integrata su Modrinth per trovare le mod per nome. Seleziona un risultato per compilare automaticamente i campi dell'URL di download e dell'hash con la versione corretta.

Incremento della versione

Il pulsante Incrementa versione aumenta il numero di versione del modpack, rendendo semplice pubblicare aggiornamenti che il launcher rileverà automaticamente.

Controllo degli URL

L'editor può verificare che tutti gli URL di download dei file siano raggiungibili, aiutandoti a individuare i link non funzionanti prima della pubblicazione.

Suggerimento

Usa Convalida prima di salvare per individuare subito i problemi. Il validatore controlla i campi obbligatori, la validità degli URL e il formato corretto degli hash.
