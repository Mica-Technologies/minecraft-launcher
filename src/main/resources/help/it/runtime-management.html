Gestione runtime

Il Mica Minecraft Launcher gestisce automaticamente i runtime Java, così non devi mai installare né configurare Java da solo.

Perché i runtime sono importanti

Minecraft e Forge richiedono versioni specifiche di Java per funzionare correttamente. Modpack e versioni di Minecraft diversi possono richiedere runtime Java diversi:

  • Minecraft 1.16 e precedenti: Java 8
  • Minecraft 1.17 - 1.20: Java 17
  • Minecraft 1.21+: Java 21 o successivo

Il launcher rileva quale runtime richiede ogni modpack o versione vanilla e lo scarica automaticamente al primo avvio.

Download automatici

Quando avvii un modpack o una versione vanilla per la prima volta, il launcher controlla se il runtime richiesto è già installato. In caso contrario, scarica la versione corretta dai server di distribuzione di Mojang o di Liberica. Il download avviene una sola volta per ogni versione del runtime.

Nota

I runtime scaricati occupano in genere 40 - 80 MB e vengono salvati nella cartella dei dati del launcher, separati da qualsiasi installazione di Java presente nel sistema.

Visualizzare i runtime installati

Apri le Impostazioni e fai clic su Gestisci i runtime per vedere l'elenco di tutti i runtime Java installati, con la versione, il percorso e i modpack che li usano.

Eliminare i runtime inutilizzati

Se hai rimosso i modpack che usavano una determinata versione di Java, puoi eliminare il runtime corrispondente per liberare spazio su disco. Seleziona un runtime nella schermata di gestione e fai clic su Elimina.

Attenzione

Se elimini un runtime ancora necessario a un modpack installato, il launcher lo scaricherà di nuovo al successivo avvio di quel modpack.

Risolvere i problemi dei runtime

Se un modpack non si avvia a causa di errori legati a Java, prova quanto segue:

  1. Apri Gestione runtime ed elimina il runtime usato dal modpack interessato.
  2. Avvia di nuovo il modpack: il launcher scaricherà una copia nuova.
  3. Se il problema persiste, consulta Risoluzione dei problemi per ulteriori passaggi.
