Console di gioco

La console di gioco mostra in tempo reale l'output del processo di Minecraft, inclusi messaggi di log, avvisi, errori e report dei crash.

Attivare la console

La finestra della console compare accanto al gioco quando l'opzione Console in gioco è attivata nelle Impostazioni, nella sezione Avanzate. Se è disattivata, il gioco viene eseguito senza una console visibile.

Funzioni della console

  • Output in tempo reale: le righe del log di gioco compaiono man mano che vengono prodotte.
  • Termina forzatamente: chiude forzatamente il processo di Minecraft se il gioco smette di rispondere. Usalo come ultima risorsa.
  • Copia: copia il contenuto della console negli appunti per condividerlo o analizzarlo.

Report dei crash

Quando il gioco va in crash, la console rileva automaticamente il crash ed evidenzia il relativo report. Puoi:

  • Visualizzare il report completo del crash direttamente nella console.
  • Usare il pulsante Copia per copiare il testo del report e condividerlo con gli autori del modpack o con i canali di supporto.
Nota

Il contenuto della console viene troncato per mantenere ragionevole l'uso della memoria durante le sessioni di gioco lunghe. Per il log completo e non troncato, consulta i file di log sul disco.

Posizione dei file di log

I log completi del gioco vengono scritti nella cartella logs/ del modpack. Puoi accedere rapidamente a questa cartella facendo clic destro sul modpack nella Schermata principale e selezionando Apri la cartella di installazione.

Suggerimento

Se segnali un crash, includi sia il report del crash sia il file di log più recente: il log contiene spesso un contesto che il solo report del crash non fornisce.
