Impostazioni

La schermata delle impostazioni ti permette di personalizzare l'allocazione della memoria, l'aspetto, il comportamento della JVM, la configurazione di rete e altro ancora. Le modifiche vengono salvate automaticamente.

Memoria di gioco

RAM minimaLa dimensione iniziale dell'heap allocata alla JVM del gioco. In genere conviene lasciare il valore predefinito (512 MB), a meno che un modpack non indichi diversamente.
RAM massimaIl limite massimo di memoria per il gioco. La maggior parte dei modpack funziona meglio con 4 - 8 GB. Allocare più memoria di quanta il sistema possa cederne può causare instabilità.
Suggerimento

Una buona regola pratica: imposta la RAM massima a non più della metà della memoria totale del sistema. Ad esempio, su un computer con 16 GB, 6 - 8 GB sono un limite massimo ragionevole.

Preset JVM

Insiemi preconfigurati di flag JVM aggiunti al comando di avvio del gioco. Consulta Preset JVM per una spiegazione più approfondita di cosa fa ogni preset, quali flag personalizzati potresti voler aggiungere e come la scelta del preset interagisce con l'allocazione della RAM.

Performance (Aikar's Flags)Consigliato. Flag ottimizzati per la garbage collection, molto usati dalla community di Minecraft. Le migliori prestazioni complessive per la maggior parte dei modpack.
Low MemoryFlag prudenti per sistemi con RAM limitata. Riduce il sovraccarico del GC a scapito di un po' di throughput.
DebugAttiva l'output di debug della JVM, inclusi i log del GC. Utile per diagnosticare crash o problemi di prestazioni.
NoneNessun flag aggiuntivo: usa le impostazioni predefinite della JVM. Usalo solo se sai cosa stai facendo o se un modpack lo richiede.

Rete / Proxy

Configura un proxy se la tua rete lo richiede (cosa comune nelle reti aziendali o scolastiche).

Proxy HTTPProxy web standard. Inserisci l'host e la porta forniti dall'amministratore di rete.
Proxy SOCKSProtocollo proxy di livello più basso. Usalo se la tua rete richiede specificamente SOCKS.
Nota

La maggior parte degli utenti può lasciare vuote le impostazioni del proxy. Configurale solo se i download o l'autenticazione non riescono su una rete con restrizioni.

Scansione malware

Il launcher include uno scanner integrato che controlla i file JAR scaricati alla ricerca delle firme di fractureiser, un malware specifico per Minecraft che nel 2023 si è diffuso tramite mod compromesse. La scansione viene eseguita automaticamente prima di ogni avvio del gioco.

Ripristino e opzioni dei runtime

Reimposta il launcherRipristina tutte le impostazioni ai valori predefiniti e cancella i dati in cache. Questa operazione non può essere annullata.
Gestione runtimeApre la schermata Gestione runtime per visualizzare, verificare o rimuovere i runtime Java installati.
Attenzione

Reimpostare il launcher rimuove tutte le impostazioni, i token memorizzati e lo stato dei modpack. I file dei modpack sul disco vengono conservati, ma dovrai aggiungerli di nuovo.

Importare / esportare le impostazioni

Usa Esporta impostazioni per salvare la configurazione corrente in un file e Importa impostazioni per caricare una configurazione salvata in precedenza. È utile per condividere le impostazioni tra computer o per ripristinare una configurazione funzionante dopo un reset.
