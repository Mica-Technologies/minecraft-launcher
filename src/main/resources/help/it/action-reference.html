Riferimento azioni

Ogni azione sui modpack del launcher è raggiungibile da almeno una superficie principale, con un duplicato nel menu contestuale per un accesso rapido quando stai già guardando una scheda. Questa pagina indica dove si trova ogni azione, così non devi cercarla.

Superfici principali

SuperficieCosa contiene
Schede in evidenza del menu principale Pulsanti principali Gioca + Sito web per ogni modpack. Un clic sulla scheda apre la finestra dei dettagli.
Finestra dei dettagli del modpack La superficie più completa per ogni modpack: riquadri di Azioni rapide (Apri cartella / Mod / Configurazione / Screenshot / Resource pack / Shader / Collegamento sul desktop / Copia link di invito / Esporta come ZIP), Statistiche, Registro aggiornamenti, Mondi, griglia degli Screenshot, elenchi di Shader pack / Resource pack, Cronologia dei crash, sezione Avanzate (verifica) e pulsanti di azione Gioca / Sito web.
Schede della schermata Sfoglia Installa / Disinstalla / Modifica a seconda del tipo di voce (modpack / versione vanilla / versione del loader).
Menu contestuale (clic destro) Accesso rapido alle Azioni rapide più comuni da qualsiasi scheda di modpack senza aprire la finestra dei dettagli. Usa gli stessi gestori della finestra.
Impostazioni Preferenze generali del launcher: Account, Gioco / runtime, Aspetto, Avanzate, Rete, Sicurezza, Sistema, Discord, RGB, Informazioni.

Suggerimento

Quasi ogni azione per singolo modpack ha una scorciatoia nel menu contestuale della scheda del modpack. Se ti ritrovi a passare ripetutamente dalla finestra dei dettagli solo per raggiungere la stessa cartella, prova a fare clic destro sulla scheda nel menu principale: le stesse voci sono a un solo clic di distanza.
