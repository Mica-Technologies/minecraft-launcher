Versiones vanilla

Además de los modpacks de Forge, el launcher puede instalar y ejecutar directamente versiones de Minecraft vanilla (sin mods).

Explorar versiones

La pantalla de versiones vanilla muestra una lista de las versiones estables y snapshots de Minecraft disponibles. Cada entrada muestra el número de versión y la fecha de publicación. Seleccione una versión para ver sus detalles.

Instalar e iniciar

  1. Seleccione una versión de Minecraft en la lista.
  2. Haga clic en Instalar para descargar el cliente del juego, las bibliotecas y los recursos de esa versión.
  3. Una vez instalada, haga clic en Jugar para iniciarla. El launcher se encarga automáticamente de toda la verificación de archivos y de la configuración del entorno de ejecución.
Nota

Las versiones vanilla usan la misma configuración de memoria y de JVM establecida en Configuración. Si una versión funciona mal, pruebe a ajustar la asignación de RAM o el preajuste de JVM.

Gestión de entornos de ejecución

Distintas versiones de Minecraft pueden requerir distintos entornos de ejecución de Java. El launcher descarga y administra automáticamente el entorno de ejecución correcto para cada versión; por ejemplo, Minecraft 1.17+ requiere Java 17 o posterior, mientras que las versiones anteriores usan Java 8.

No necesita instalar Java manualmente. Consulte Gestión de entornos de ejecución para obtener más detalles sobre cómo se gestionan los entornos de ejecución.

Consejo

Las versiones vanilla son una buena forma de comprobar si su sistema cumple los requisitos básicos antes de instalar modpacks más grandes.
