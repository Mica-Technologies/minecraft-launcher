Referencia de acciones

Todas las acciones de modpack del launcher se pueden realizar desde al menos una ubicación principal, con un duplicado en el menú contextual para acceder rápidamente cuando ya está mirando una tarjeta. Esta página indica dónde se encuentra cada acción para que no tenga que buscarla.

Ubicaciones principales

UbicaciónQué contiene
Tarjetas destacadas del menú principal Botones principales Jugar y Sitio web de cada modpack. Al hacer clic en la tarjeta se abre la ventana de detalles.
Ventana de detalles del modpack La ubicación más completa para cada modpack: mosaicos de Acciones rápidas (Abrir carpeta / Mods / Configuración / Capturas de pantalla / Paquetes de recursos / Shaders / Acceso directo en el escritorio / Copiar enlace de invitación / Exportar como ZIP), Estadísticas, Registro de actualizaciones, Mundos, cuadrícula de Capturas de pantalla, listas de Paquetes de shaders / Paquetes de recursos, Historial de fallos, sección Avanzado (verificación) y botones de acción Jugar / Sitio web.
Tarjetas de la pantalla Explorar Instalar / Desinstalar / Editar según el tipo de entrada (modpack / vanilla / versión de cargador).
Menú contextual (clic derecho) Acceso rápido a las Acciones rápidas habituales desde cualquier tarjeta de modpack sin abrir la ventana de detalles. Comparte exactamente los mismos controladores que la ventana.
Configuración Preferencias generales del launcher: cuenta, juego / entorno de ejecución, apariencia, avanzado, red, seguridad, sistema, Discord, RGB, Acerca de.

Consejo

Casi todas las acciones de cada modpack tienen un acceso directo en el menú contextual de la tarjeta del modpack. Si se encuentra pasando una y otra vez por la ventana de detalles solo para llegar a la misma carpeta, pruebe a hacer clic derecho en la tarjeta del menú principal: los mismos elementos están a un solo clic.
