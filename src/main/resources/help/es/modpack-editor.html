Editor de modpacks

El editor de modpacks es una herramienta integrada para crear y editar los archivos JSON de definición de modpacks. Ofrece una interfaz estructurada con validación, búsqueda integrada y seguimiento de diferencias.

Barra de herramientas

  • Nuevo: crea una definición de modpack en blanco a partir de una plantilla.
  • Abrir archivo: carga una definición JSON existente desde el disco.
  • Abrir URL: obtiene y carga una definición desde una URL remota.
  • Guardar: escribe la definición actual en un archivo local.
  • Validar: comprueba si la definición tiene errores (campos que faltan, URL no válidas, hashes que no coinciden).
  • Diferencias: compara el estado actual con la última versión guardada para ver qué ha cambiado.

Campos de metadatos

La sección superior contiene la información principal del modpack: nombre, versión, descripción, autor, versión de Minecraft y versión de Forge. El selector de versión de Forge le permite explorar las compilaciones de Forge disponibles para la versión de Minecraft seleccionada.

Pestañas de archivos

Los archivos se organizan en pestañas por categorías:

ModsArchivos JAR de mods de Forge que se colocan en la carpeta mods/.
ConfiguracionesArchivos de configuración de los mods, que se colocan en config/.
RecursosPaquetes de recursos y otros recursos.
ShadersPaquetes de shaders para OptiFine o Iris.
Archivos inicialesArchivos que solo se copian en la primera instalación (p. ej., el options.txt predeterminado).

Cada entrada de archivo incluye una URL de descarga y un hash SHA-1. El editor puede calcular los hashes automáticamente descargando el archivo y calculando su suma de comprobación.

Búsqueda en Modrinth

Use la búsqueda integrada de Modrinth para encontrar mods por nombre. Seleccione un resultado para rellenar automáticamente los campos de URL de descarga y hash con la versión correcta.

Incremento de versión

El botón Incrementar versión aumenta el número de versión del modpack, lo que facilita publicar actualizaciones que el launcher detectará automáticamente.

Comprobación de URL

El editor puede verificar que todas las URL de descarga de los archivos son accesibles, lo que le ayuda a detectar enlaces rotos antes de publicar.

Consejo

Use Validar antes de guardar para detectar problemas pronto. El validador comprueba los campos obligatorios, que las URL sean válidas y que los formatos de hash sean correctos.
