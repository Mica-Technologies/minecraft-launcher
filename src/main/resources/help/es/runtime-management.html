Gestión de entornos de ejecución

Mica Minecraft Launcher administra automáticamente los entornos de ejecución de Java, de modo que nunca tiene que instalar ni configurar Java usted mismo.

Por qué importan los entornos de ejecución

Minecraft y Forge requieren versiones concretas de Java para funcionar correctamente. Distintos modpacks y versiones de Minecraft pueden necesitar distintos entornos de ejecución de Java:

  • Minecraft 1.16 y anteriores: Java 8
  • Minecraft 1.17 - 1.20: Java 17
  • Minecraft 1.21+: Java 21 o posterior

El launcher detecta qué entorno de ejecución necesita cada modpack o versión vanilla y lo descarga automáticamente en el primer inicio.

Descargas automáticas

Cuando inicia un modpack o una versión vanilla por primera vez, el launcher comprueba si el entorno de ejecución necesario ya está instalado. Si no lo está, descarga la versión correcta desde los servidores de distribución de Mojang o de Liberica. Es una descarga única por cada versión del entorno de ejecución.

Nota

Las descargas de entornos de ejecución suelen ocupar entre 40 y 80 MB y se guardan en el directorio de datos del launcher, separadas de cualquier instalación de Java de su sistema.

Ver los entornos de ejecución instalados

Abra Configuración y haga clic en Gestión de entornos de ejecución para ver una lista de todos los entornos de ejecución de Java instalados, con su versión, su ruta y los modpacks que los usan.

Eliminar entornos de ejecución sin usar

Si ha quitado modpacks que usaban una versión concreta de Java, puede eliminar el entorno de ejecución correspondiente para liberar espacio en disco. Seleccione un entorno de ejecución en la pantalla de gestión y haga clic en Eliminar.

Advertencia

Si elimina un entorno de ejecución que todavía necesita un modpack instalado, el launcher lo volverá a descargar la próxima vez que inicie ese modpack.

Solución de problemas de entornos de ejecución

Si un modpack no se inicia por errores relacionados con Java, pruebe lo siguiente:

  1. Abra Gestión de entornos de ejecución y elimine el entorno de ejecución que usa el modpack afectado.
  2. Vuelva a iniciar el modpack: el launcher descargará una copia nueva.
  3. Si el problema continúa, consulte Solución de problemas para ver pasos adicionales.
