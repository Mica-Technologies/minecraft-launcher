Idioma y localización

Mica Minecraft Launcher muestra su interfaz en 17 idiomas y elige automáticamente el adecuado en el primer inicio. También puede reemplazar el idioma detectado en cualquier momento desde Configuración.

Cómo elige el launcher un idioma

Cada vez que inicia el launcher, este determina el idioma activo en el siguiente orden:

  1. Su selección guardada, si ha establecido una en Configuración → Apariencia → Idioma. Esta siempre tiene prioridad.
  2. El idioma de su sistema operativo, detectado mediante la configuración regional estándar de la JVM. En Windows es su configuración de Región / Idioma; en macOS es Ajustes del Sistema → Idioma y región; en Linux es el entorno LANG / LC_*.
  3. Inglés (Estados Unidos) como alternativa si la plataforma informa de una configuración regional sin idioma (p. ej., POSIX o C), o si el idioma de su sistema operativo no es uno de los 17 para los que incluimos traducciones.
El cambio de idioma se aplica tras reiniciar

Cambiar la selección en Configuración actualiza la preferencia de inmediato, pero las pantallas que ya se están mostrando conservan el idioma anterior hasta que se reinicia el launcher. La propia página de Configuración se lo recuerda cuando cambia el desplegable.

Establecer una selección manual

  1. Abra Configuración desde la barra de navegación (o pulse Ctrl+, / Cmd+,).
  2. Cambie a la pestaña Apariencia.
  3. Elija un idioma en el desplegable Idioma. La primera entrada («Usar el idioma del sistema operativo») restablece la detección automática descrita arriba y muestra entre paréntesis el idioma que resolvería el sistema operativo.
  4. Haga clic en Guardar. Reinicie el launcher para ver el nuevo idioma aplicado en todas las pantallas.

Idiomas compatibles

El launcher incluye traducciones para los 17 idiomas más hablados del mundo, además del inglés:

  • Árabe (عربي)
  • Chino simplificado (简体中文)
  • Chino tradicional (繁體中文)
  • Neerlandés (Nederlands)
  • Inglés (idioma de origen)
  • Francés (Français)
  • Alemán (Deutsch)
  • Hindi (हिंदी)
  • Italiano (Italiano)
  • Japonés (日本語)
  • Coreano (한국어)
  • Polaco (Polski)
  • Portugués de Brasil (Português do Brasil)
  • Ruso (Русский)
  • Español (Español)
  • Sueco (Svenska)
  • Turco (Türkçe)

Cada idioma se identifica por su etiqueta BCP-47 (p. ej., fr-FR, pt-BR, zh-CN). La lista está en SupportedLocales.ENTRIES en el código fuente del launcher; los archivos de propiedades se encuentran junto a ella como DisplayStrings_<tag>.properties en src/main/resources/lang/.

Calidad de las traducciones y notificación de problemas

Las traducciones a idiomas distintos del inglés se generan con un script que llama a Google Translate a partir del paquete de origen en inglés y después procesa los marcadores de parámetros para que elementos como {0} se conserven intactos tras la traducción. El resultado es bueno, pero no perfecto — en particular, las etiquetas cortas de la interfaz (botones de una palabra, sustantivos sueltos) a veces pierden el contexto que tenían en inglés.

Si encuentra una traducción incorrecta, lo mejor es abrir una incidencia en GitHub con el nombre de la clave (p. ej., browse.filter.type.label), su configuración regional, el texto actual y una corrección propuesta. Las correcciones hechas a mano se conservan en la siguiente regeneración porque el script, de forma predeterminada, solo completa las claves que faltan.

Añadir un idioma nuevo

Si su idioma no está en la lista anterior y quiere contribuir con una traducción, el proceso es el siguiente:

  1. Añada una nueva entrada a SupportedLocales.ENTRIES (Java) y a TARGET_LOCALES en tools/i18n/translate-locales.js (Node).
  2. Ejecute cd tools/i18n && npm run translate — el script generará el archivo inicial DisplayStrings_<tag>.properties a partir del origen en inglés.
  3. Revise el archivo generado, corrija a mano todo lo que suene extraño y, a continuación, abra una pull request.

El script tools/i18n/translate-locales.js es incremental: al volver a ejecutarlo solo traduce las claves que todavía no existen en el archivo de destino, de modo que las correcciones manuales se conservan en cada actualización posterior del launcher.
