Atajos de teclado

El launcher ofrece un pequeño conjunto de atajos de teclado para las acciones que más usará. En macOS el modificador es ⌘ Comando; en Windows y Linux es Ctrl. Los atajos siguientes muestran el modificador como ⌘/Ctrl para cubrir ambos casos.

Navegación global

Disponibles en todas las pantallas excepto Inicio de sesión, Progreso del inicio y la ventana de la consola del juego: esas pantallas no aceptan atajos de navegación a propósito, para que no las abandone por accidente a mitad del proceso.

AtajoAcción
⌘/Ctrl + ,Abrir Configuración (convención universal)
⌘/Ctrl + LAbrir la pantalla Explorar (instalar y administrar)
⌘/Ctrl + EAbrir el Editor de modpacks
⌘/Ctrl + Shift + MVolver al menú principal (Inicio)
F1 / ⌘/Ctrl + ?Abrir la ventana de Ayuda en el tema de la pantalla actual
¿Por qué Cmd+Shift+M para Inicio?

⌘ + M a secas es el atajo del sistema de macOS para «Minimizar ventana»; el launcher evita reemplazarlo. ⌘/Ctrl + Shift + M evita el conflicto en todas las plataformas.

Consejo

El botón de ayuda (?) de la esquina superior derecha de cada pantalla es la forma más cómoda con el ratón de abrir esta página o cualquier otro tema de ayuda. Pase el puntero sobre su icono y verá la misma descripción emergente que anuncia el lector de pantalla.
