JVM 프리셋

설정 → 고급의 JVM 사전 설정 드롭다운은 런처가 Minecraft를 시작할 때 JVM에 전달하는 이름 붙은 인수 묶음을 선택합니다. 이 인수들은 가비지 컬렉터를 조정하고, 힙 영역 크기를 제어하며, GC 로깅을 켜고 끕니다. 게임 자체의 동작은 바뀌지 않으며, 게임을 실행하는 JVM이 메모리를 관리하는 방식만 바뀝니다.

알맞은 프리셋 선택은 대형 모드팩(모드 200개 이상)에서 가장 중요합니다. 이런 팩에서는 수천 개의 청크가 로드되고 언로드될 때마다 GC가 뒷정리를 해야 하기 때문입니다. 바닐라와 소형 모드팩에서는 어떤 프리셋이든 괜찮으며 기본값인 "Performance"로 충분합니다.

성능 (Aikar 플래그)

기본 프리셋이며 대부분의 사용자에게 권장됩니다. G1 가비지 컬렉터에 Aikar(Paper Minecraft 서버 제작자)가 수년 전에 공개했고 지금도 많은 튜토리얼이 인용하는 파라미터 조정을 적용합니다. 플레이 부하가 클 때 GC 일시 정지로 인한 끊김을 최소화하도록 설계되었습니다.

추천 대상: RAM을 6 GB 이상 할당한 모드팩, 부하가 걸릴 때 주기적으로 프레임이 끊기는 것을 경험한 모드가 많은 팩.

저메모리

여유 RAM이 적은 시스템을 위해 줄인 플래그입니다. G1에 더 짧은 일시 정지 목표와 더 작은 힙 영역을 사용하며, 메모리가 빠듯한 상황에서 처리량을 일부 희생하는 대신 예측 가능한 동작을 얻습니다.

추천 대상: 전체 시스템 RAM이 8 GB 이하인 시스템, 배터리로 동작하는 노트북, 또는 여러 모드팩을 다른 앱과 함께 실행해 두고 싶을 때. 대형 모드팩(모드 200개 이상)에는 권장하지 않습니다. 같은 총 할당량에서도 Aikar 플래그가 메모리를 더 효율적으로 회수합니다.

디버그

Performance 플래그에 GC 상세 로깅과 Java 어설션을 더해 켭니다. 모드팩 설치 폴더에 {@code gc.log} 파일을 기록하며, 모든 GC 이벤트가 타임스탬프와 함께 남습니다. 주로 모드 개발자나 반복되는 OOM 크래시를 진단하는 사람에게 유용합니다. 평상시에도 약간의 부하가 생기므로 일상적인 플레이에서는 켜 두지 마세요.

추천 대상: GC 일시 정지 관련 문제 진단, "1분마다 몇 초씩 응답하지 않는다"는 보고 조사.

없음

인수 목록이 비어 있으며 JVM 자체 기본값을 사용합니다. 체감되는 성능 문제가 프리셋 플래그 자체 때문인지 확인할 때 유용합니다 (드물지만 JDK 버전이 Aikar 플래그가 작성된 시점보다 훨씬 새로운 경우 가능합니다).

추천 대상: 프리셋이 특정 모드나 JDK 릴리스와 잘 맞지 않는다고 의심될 때 기본 동작 확인.

RAM 할당 참고 사항

프리셋은 시작 시 JVM을 조정하지만, JVM이 사용할 수 있는 메모리 양은 설정 → 계정 / 게임의 최소 RAM 및 최대 RAM 슬라이더가 결정합니다. 적절한 양은 모드팩에 따라 다릅니다:

  • 바닐라 Minecraft: 2 GB면 충분합니다.
  • 가벼운 모드팩(모드 50개 이하): 4 GB.
  • 중간 규모 모드팩(모드 50~150개): 6 GB.
  • 무거운 모드팩(모드 150개 이상, 셰이더): 8~12 GB.
  • 초대형 모드팩(모드 300개 이상, 사용자 지정 월드 생성): 12~16 GB.
경고

시스템이 감당할 수 있는 것보다 많은 RAM을 할당하면 Minecraft가 디스크로 스왑하게 되어 끊김이 줄기는커녕 더 심해집니다. 최대 RAM은 시스템 전체 RAM의 절반 이하로 유지하세요. 16 GB 시스템이라면 Minecraft에 8 GB를 넘게 할당하지 마세요.

사용자 지정 플래그

설정에서 프리셋 드롭다운 아래의 입력란은 편집할 수 있습니다. 프리셋이 맞지 않으면 직접 인수 문자열을 붙여넣을 수 있습니다. 자주 추가하는 항목:

  • -XX:+UseZGC — Z 가비지 컬렉터로 전환합니다 (일시 정지가 짧음, JDK 15 이상 필요). 매우 큰 힙(32 GB 이상)에서는 G1보다 나을 때도 있지만, 일반적인 Minecraft 환경에서는 G1에서 바꿀 만한 가치가 거의 없습니다.
  • -Dfile.encoding=UTF-8 — 기본 문자 집합이 Latin-1일 수 있는 Windows에서 모드가 ASCII가 아닌 내용이 포함된 설정 파일을 생성할 때 유용합니다.
  • -Xss2M — 스레드 스택 크기를 JVM 기본값보다 늘립니다. 호출 체인이 깊은 일부 모드팩(무거운 월드 생성 모드, 대형 차원 생성기)에는 이 설정이 필요합니다.

사용자 지정 플래그에 실수가 있으면 "Error: Could not create the Java Virtual Machine"이나 "Unrecognized VM option" 같은 메시지와 함께 실행에 실패합니다. 이런 메시지가 보이면 사용자 지정 입력란을 고치기 전에 Performance로 되돌린 뒤 다시 시도하세요.
