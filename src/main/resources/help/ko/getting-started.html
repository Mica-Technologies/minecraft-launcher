시작하기

Mica Minecraft Launcher에 오신 것을 환영합니다. 이 런처는 클릭 한 번으로 모드팩을 설치, 업데이트, 플레이할 수 있게 해 주는 크로스 플랫폼 Minecraft Forge 모드팩 런처입니다.

빠른 시작

  1. Microsoft 계정으로 로그인하세요. 런처는 공식 Microsoft 인증을 사용해 Minecraft 소유 여부를 확인합니다. 자세한 내용은 로그인을 참조하세요.
  2. 모드팩을 선택하세요. 메인 화면 왼쪽 목록에서 고를 수 있습니다. 아직 설치된 모드팩이 없다면 찾아보기에서 추가하세요.
  3. 플레이를 클릭하면 런처가 필요한 파일을 모두 자동으로 다운로드하고, 알맞은 Forge 버전을 설치하고, 파일 무결성을 검증한 뒤 게임을 실행합니다.

런처가 대신 처리하는 작업

  • 모드팩 파일(모드, 설정, 리소스) 다운로드 및 업데이트
  • 모드팩마다 알맞은 Forge 버전 설치
  • Java 런타임 관리 — JDK를 직접 설치할 필요가 없습니다
  • SHA-1 해시 검사로 파일 무결성 검증
  • 다운로드한 파일에서 알려진 악성 코드 검사
팁

모든 화면에 있는 ? 버튼을 찾아보세요. 현재 보고 있는 화면에 맞는 도움말이 열립니다.

더 알아보기

  • 메인 화면 — 런처 인터페이스 사용법
  • 설정 — 메모리, 테마, JVM 플래그 등
  • 찾아보기 — 모드팩 추가 및 제거
  • 바닐라 버전 — 모드 없는 Minecraft 플레이
  • 키보드 단축키 — 자주 쓰는 작업을 위한 키
  • 작업 참조 — 런처 곳곳에 있는 모드팩 작업의 위치
  • 언어 및 현지화 — 자동 감지, 수동 지정, 지원 언어
  • 문제 해결 — 자주 발생하는 문제와 해결 방법
