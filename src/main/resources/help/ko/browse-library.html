찾아보기

찾아보기 화면은 설치 및 관리를 위한 화면입니다. 여기에서 공개 매니페스트의 새 모드팩 설치, 순수 바닐라 Minecraft 버전 설치, 빈 Forge / NeoForge / Fabric 스타터 팩 설치, 이미 있는 팩 편집, 더 이상 필요 없는 항목 제거를 할 수 있습니다.

카드 및 필터 막대

모든 항목은 로고, 배지, 이름, 칩(로더 / Minecraft 버전), 상태 줄, 작업 버튼이 있는 히어로 카드로 표시됩니다. 상단의 필터 막대로 표시할 항목을 좁힐 수 있습니다.

  • 검색 — 카드 제목과 자유롭게 일치하는 텍스트를 찾습니다. 입력하는 동안 결과가 갱신됩니다(레이아웃이 계속 흔들리지 않도록 약간의 지연이 있습니다).
  • 유형 — 모두, 모드팩 또는 버전 카탈로그 중 하나입니다: 바닐라(정식 버전 / 스냅샷 / Old Beta / Old Alpha) 및 Forge / NeoForge / Fabric 버전. 로더 버전 필터는 의도적으로 "모두"에 포함되지 않습니다. 합치면 목록이 수천 개에 달해 "전부 보여 줘" 검색이 원하는 결과가 아니기 때문입니다.
  • 상태 — 모두, 설치됨 또는 사용 가능입니다. "사용 가능"은 아직 설치하지 않은 항목을, "설치됨"은 이미 디스크에 있는 항목을 표시합니다.
  • 정렬 — 기본, 이름 (A–Z / Z–A), 출시일, 마지막 플레이, 가장 많이 플레이, 최근 업데이트됨. 플레이 / 업데이트 기록에 따라 정렬하는 방식(마지막 플레이, 가장 많이 플레이, 최근 업데이트됨)은 모드팩이 아닌 항목을 섞지 않고 맨 아래로 보내 혼란을 줄입니다.

설치된 모드팩

이미 디스크에 있는 팩의 카드에는 두 개의 버튼이 표시됩니다:

  • 제거 — 설치 폴더도 삭제할지 묻습니다. "제거(파일 유지)"를 선택하면 런처가 더 이상 팩을 인식하지 않더라도 월드, 설정, 모드가 그대로 남습니다. 나중에 같은 팩을 다시 설치할 계획이라면 유용합니다.
  • 편집 — 팩의 로컬 매니페스트를 모드팩 편집기로 엽니다. 변경 사항은 디스크에 기록되며 다음 실행부터 적용됩니다.
팁

설치된 모드팩 카드를 마우스 오른쪽 버튼으로 클릭하면 홈 화면과 같은 컨텍스트 메뉴가 열립니다: 팩 폴더 열기, mods 폴더 열기, 바탕 화면 바로 가기 만들기, 플레이 통계 보기, 제거.

사용 가능한 모드팩

공개 매니페스트에 있지만 아직 설치하지 않은 팩의 카드에는 설치 버튼이 표시됩니다. 클릭하면 매니페스트를 다운로드하고 모드팩을 설치한 뒤, 다음 목록 갱신 때 카드가 설치됨 그룹으로 이동합니다. 설치가 진행되는 동안에도 필터를 계속 사용할 수 있으며, 진행 중인 카드는 설치가 끝날 때까지 그리드 맨 위에 고정됩니다.

바닐라 버전

Mojang의 전체 정식 버전 / 스냅샷 / 베타 / 알파 카탈로그입니다. 각 카드는 해당 Minecraft 버전을 그대로 빈 가상 모드팩으로 설치하며, 홈 화면에서 바로 플레이할 수 있습니다. 오래된 베타와 알파 버전도 실행할 수 있습니다. 런처가 버전마다 알맞은 Java 런타임을 자동으로 가져옵니다.

Forge / NeoForge / Fabric 버전

로더 버전 필터는 각 프로젝트의 버전 서비스가 제공하는 모든 릴리스를 보여 줍니다: Forge promotions, NeoForge maven 메타데이터, Fabric meta API. 이 중 하나에서 설치를 클릭하면 설정 폴더 아래에 가상의 "빈 모드팩" 매니페스트를 만들고 런처에 등록합니다. 따라서 결과물은 다른 설치된 모드팩과 똑같이 동작합니다:

  • 홈 화면의 히어로 카드에 표시됩니다.
  • 모드팩 편집기에서 편집할 수 있습니다(모드를 추가해 나만의 팩을 만들 수 있습니다).
  • 다른 팩처럼 제거할 수 있습니다.
  • 일반 모드팩과 같은 자동 업데이트 체계를 사용합니다.
참고

런처가 로컬에 캐시해 둔 경우 카드에 각 프로젝트의 공식 로고가 표시됩니다. 로더 필터를 처음 열면 실제 로고를 백그라운드에서 다운로드하는 동안 브랜드 색상의 자리 표시자가 표시되며, 캐시된 후에는 바로 표시됩니다.

URL로 추가

하단 막대의 URL에서 추가 버튼은 호스팅된 installable.json 매니페스트의 직접 URL을 받아 사용 가능한 팩 카드와 같은 방식으로 설치합니다. 공개 매니페스트 밖에서 배포되는 모드팩에 사용하세요. 링크를 붙여넣고 버튼을 클릭하면 설치를 시작하기 전에 매니페스트의 메타데이터를 다운로드하고 검증합니다.

모드팩 편집기

하단 막대의 모드팩 편집기 버튼은 빈 매니페스트로 모드팩 편집기를 열어 새 팩을 처음부터 만들 수 있게 합니다. 로더(Forge / NeoForge / Fabric / 바닐라), Minecraft 버전, 모드 목록 등을 설정하세요. 편집기는 기존 팩 카드의 편집 버튼으로도 열 수 있습니다.

호스팅 매니페스트 생성

하단 막대의 호스팅 매니페스트 생성 버튼은 편집기에 열려 있는 모드팩의 installable.json을 만듭니다. 이 파일은 어떤 웹 서버나 파일 공유 서비스에도 바로 올릴 수 있습니다. 결과 URL을 가진 사람은 누구나 URL에서 추가로 팩을 설치할 수 있습니다.

페이지 나누기

긴 목록은 여러 페이지로 나뉩니다. 카드 위의 페이지 막대에 있는 이전 / 다음 버튼으로 페이지를 이동하고, 페이지당 드롭다운으로 페이지 크기를 24, 48, 72, 96 중에서 설정하세요. 기본값 48이면 일반적인 설치 라이브러리가 한 페이지에 들어가며, 96으로 늘리면 로더 버전 필터를 한 페이지에서 스크롤해 볼 수 있습니다.
