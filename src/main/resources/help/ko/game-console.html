게임 콘솔

게임 콘솔은 로그 메시지, 경고, 오류, 크래시 리포트를 포함해 Minecraft 프로세스의 출력을 실시간으로 표시합니다.

콘솔 켜기

게임 내 콘솔이 설정의 고급 항목에서 켜져 있으면 게임과 함께 콘솔 창이 표시됩니다. 끄면 콘솔 창 없이 게임이 실행됩니다.

콘솔 기능

  • 실시간 출력 — 게임 로그가 생성되는 즉시 표시됩니다.
  • 게임 강제 종료 — 게임이 응답하지 않을 때 Minecraft 프로세스를 강제로 종료합니다. 최후의 수단으로만 사용하세요.
  • 복사 — 공유하거나 분석할 수 있도록 콘솔 내용을 클립보드에 복사합니다.

크래시 리포트

게임이 크래시되면 콘솔이 자동으로 이를 감지하고 관련 크래시 리포트를 강조 표시합니다. 다음을 할 수 있습니다:

  • 콘솔에서 전체 크래시 리포트를 바로 확인합니다.
  • 복사 버튼으로 크래시 리포트 텍스트를 복사해 모드팩 제작자나 지원 채널에 공유합니다.
참고

오래 플레이할 때 메모리 사용량을 적정하게 유지하기 위해 콘솔 표시 내용은 일부 잘립니다. 잘리지 않은 전체 로그는 디스크의 로그 파일에서 확인하세요.

로그 파일 위치

전체 게임 로그는 모드팩의 logs/ 디렉터리에 기록됩니다. 메인 화면에서 모드팩을 마우스 오른쪽 버튼으로 클릭하고 설치 폴더 열기를 선택하면 이 폴더에 빠르게 접근할 수 있습니다.

팁

크래시를 보고할 때는 크래시 리포트와 최신 로그 파일을 모두 첨부하세요. 로그에는 크래시 리포트만으로는 알 수 없는 정황이 담겨 있는 경우가 많습니다.
