모드팩 편집기

모드팩 편집기는 모드팩 JSON 정의 파일을 만들고 편집하는 내장 도구입니다. 유효성 검사, 검색 연동, 변경 사항 추적 기능이 있는 체계적인 인터페이스를 제공합니다.

도구 모음

  • 새로 만들기 — 템플릿으로 빈 모드팩 정의를 만듭니다.
  • 파일 열기 — 디스크에서 기존 JSON 정의를 불러옵니다.
  • URL 열기 — 원격 URL에서 정의를 가져와 불러옵니다.
  • 저장 — 현재 정의를 로컬 파일에 씁니다.
  • 유효성 검사 — 정의에 오류(누락된 필드, 잘못된 URL, 해시 불일치)가 있는지 검사합니다.
  • 비교 — 현재 상태를 마지막으로 저장한 버전과 비교해 무엇이 바뀌었는지 보여 줍니다.

메타데이터 필드

위쪽 섹션에는 이름, 버전, 설명, 제작자, Minecraft 버전, Forge 버전 등 모드팩의 핵심 정보가 있습니다. Forge 버전 선택으로 선택한 Minecraft 버전에 사용할 수 있는 Forge 빌드를 살펴볼 수 있습니다.

파일 탭

파일은 다음 탭으로 분류되어 있습니다:

모드mods/ 폴더에 들어가는 Forge 모드 JAR.
설정config/에 들어가는 모드 설정 파일.
리소스리소스 팩 및 기타 에셋.
셰이더OptiFine 또는 Iris용 셰이더 팩.
초기 파일처음 설치할 때만 복사되는 파일(예: 기본 options.txt).

각 파일 항목에는 다운로드 URL과 SHA-1 해시가 들어 있습니다. 편집기는 파일을 다운로드해 체크섬을 계산하는 방식으로 해시를 자동 계산할 수 있습니다.

Modrinth 검색

내장된 Modrinth 검색으로 이름을 기준으로 모드를 찾을 수 있습니다. 결과를 선택하면 알맞은 버전의 다운로드 URL과 해시 필드가 자동으로 채워집니다.

버전 올리기

버전 올리기 버튼은 모드팩의 버전 번호를 높여 주므로, 런처가 자동으로 감지하는 업데이트를 손쉽게 배포할 수 있습니다.

URL 확인

편집기는 모든 파일 다운로드 URL에 접근할 수 있는지 확인해, 배포하기 전에 깨진 링크를 찾아낼 수 있도록 도와줍니다.

팁

저장하기 전에 유효성 검사를 실행해 문제를 미리 찾으세요. 유효성 검사는 필수 필드, 올바른 URL, 올바른 해시 형식을 확인합니다.
