문제 해결

이 페이지에서는 자주 발생하는 문제와 해결 방법을 다룹니다. 원하는 문제가 여기에 없다면 런처 로그에서 오류 세부 정보를 확인하세요.

다운로드 실패

실행 중에 파일 다운로드가 실패하거나 검증 오류가 표시됩니다.

  • 인터넷 연결을 확인하고 다시 시도하세요.
  • 회사나 학교 네트워크를 사용 중이라면 설정의 네트워크 / 프록시에서 프록시를 구성하세요.
  • 다시 실행해 보세요 — 일시적인 네트워크 오류는 두 번째 시도에서 해결되는 경우가 많습니다.
  • 특정 파일이 계속 실패한다면 해당 다운로드 URL이 깨졌을 수 있습니다. 모드팩 제작자에게 알려 주세요.

오프라인 표시

런처가 인터넷 연결이 없다고 감지하면 모든 주요 화면의 도움말 버튼 옆에 빨간색 오프라인 칩이 표시됩니다. 오프라인 상태에서는:

  • 파일을 이미 모두 다운로드한 모드팩은 계속 실행할 수 있습니다.
  • 설치, 업데이트, 모드팩 편집기의 버전 선택 대화 상자는 실패하거나 오래된 데이터를 표시합니다.
  • 찾아보기 화면의 사용 가능한 팩과 로더 버전 필터는 네트워크가 복구될 때까지 비어 있습니다.
  • 기존 토큰(실행 간에 디스크에 캐시됨)이 아직 유효하다면 인증에는 영향이 없습니다.

표시는 화면을 이동할 때 갱신되므로, 네트워크가 다시 연결되면 다른 화면으로 갔다가 돌아오면 칩이 갱신됩니다.

게임 크래시

게임이 시작된 직후 또는 플레이 도중에 크래시됩니다.

  • 설정에서 게임 콘솔을 켜서 크래시 출력을 실시간으로 확인하세요.
  • 모드팩의 crash-reports/ 폴더에 있는 크래시 리포트에서 구체적인 오류 내용을 확인하세요.
  • 설정에서 최대 RAM 할당을 늘려 보세요 — 많은 모드팩에 최소 4 - 6 GB가 필요합니다.
  • 메인 화면에서 모드팩을 마우스 오른쪽 버튼으로 클릭하고 설치 폴더 열기를 선택한 다음, mods/ 폴더를 삭제하고 다시 실행해 새로 다운로드하게 하세요.
경고

RAM을 너무 많이 할당하면(시스템이 감당할 수 있는 것보다 많이) 너무 적게 할당할 때와 마찬가지로 크래시가 발생할 수 있습니다. 최대 RAM은 전체 시스템 메모리의 절반 이하로 유지하세요.

런처가 로딩 중에 멈춤

런처가 멈춘 것처럼 보이거나 진행률 표시줄이 움직이지 않습니다.

  • 몇 분 기다려 보세요 — 대형 모드팩은 특히 처음 실행할 때 파일 검증에 시간이 걸릴 수 있습니다.
  • 런처 로그에서 오류를 확인하세요(설정에서 향상된 로깅을 켜세요).
  • 최후의 수단으로 런처 재설정을 사용해 깨끗한 상태로 되돌리세요(설정에 있습니다).

오프라인 모드

런처는 인증과 파일 다운로드에 인터넷 연결이 필요합니다. 하지만 모드팩 매니페스트와 게임 파일은 처음 다운로드에 성공한 뒤 로컬에 캐시됩니다.

  • 초기 설정 후 연결이 끊겨도 캐시된 파일로 게임을 실행할 수 있습니다.
  • 인증 토큰은 약 4시간 동안 캐시됩니다 — 토큰이 아직 유효하다면 그동안 오프라인으로 플레이할 수 있습니다.

성능 문제

게임은 실행되지만 FPS가 낮거나 자주 끊깁니다.

  • JVM 프리셋을 Performance (Aikar's Flags)로 전환하세요. 설정에서 바꿀 수 있습니다.
  • RAM을 충분히 할당했는지 확인하세요 — 대부분의 모드팩에는 최소 4 GB가 필요합니다.
  • 플레이하는 동안 메모리를 많이 사용하는 다른 애플리케이션을 닫으세요.
  • 그래픽 드라이버가 최신 버전인지 확인하세요.

모드 또는 파일 누락

게임은 실행되지만 모드가 빠져 있거나 설정이 잘못되어 있습니다.

  • 런처는 실행할 때마다 파일 해시를 검증합니다. 파일을 직접 수정했다면 모드팩 정의와 일치하도록 다시 다운로드됩니다.
  • 모드팩 자체에 모드가 빠져 있다면 모드팩 제작자에게 문의하세요.
  • 모드팩을 제거했다가 다시 추가해 전체를 강제로 다시 다운로드해 보세요.

인증 문제

로그인할 수 없거나 계속해서 다시 인증하라는 요청이 표시됩니다.

  • 토큰은 약 4시간 후에 만료되므로 다시 인증하는 것은 정상입니다.
  • 로그인이 계속 실패하면 login.microsoftonline.com의 브라우저 쿠키를 지워 보세요.
  • Microsoft 계정에 유효한 Minecraft 라이선스가 있는지 확인하세요.
  • 인증 과정에 대한 자세한 내용은 로그인을 참조하세요.
팁

문제를 보고할 때는 항상 모드팩 이름과 버전, 운영 체제, 런처 로그 파일, 크래시 리포트를 함께 첨부하세요. 문제를 훨씬 빠르게 진단할 수 있습니다.
