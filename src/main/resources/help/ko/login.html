로그인

Mica Minecraft Launcher는 공식 Microsoft 인증을 사용해 Minecraft 계정을 확인합니다. 공식 Minecraft 런처와 같은 로그인 절차입니다.

작동 방식

  1. 로그인 화면에서 로그인을 클릭합니다. 브라우저 창에 Microsoft 로그인 페이지가 열립니다.
  2. Microsoft 계정 자격 증명을 입력하고 로그인을 승인합니다.
  3. 인증이 완료되면 브라우저 창이 닫히고 런처가 메인 화면으로 이동합니다.

토큰 캐시

로그인에 성공하면 인증 토큰이 기기에서 파생된 키와 AES-256-GCM 암호화를 사용해 로컬에 캐시됩니다. 즉:

  • 약 4시간 동안은 다시 로그인할 필요가 없습니다.
  • 캐시된 토큰은 암호화되어 해당 컴퓨터에 묶여 있으므로 다른 곳으로 옮기거나 재사용할 수 없습니다.
  • 캐시가 만료되면 런처가 다시 로그인하라고 요청합니다.

로그인 문제 해결

인터넷 연결 필요

처음 로그인할 때는 인터넷에 연결되어 있어야 합니다. 런처는 완전한 오프라인 모드에서 인증할 수 없습니다.

로그인에 문제가 있다면:

  • 브라우저가 열리지 않음 — 시스템에 기본 브라우저가 설정되어 있는지 확인하세요.
  • 로그인 시간 초과 — 인터넷 연결을 확인하고 다시 시도하세요.
  • 계정을 인식하지 못함 — Minecraft를 소유한 Microsoft 계정을 사용하고 있는지 확인하세요.
  • 로그인 요청이 반복됨 — 캐시된 토큰이 만료되었을 수 있습니다. 4시간 동안 사용하지 않으면 정상적으로 발생합니다.

문제가 계속되면 문제 해결을 참조하세요.
