설정

설정 화면에서는 메모리 할당, 모양, JVM 동작, 네트워크 구성 등을 사용자 지정할 수 있습니다. 변경 사항은 자동으로 저장됩니다.

게임 메모리

최소 RAM게임 JVM에 할당되는 초기 힙 크기입니다. 모드팩에서 따로 지정하지 않는 한 보통 기본값(512 MB)으로 두세요.
최대 RAM게임이 사용할 수 있는 메모리 상한입니다. 대부분의 모드팩은 4 - 8 GB에서 가장 잘 동작합니다. 시스템이 감당할 수 있는 것보다 많이 할당하면 불안정해질 수 있습니다.
팁

최대 RAM은 전체 시스템 메모리의 절반을 넘지 않게 설정하는 것이 좋습니다. 예를 들어 16 GB 컴퓨터라면 6 - 8 GB가 적당한 상한입니다.

JVM 프리셋

게임 실행 명령에 덧붙는 미리 구성된 JVM 플래그 묶음입니다. 각 프리셋의 역할, 추가할 만한 사용자 지정 플래그, 프리셋 선택과 RAM 할당의 관계에 대한 자세한 설명은 JVM 프리셋을 참조하세요.

성능 (Aikar 플래그)권장. Minecraft 커뮤니티에서 널리 쓰이는 최적화된 가비지 컬렉션 플래그입니다. 대부분의 모드팩에서 전반적으로 가장 좋은 성능을 냅니다.
저메모리RAM이 부족한 시스템을 위한 보수적인 플래그입니다. 처리량을 일부 희생하는 대신 GC 부하를 줄입니다.
디버그GC 로그를 포함한 JVM 디버그 출력을 켭니다. 크래시나 성능 문제를 진단할 때 유용합니다.
없음추가 플래그 없이 JVM 기본값을 사용합니다. 무엇을 하는지 잘 알거나 모드팩에서 요구하는 경우에만 사용하세요.

네트워크 / 프록시

네트워크에서 프록시가 필요한 경우(회사나 학교 네트워크에서 흔함) 프록시를 구성하세요.

HTTP 프록시일반적인 웹 프록시입니다. 네트워크 관리자가 알려 준 호스트와 포트를 입력하세요.
SOCKS 프록시더 낮은 수준의 프록시 프로토콜입니다. 네트워크에서 SOCKS를 명시적으로 요구할 때 사용하세요.
참고

대부분의 사용자는 프록시 설정을 비워 두어도 됩니다. 제한된 네트워크에서 다운로드나 인증이 실패할 때만 구성하세요.

악성 코드 검사

런처에는 다운로드한 JAR 파일에서 fractureiser의 시그니처를 검사하는 내장 스캐너가 있습니다. fractureiser는 2023년에 손상된 모드를 통해 퍼진 Minecraft 전용 악성 코드입니다. 검사는 게임을 실행하기 전에 매번 자동으로 실행됩니다.

초기화 및 런타임 옵션

런처 재설정모든 설정을 기본값으로 되돌리고 캐시된 데이터를 지웁니다. 이 작업은 되돌릴 수 없습니다.
런타임 관리런타임 관리 화면을 열어 설치된 Java 런타임을 확인, 검증하거나 제거합니다.
경고

런처를 재설정하면 모든 설정, 캐시된 토큰, 모드팩 상태가 삭제됩니다. 디스크의 모드팩 파일은 유지되지만 모드팩을 다시 추가해야 합니다.

설정 가져오기 / 내보내기

설정 내보내기로 현재 구성을 파일로 저장하고, 설정 가져오기로 이전에 저장한 구성을 불러올 수 있습니다. 여러 컴퓨터 간에 설정을 공유하거나 재설정 후 정상 동작하던 구성을 복원할 때 유용합니다.
