바닐라 버전

런처는 Forge 모드팩뿐 아니라 바닐라(모드 없는) Minecraft 버전도 직접 설치하고 플레이할 수 있습니다.

버전 살펴보기

바닐라 버전 화면에는 사용 가능한 Minecraft 정식 버전과 스냅샷 목록이 표시됩니다. 각 항목에는 버전 번호와 출시일이 표시됩니다. 버전을 선택하면 상세 정보를 볼 수 있습니다.

설치 및 실행

  1. 목록에서 Minecraft 버전을 선택합니다.
  2. 설치를 클릭해 해당 버전의 게임 클라이언트, 라이브러리, 에셋을 다운로드합니다.
  3. 설치가 끝나면 플레이를 클릭해 실행합니다. 파일 검증과 런타임 설정은 런처가 모두 자동으로 처리합니다.
참고

바닐라 버전은 설정에서 구성한 것과 같은 메모리 및 JVM 설정을 사용합니다. 버전이 원활하게 실행되지 않으면 RAM 할당이나 JVM 프리셋을 조정해 보세요.

런타임 관리

Minecraft 버전마다 서로 다른 Java 런타임이 필요할 수 있습니다. 런처는 버전마다 알맞은 런타임을 자동으로 다운로드하고 관리합니다 — 예를 들어 Minecraft 1.17 이상은 Java 17 이상이 필요하고, 이전 버전은 Java 8을 사용합니다.

Java를 직접 설치할 필요가 없습니다. 런타임 처리 방식에 대한 자세한 내용은 런타임 관리를 참조하세요.

팁

바닐라 버전은 대형 모드팩을 설치하기 전에 시스템이 기본 요구 사항을 충족하는지 확인하는 좋은 방법입니다.
