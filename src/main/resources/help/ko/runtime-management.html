런타임 관리

Mica Minecraft Launcher는 Java 런타임을 자동으로 관리하므로 Java를 직접 설치하거나 설정할 필요가 없습니다.

런타임이 중요한 이유

Minecraft와 Forge가 올바르게 실행되려면 특정 Java 버전이 필요합니다. 모드팩과 Minecraft 버전에 따라 서로 다른 Java 런타임이 필요할 수 있습니다:

  • Minecraft 1.16 이하 — Java 8
  • Minecraft 1.17 - 1.20 — Java 17
  • Minecraft 1.21 이상 — Java 21 이상

런처는 각 모드팩이나 바닐라 버전에 필요한 런타임을 감지하고, 처음 실행할 때 자동으로 다운로드합니다.

자동 다운로드

모드팩이나 바닐라 버전을 처음 실행하면 런처는 필요한 런타임이 이미 설치되어 있는지 확인합니다. 설치되어 있지 않으면 Mojang 또는 Liberica 배포 서버에서 알맞은 버전을 다운로드합니다. 런타임 버전마다 한 번만 다운로드합니다.

참고

런타임 다운로드 크기는 보통 40 - 80 MB이며, 시스템에 설치된 Java와는 별도로 런처의 데이터 디렉터리에 저장됩니다.

설치된 런타임 보기

설정을 열고 런타임 관리를 클릭하면 설치된 모든 Java 런타임 목록과 각 런타임의 버전, 경로, 사용하는 모드팩을 확인할 수 있습니다.

사용하지 않는 런타임 삭제

특정 Java 버전을 사용하던 모드팩을 제거했다면, 해당 런타임을 삭제해 디스크 공간을 확보할 수 있습니다. 관리 화면에서 런타임을 선택하고 삭제를 클릭하세요.

경고

설치된 모드팩에 아직 필요한 런타임을 삭제하면, 해당 모드팩을 다음에 실행할 때 런처가 런타임을 다시 다운로드합니다.

런타임 문제 해결

모드팩이 Java 관련 오류로 실행되지 않으면 다음을 시도해 보세요:

  1. 런타임 관리를 열고 문제가 있는 모드팩이 사용하는 런타임을 삭제합니다.
  2. 모드팩을 다시 실행합니다 — 런처가 새 복사본을 다시 다운로드합니다.
  3. 문제가 계속되면 문제 해결에서 추가 단계를 확인하세요.
