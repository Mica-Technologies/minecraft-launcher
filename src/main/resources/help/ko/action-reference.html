작업 참조

런처의 모든 모드팩 작업은 적어도 하나의 기본 위치에서 실행할 수 있으며, 이미 카드를 보고 있을 때 빠르게 사용할 수 있도록 컨텍스트 메뉴에도 같은 항목이 있습니다. 이 페이지에서는 각 작업이 어디에 있는지 정리해 두었으므로 일일이 찾아다닐 필요가 없습니다.

기본 위치

위치제공되는 기능
홈 화면 히어로 카드 팩마다 기본 플레이 + 웹사이트 버튼이 있습니다. 카드를 클릭하면 모드팩 상세 창이 열립니다.
모드팩 상세 창 팩별 기능이 가장 많은 곳입니다. 빠른 작업 타일 (폴더 열기 / 모드 / 설정 파일 / 스크린샷 / 리소스 팩 / 셰이더 / 바탕 화면 바로 가기 / 초대 링크 복사 / ZIP으로 내보내기), 통계, 업데이트 로그, 월드, 스크린샷 그리드, 셰이더 팩 / 리소스 팩 목록, 크래시 기록, 고급 섹션(검증), 플레이 / 웹사이트 버튼이 있습니다.
찾아보기 화면 카드 항목의 종류(모드팩 / 바닐라 / 로더 버전)에 따라 설치 / 제거 / 편집 버튼이 표시됩니다.
마우스 오른쪽 버튼 컨텍스트 메뉴 상세 창을 열지 않고도 어느 팩 카드에서나 자주 쓰는 빠른 작업을 바로 실행할 수 있습니다. 상세 창과 동일한 처리 로직을 사용합니다.
설정 런처 전체 환경설정: 계정, 게임 / 런타임, 모양, 고급, 네트워크, 보안, 시스템, Discord, RGB, 정보.

팁

팩별 작업은 거의 모두 팩 카드의 마우스 오른쪽 버튼 컨텍스트 메뉴에서도 실행할 수 있습니다. 같은 폴더를 열려고 상세 창을 반복해서 거치고 있다면 홈 화면에서 카드를 마우스 오른쪽 버튼으로 클릭해 보세요. 같은 항목을 한 번의 클릭으로 사용할 수 있습니다.
