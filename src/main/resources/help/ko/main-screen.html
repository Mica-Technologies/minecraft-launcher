메인 화면

메인 화면은 로그인한 뒤 가장 먼저 만나는 기본 화면입니다. 여기에서 설치된 모드팩을 살펴보고, 게임을 실행하고, 설정이나 모드팩 관리 화면으로 이동할 수 있습니다.

모드팩 목록

왼쪽 패널에는 설치된 모든 모드팩이 표시됩니다. 각 항목에는 모드팩 이름과 그 아래에 마지막 플레이 시간이 표시됩니다. 모드팩을 선택하면 가운데 영역에 상세 정보가 표시됩니다.

모드팩의 새 버전이 있으면 이름 옆에 녹색 업데이트 배지가 표시됩니다. 업데이트는 다음에 플레이를 클릭할 때 자동으로 적용됩니다.

팁

목록에서 모드팩을 마우스 오른쪽 버튼으로 클릭하면 추가 옵션이 있는 컨텍스트 메뉴가 열립니다:

  • 설치 폴더 열기 — 디스크에 있는 로컬 파일 살펴보기
  • mods 폴더 열기 — mods 디렉터리로 바로 이동
  • 바탕 화면 바로 가기 만들기 — 바탕 화면에서 이 모드팩을 바로 실행
  • 플레이 통계 — 총 플레이 시간과 세션 기록 보기

가운데 패널

모드팩을 선택하면 가운데 영역에 설명과 배경 이미지가 표시됩니다. 아래쪽에는 두 개의 기본 버튼이 있습니다:

  • 플레이 — 누락되었거나 업데이트된 파일을 다운로드한 뒤 게임을 실행합니다.
  • 웹사이트 — 모드팩 홈페이지가 지정되어 있으면 브라우저에서 엽니다.

탐색

  • 설정 — 런처 설정(메모리, 테마, JVM 플래그 등)을 엽니다.
  • 찾아보기 — 모드팩, 바닐라 버전, 로더 버전 스타터 팩을 위한 설치 및 관리 화면을 엽니다.
참고

설치된 모드팩이 없으면 가운데 패널에서 찾아보기를 통해 모드팩을 추가하라는 안내가 표시됩니다.
