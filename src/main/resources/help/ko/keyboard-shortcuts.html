키보드 단축키

런처는 자주 쓰는 작업을 위해 몇 가지 키보드 단축키를 제공합니다. macOS에서는 보조 키가 ⌘ Command이고, Windows와 Linux에서는 Ctrl입니다. 아래 단축키에서는 두 경우를 모두 나타내기 위해 보조 키를 ⌘/Ctrl로 표기합니다.

전역 탐색

로그인, 실행 진행, 게임 내 콘솔 창을 제외한 모든 화면에서 사용할 수 있습니다. 이 화면들은 작업 도중 실수로 다른 화면으로 넘어가지 않도록 의도적으로 탐색 단축키를 받지 않습니다.

단축키작업
⌘/Ctrl + ,설정 열기(일반적인 관례)
⌘/Ctrl + L찾아보기 화면 열기(설치 및 관리)
⌘/Ctrl + E모드팩 편집기 열기
⌘/Ctrl + Shift + M홈 화면으로 돌아가기(홈)
F1 / ⌘/Ctrl + ?현재 화면에 해당하는 항목으로 도움말 창 열기
홈으로 가는 키가 왜 Cmd+Shift+M인가요?

⌘ + M만 누르면 macOS의 "창 최소화" 시스템 단축키이므로 런처는 이를 덮어쓰지 않습니다. ⌘/Ctrl + Shift + M은 모든 플랫폼에서 이 충돌을 피합니다.

시스템 메뉴 막대(macOS)

macOS 시스템 메뉴 막대에서는 다음도 사용할 수 있습니다:

단축키작업
⌘ + R모드팩 목록 새로 고침(모드팩 메뉴 → 팩 목록 새로 고침)

홈 화면

단축키작업
Enter마지막으로 선택한 모드팩 플레이
F5사용 가능한 모드팩 새로 고침(탐색 막대의 새로 고침 아이콘과 동일)
⌘/Ctrl + F검색 입력란으로 이동

찾아보기

단축키작업
⌘/Ctrl + F검색 입력란으로 이동

모드팩 편집기

단축키작업
⌘/Ctrl + S열려 있는 매니페스트 저장
⌘/Ctrl + N새 매니페스트 시작

모드팩 상세 창

단축키작업
Esc창 닫기
팁

모든 화면 오른쪽 위에 있는 도움말 버튼(?)을 클릭해도 이 페이지나 다른 도움말 항목을 열 수 있습니다. 아이콘 위에 마우스를 올리면 화면 읽기 프로그램이 읽어 주는 것과 같은 도구 설명이 표시됩니다.
