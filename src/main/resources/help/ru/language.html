Язык и локализация

Интерфейс Mica Minecraft Launcher доступен на 17 языках, и при первом запуске лаунчер автоматически выбирает подходящий. Определённый язык можно в любой момент изменить в настройках.

Как лаунчер выбирает язык

При каждом запуске лаунчер определяет активный язык в следующем порядке:

  1. Ваш сохранённый выбор, если вы задали его в разделе Настройки → Внешний вид → Язык. Он всегда имеет приоритет.
  2. Язык операционной системы, определяемый через стандартную локаль JVM. В Windows это параметр «Регион» / «Язык»; в macOS — «Системные настройки» → «Язык и регион»; в Linux — переменные окружения LANG / LC_*.
  3. Английский (США) — резервный вариант, если платформа сообщает локаль без языка (например, POSIX или C) или если язык вашей ОС не входит в 17 языков, для которых есть переводы.
Смена языка вступает в силу после перезапуска

Изменение выбора в настройках сразу обновляет параметр, но уже открытые экраны продолжают показывать прежний язык до перезапуска лаунчера. Страница настроек сама напоминает об этом, когда вы меняете значение в раскрывающемся списке.

Выбор языка вручную

  1. Откройте Настройки на панели навигации (или нажмите Ctrl+, / Cmd+,).
  2. Перейдите на вкладку Внешний вид.
  3. Выберите язык в раскрывающемся списке Язык. Первый пункт («Использовать язык ОС») восстанавливает автоопределение, описанное выше, и показывает в скобках, какой язык будет выбран по настройкам ОС.
  4. Нажмите Сохранить. Перезапустите лаунчер, чтобы новый язык применился ко всем экранам.

Поддерживаемые языки

Лаунчер поставляется с переводами на 17 самых распространённых языков мира, включая английский:

  • Арабский (عربي)
  • Китайский, упрощённый (简体中文)
  • Китайский, традиционный (繁體中文)
  • Нидерландский (Nederlands)
  • Английский (исходный язык)
  • Французский (Français)
  • Немецкий (Deutsch)
  • Хинди (हिंदी)
  • Итальянский (Italiano)
  • Японский (日本語)
  • Корейский (한국어)
  • Польский (Polski)
  • Португальский, бразильский (Português do Brasil)
  • Русский (Русский)
  • Испанский (Español)
  • Шведский (Svenska)
  • Турецкий (Türkçe)

Каждый язык обозначается тегом BCP-47 (например, fr-FR, pt-BR, zh-CN). Список находится в SupportedLocales.ENTRIES в исходном коде лаунчера, а файлы свойств лежат рядом как DisplayStrings_<tag>.properties в src/main/resources/lang/.

Качество перевода и сообщения о проблемах

Переводы на языки, отличные от английского, создаются скриптом, который обращается к Google Translate с английским исходным набором строк, а затем обрабатывает заполнители параметров, чтобы такие элементы, как {0}, сохранялись при переводе. Результат хороший, но не идеальный — в частности, короткие подписи интерфейса (кнопки из одного слова, отдельные существительные) иногда теряют контекст, который был у них в английском.

Если вы заметили неудачный перевод, лучше всего открыть issue на GitHub, указав имя ключа (например, browse.filter.type.label), вашу локаль, текущий вариант и предлагаемое исправление. Исправления, внесённые вручную, сохраняются при следующей генерации, потому что скрипт по умолчанию заполняет только отсутствующие ключи.

Добавление нового языка

Если вашего языка нет в списке выше и вы хотите предложить перевод, порядок действий такой:

  1. Добавьте новую запись в SupportedLocales.ENTRIES (Java) и в TARGET_LOCALES в tools/i18n/translate-locales.js (Node).
  2. Выполните cd tools/i18n && npm run translate — скрипт создаст исходный файл DisplayStrings_<tag>.properties из английского источника.
  3. Проверьте созданный файл, вручную исправьте всё, что звучит неестественно, и откройте pull request.

Скрипт tools/i18n/translate-locales.js работает инкрементно: при повторном запуске он переводит только ключи, которых ещё нет в целевом файле, поэтому ручные исправления сохраняются при каждом последующем обновлении лаунчера.
