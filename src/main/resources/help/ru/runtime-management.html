Управление средами выполнения

Mica Minecraft Launcher автоматически управляет средами выполнения Java, поэтому вам никогда не придётся устанавливать или настраивать Java самостоятельно.

Почему важны среды выполнения

Для корректной работы Minecraft и Forge нужны определённые версии Java. Разным модпакам и версиям Minecraft могут требоваться разные среды выполнения Java:

  • Minecraft 1.16 и более ранние — Java 8
  • Minecraft 1.17 - 1.20 — Java 17
  • Minecraft 1.21+ — Java 21 или новее

Лаунчер определяет, какая среда выполнения нужна каждому модпаку или ванильной версии, и автоматически загружает её при первом запуске.

Автоматическая загрузка

При первом запуске модпака или ванильной версии лаунчер проверяет, установлена ли нужная среда выполнения. Если нет, он загружает подходящую версию с серверов Mojang или Liberica. Каждая версия среды выполнения загружается только один раз.

Примечание

Размер загружаемой среды выполнения обычно 40 - 80 МБ. Она хранится в каталоге данных лаунчера отдельно от любой установленной в системе Java.

Просмотр установленных сред выполнения

Откройте Настройки и нажмите Управление средами выполнения, чтобы увидеть список всех установленных сред выполнения Java с их версией, путём и модпаками, которые их используют.

Удаление неиспользуемых сред выполнения

Если вы удалили модпаки, которые использовали определённую версию Java, соответствующую среду выполнения можно удалить, чтобы освободить место на диске. Выберите среду выполнения на экране управления и нажмите Удалить.

Предупреждение

Если удалить среду выполнения, которая всё ещё нужна установленному модпаку, лаунчер снова загрузит её при следующем запуске этого модпака.

Устранение проблем со средами выполнения

Если модпак не запускается из-за ошибок, связанных с Java, попробуйте следующее:

  1. Откройте «Управление средами выполнения» и удалите среду выполнения, которую использует проблемный модпак.
  2. Снова запустите модпак — лаунчер загрузит новую копию.
  3. Если проблема сохраняется, дополнительные шаги см. в разделе Устранение неполадок.
