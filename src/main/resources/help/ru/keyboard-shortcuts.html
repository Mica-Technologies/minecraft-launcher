Сочетания клавиш

В лаунчере есть небольшой набор сочетаний клавиш для самых частых действий. В macOS клавиша-модификатор — ⌘ Command, в Windows и Linux — Ctrl. В сочетаниях ниже модификатор обозначен как ⌘/Ctrl, чтобы охватить оба варианта.

Общая навигация

Доступны на всех экранах, кроме экрана входа, экрана хода запуска и окна внутриигровой консоли — эти экраны намеренно не принимают сочетания для навигации, чтобы вы случайно не ушли с них посреди процесса.

СочетаниеДействие
⌘/Ctrl + ,Открыть настройки (общепринятое сочетание)
⌘/Ctrl + LОткрыть экран «Обзор» (установка и управление)
⌘/Ctrl + EОткрыть Редактор модпаков
⌘/Ctrl + Shift + MВернуться в главное меню («Главная»)
F1 / ⌘/Ctrl + ?Открыть окно справки на теме текущего экрана
Почему Cmd+Shift+M для «Главной»?

Простое сочетание ⌘ + M в macOS — системное сочетание «Свернуть окно», и лаунчер не переопределяет его. ⌘/Ctrl + Shift + M обходит этот конфликт на всех платформах.

Совет

Кнопка справки (?) в правом верхнем углу каждого экрана — удобный способ открыть эту страницу или любую другую тему справки щелчком мыши. Наведите указатель на её значок, и вы увидите ту же подсказку, которую зачитывает средство чтения с экрана.
