Обзор

Экран «Обзор» — место для установки и управления. Здесь можно устанавливать новые модпаки из общедоступного манифеста, устанавливать чистые ванильные версии Minecraft, устанавливать пустые стартовые паки Forge / NeoForge / Fabric, редактировать уже имеющиеся модпаки и удалять то, что больше не нужно.

Карточки и панель фильтров

Каждая запись отображается в виде крупной карточки с логотипом, значком, названием, метками (загрузчик / версия Minecraft), строкой состояния и кнопками действий. Панель фильтров в верхней части позволяет сузить список.

  • Поиск — поиск по произвольному тексту в названиях карточек. Обновляется по мере ввода (с небольшой задержкой, чтобы не перестраивать макет при каждом нажатии).
  • Тип — «Все», «Модпаки» или один из каталогов версий: Vanilla (релизы / снапшоты / старые бета-версии / старые альфа-версии) и версии Forge / NeoForge / Fabric. Фильтры версий загрузчиков намеренно не входят в «Все»: объединённый список содержал бы тысячи записей, а это не то, что нужно при поиске «показать всё».
  • Статус — «Все», «Установленные» или «Доступные». «Доступные» показывает то, что вы ещё не установили; «Установленные» — то, что уже есть на диске.
  • Сортировка — «По умолчанию», «Название (А–Я / Я–А)», «Дата выпуска», «Последний запуск», «По времени игры», «Недавно обновлено». Сортировки, зависящие от истории игры / обновлений («Последний запуск», «По времени игры», «Недавно обновлено»), опускают записи, не являющиеся модпаками, в конец списка, а не перемешивают их с модпаками.

Установленные модпаки

На карточках модпаков, которые уже есть на диске, показаны две кнопки:

  • Удалить — спрашивает, удалить ли также папку установки. «Удалить (сохранить файлы)» сохраняет ваши миры, конфигурации и моды, хотя лаунчер больше не знает об этом модпаке, — это удобно, если вы планируете позже установить тот же модпак снова.
  • Редактировать — открывает Редактор модпаков с локальным манифестом модпака. Изменения записываются на диск и вступают в силу при следующем запуске.
Совет

Щёлкните карточку установленного модпака правой кнопкой мыши, чтобы открыть то же контекстное меню, что и в главном меню: открыть папку модпака, открыть папку модов, создать ярлык на рабочем столе, посмотреть статистику игры и удалить модпак.

Доступные модпаки

На карточках из общедоступного манифеста, которых у вас ещё нет, есть кнопка Установить. Нажатие на неё загружает манифест, устанавливает модпак и при следующем обновлении списка переносит карточку в группу установленных. Пока идёт установка, можно продолжать пользоваться фильтрами — карточка устанавливаемого модпака остаётся закреплённой вверху сетки до завершения установки.

Ванильные версии

Полный каталог Mojang: релизы / снапшоты / бета-версии / альфа-версии. Каждая карточка устанавливает именно эту версию Minecraft в виде синтетического пустого модпака, который можно запускать прямо из главного меню. Старые бета- и альфа-версии тоже запускаются — лаунчер автоматически загружает подходящую среду выполнения Java для каждой версии.

Версии Forge / NeoForge / Fabric

Фильтры версий загрузчиков показывают все выпуски, которые публикует служба версий каждого проекта: рекомендованные сборки Forge, метаданные Maven NeoForge и API Fabric meta. Нажатие «Установить» на одной из таких карточек записывает синтетический манифест «пустого модпака» в папку конфигурации и регистрирует его в лаунчере, поэтому результат ведёт себя как любой другой установленный модпак:

  • отображается в крупных карточках главного меню;
  • редактируется в Редакторе модпаков (можно добавить моды поверх и собрать собственный модпак);
  • удаляется так же, как любой другой модпак;
  • использует тот же механизм автообновления, что и обычный модпак.
Примечание

На карточках показывается официальный логотип каждого проекта, если он кэширован локально. При первом открытии фильтра загрузчика отображается заглушка в фирменном цвете, пока настоящие логотипы загружаются в фоне; после кэширования последующие открытия происходят мгновенно.

Добавление по URL

Кнопка Добавить из URL на нижней панели принимает прямой URL размещённого манифеста installable.json и устанавливает его так же, как карточки доступных модпаков. Используйте её для модпаков, распространяемых вне общедоступного манифеста: вставьте ссылку, нажмите кнопку, и метаданные манифеста будут загружены и проверены перед началом установки.

Редактор модпаков

Кнопка Редактор модпаков на нижней панели открывает Редактор модпаков с пустым манифестом, чтобы вы могли собрать новый модпак с нуля: задать загрузчик (Forge / NeoForge / Fabric / vanilla), версию Minecraft, список модов и т. д. Редактор также можно открыть для существующего модпака кнопкой Редактировать на его карточке.

Создание манифеста хостинга

Кнопка Создать манифест хостинга на нижней панели создаёт installable.json для модпака, открытого в редакторе, — его можно разместить на любом веб-сервере или файлообменном сервисе. Любой, у кого есть полученный URL, сможет установить ваш модпак через «Добавить из URL».

Постраничный просмотр

Длинные списки разбиты на страницы. Кнопки Назад / Далее на панели страниц (над карточками) переключают страницы, а раскрывающийся список На странице задаёт размер страницы — 24, 48, 72 или 96. Значение по умолчанию 48 позволяет уместить типичную установленную библиотеку на одной странице; при значении 96 фильтры версий загрузчиков прокручиваются в пределах одной страницы.
