Ванильные версии

Помимо модпаков Forge, лаунчер может напрямую устанавливать и запускать версии ванильного Minecraft (без модов).

Просмотр версий

Экран ванильных версий показывает список доступных релизов и снапшотов Minecraft. Для каждой версии указаны номер и дата выпуска. Выберите версию, чтобы посмотреть подробности.

Установка и запуск

  1. Выберите версию Minecraft в списке.
  2. Нажмите Установить, чтобы загрузить игровой клиент, библиотеки и ресурсы для этой версии.
  3. После установки нажмите Играть. Лаунчер автоматически выполнит проверку всех файлов и настройку среды выполнения.
Примечание

Ванильные версии используют те же параметры памяти и JVM, что заданы в настройках. Если версия работает плохо, попробуйте изменить объём выделенной ОЗУ или предустановку JVM.

Управление средами выполнения

Разным версиям Minecraft могут требоваться разные среды выполнения Java. Лаунчер автоматически загружает нужную среду выполнения для каждой версии и управляет ею: например, Minecraft 1.17+ требует Java 17 или новее, а более старые версии используют Java 8.

Устанавливать Java вручную не нужно. Подробнее о работе со средами выполнения см. в разделе Управление средами выполнения.

Совет

Ванильные версии — хороший способ проверить, соответствует ли ваша система базовым требованиям, прежде чем устанавливать крупные модпаки.
