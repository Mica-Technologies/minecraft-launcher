Справочник действий

Каждое действие с модпаком в лаунчере доступно как минимум из одного основного места, а для быстрого доступа продублировано в контекстном меню, когда вы уже смотрите на карточку. На этой странице указано, где находится каждое действие, чтобы вам не приходилось его искать.

Основные места

МестоЧто здесь находится
Крупные карточки главного меню Основные кнопки Играть и Сайт для каждого модпака. Щелчок по карточке открывает окно сведений.
Окно сведений о модпаке Самое полное место для каждого модпака: плитки «Быстрые действия» (Открыть папку / Моды / Конфигурация / Скриншоты / Наборы ресурсов / Шейдеры / Ярлык на рабочем столе / Копировать ссылку-приглашение / Экспорт в ZIP), «Статистика», «Журнал обновлений», «Миры», сетка «Скриншоты», списки «Наборы шейдеров» / «Наборы ресурсов», «История сбоев», раздел «Дополнительно» (проверка) и кнопки действий «Играть» / «Сайт».
Карточки экрана «Обзор» Установить / Удалить / Редактировать в зависимости от вида записи (модпак / ванильная версия / версия загрузчика).
Контекстное меню (правая кнопка мыши) Быстрый доступ к частым быстрым действиям из любой карточки модпака без открытия окна сведений. Использует те же обработчики, что и окно.
Настройки Общие параметры лаунчера: учётная запись, игра / среда выполнения, внешний вид, дополнительно, сеть, безопасность, система, Discord, RGB, «О программе».

Совет

Почти у каждого действия с модпаком есть ярлык в контекстном меню карточки модпака. Если вы раз за разом проходите через окно сведений только ради одной и той же папки, попробуйте щёлкнуть карточку правой кнопкой мыши в главном меню — те же пункты находятся в одном щелчке.
