Редактор модпаков

Редактор модпаков — встроенный инструмент для создания и редактирования JSON-файлов определения модпаков. Он предоставляет структурированный интерфейс с проверкой, встроенным поиском и отслеживанием изменений.

Панель инструментов

  • Создать — создать пустое определение модпака из шаблона.
  • Открыть файл — загрузить существующее JSON-определение с диска.
  • Открыть URL — получить и загрузить определение по удалённому URL.
  • Сохранить — записать текущее определение в локальный файл.
  • Проверить — проверить определение на ошибки (отсутствующие поля, недопустимые URL, несовпадение хешей).
  • Различия — сравнить текущее состояние с последней сохранённой версией и увидеть, что изменилось.

Поля метаданных

В верхней части находятся основные сведения о модпаке: название, версия, описание, автор, версия Minecraft и версия Forge. Выбор версии Forge позволяет просматривать доступные сборки Forge для выбранной версии Minecraft.

Вкладки файлов

Файлы распределены по вкладкам-категориям:

МодыJAR-файлы модов Forge, помещаемые в папку mods/.
КонфигурацииФайлы конфигурации модов, помещаемые в config/.
РесурсыНаборы ресурсов и другие ресурсы.
ШейдерыНаборы шейдеров для OptiFine или Iris.
Начальные файлыФайлы, копируемые только при первой установке (например, options.txt по умолчанию).

Для каждого файла указываются URL загрузки и хеш SHA-1. Редактор может автоматически вычислять хеши: он загружает файл и вычисляет его контрольную сумму.

Поиск в Modrinth

Используйте встроенный поиск Modrinth, чтобы находить моды по названию. Выберите результат, и поля URL загрузки и хеша будут автоматически заполнены для нужной версии.

Повышение версии

Кнопка повышения версии увеличивает номер версии модпака, упрощая публикацию обновлений, которые лаунчер обнаружит автоматически.

Проверка URL

Редактор может проверить доступность всех URL загрузки файлов, чтобы вы находили неработающие ссылки до публикации.

Совет

Нажимайте Проверить перед сохранением, чтобы выявить проблемы заранее. Проверка находит отсутствующие обязательные поля, недопустимые URL и неверный формат хешей.
