Главный экран

Главный экран — ваша отправная точка после входа. Здесь можно просматривать установленные модпаки, запускать игру и переходить к настройкам или управлению модпаками.

Список модпаков

На левой панели показаны все установленные модпаки. Для каждого указаны название и время последнего запуска. Выберите модпак, чтобы увидеть сведения о нём в центральной области.

Если для модпака доступна новая версия, рядом с его названием появляется зелёный значок ОБНОВЛЕНИЕ. Обновление применяется автоматически при следующем нажатии «Играть».

Совет

Щёлкните правой кнопкой мыши по любому модпаку в списке, чтобы открыть контекстное меню с дополнительными действиями:

  • Открыть папку установки — просмотр локальных файлов на диске
  • Открыть папку модов — прямой переход в каталог модов
  • Создать ярлык на рабочем столе — запуск этого модпака прямо с рабочего стола
  • Статистика игры — общее время игры и история сеансов

Центральная панель

При выборе модпака в центральной области отображаются его описание и фоновое изображение. Внизу находятся две основные кнопки:

  • Играть — загружает недостающие или обновлённые файлы, а затем запускает игру.
  • Сайт — открывает домашнюю страницу модпака в браузере (если она указана).

Навигация

  • Настройки — открывает настройки лаунчера (память, тема, флаги JVM и многое другое).
  • Обзор — открывает экран установки и управления модпаками, ванильными версиями и стартовыми паками версий загрузчиков.
Примечание

Если модпаки не установлены, центральная панель предложит добавить модпак через Обзор.
