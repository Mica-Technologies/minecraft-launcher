Начало работы

Добро пожаловать в Mica Minecraft Launcher — кроссплатформенный лаунчер модпаков Minecraft Forge, с которым установка, обновление и запуск модпаков выполняются одним щелчком.

Быстрый старт

  1. Войдите с учётной записью Microsoft. Лаунчер использует официальную аутентификацию Microsoft, чтобы подтвердить, что у вас есть Minecraft. Подробнее см. в разделе Вход.
  2. Выберите модпак в списке слева на главном экране. Если модпаки ещё не установлены, добавьте модпак через Обзор.
  3. Нажмите «Играть» — лаунчер автоматически загрузит все необходимые файлы, установит нужную версию Forge, проверит целостность файлов и запустит игру.

Что лаунчер делает за вас

  • Загружает и обновляет файлы модпаков (моды, конфигурации, ресурсы)
  • Устанавливает нужную версию Forge для каждого модпака
  • Управляет средами выполнения Java — устанавливать JDK вручную не нужно
  • Проверяет целостность файлов по хешам SHA-1
  • Проверяет загруженные файлы на известное вредоносное ПО
Совет

Ищите кнопку ? на каждом экране — она открывает контекстную справку по экрану, на котором вы находитесь.

Что ещё почитать

  • Главный экран — навигация по интерфейсу лаунчера
  • Настройки — память, темы, флаги JVM и многое другое
  • Обзор — добавление и удаление модпаков
  • Ванильные версии — игра в Minecraft без модов
  • Сочетания клавиш — клавиши для самых частых действий
  • Справочник действий — где в лаунчере находится каждое действие с модпаком
  • Язык и локализация — автоопределение, ручной выбор, поддерживаемые языки
  • Устранение неполадок — частые проблемы и их решения
