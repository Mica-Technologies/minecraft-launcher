क्रिया संदर्भ

लॉन्चर में हर मॉडपैक क्रिया कम से कम एक मुख्य स्थान से उपलब्ध है, और जब आप पहले से किसी कार्ड को देख रहे हों तो तेज़ पहुँच के लिए संदर्भ मेनू में उसकी एक प्रति भी होती है। यह पेज बताता है कि हर क्रिया कहाँ है, ताकि आपको उसे खोजना न पड़े।

मुख्य स्थान

स्थानयहाँ क्या मिलता है
मुख्य मेनू के बड़े कार्ड हर पैक के लिए मुख्य खेलें और वेबसाइट बटन। कार्ड पर क्लिक करने से विवरण विंडो खुलती है।
मॉडपैक विवरण विंडो हर पैक के लिए सबसे समृद्ध स्थान: त्वरित क्रियाएँ टाइलें (फ़ोल्डर खोलें / मॉड / कॉन्फ़िग / स्क्रीनशॉट / रिसोर्स पैक / शेडर / डेस्कटॉप शॉर्टकट / आमंत्रण लिंक कॉपी करें / ZIP के रूप में निर्यात करें), आँकड़े, अपडेट लॉग, वर्ल्ड, स्क्रीनशॉट ग्रिड, शेडर / रिसोर्स पैक सूचियाँ, क्रैश इतिहास, उन्नत अनुभाग (सत्यापन), और खेलें / वेबसाइट क्रिया बटन।
ब्राउज़ स्क्रीन के कार्ड प्रविष्टि के प्रकार (मॉडपैक / वैनिला / लोडर संस्करण) के अनुसार इंस्टॉल करें / अनइंस्टॉल करें / संपादित करें।
राइट-क्लिक संदर्भ मेनू विवरण विंडो खोले बिना किसी भी पैक कार्ड से आम त्वरित क्रियाओं तक तेज़ पहुँच। विंडो वाले सभी हैंडलर ही साझा करता है।
सेटिंग्स पूरे लॉन्चर की प्राथमिकताएँ: खाता, गेम / रनटाइम, रूप-रंग, उन्नत, नेटवर्क, सुरक्षा, सिस्टम, Discord, RGB, परिचय।

हर क्रिया कहाँ मिलेगी

क्रियामुख्य स्थानइसके ज़रिए भी उपलब्ध
मॉडपैक खेलेंबड़े कार्ड का खेलें बटन / विवरण विंडो का खेलें बटनराइट-क्लिक → (कोई नहीं — कार्ड पर क्लिक करने से विवरण विंडो के ज़रिए अप्रत्यक्ष रूप से खेल शुरू होता है)
इंस्टॉल फ़ोल्डर खोलेंविवरण विंडो की त्वरित क्रियाएँराइट-क्लिक संदर्भ मेनू
mods / config / screenshots / shaderpacks / resourcepacks खोलेंविवरण विंडो की त्वरित क्रियाएँराइट-क्लिक संदर्भ मेनू
वर्ल्ड / स्क्रीनशॉट / शेडर पैक / रिसोर्स पैक / क्रैश इतिहास देखेंविवरण विंडो का संबंधित अनुभाग—
मॉडपैक मैनिफ़ेस्ट संपादित करेंब्राउज़ कार्ड का संपादित करें बटनराइट-क्लिक → पैक संपादित करें…
पैक अनइंस्टॉल करेंब्राउज़ कार्ड का अनइंस्टॉल करें बटनराइट-क्लिक → अनइंस्टॉल करें…
डेस्कटॉप शॉर्टकट बनाएँविवरण विंडो की त्वरित क्रियाएँराइट-क्लिक संदर्भ मेनू
Discord आमंत्रण लिंक कॉपी करेंविवरण विंडो की त्वरित क्रियाएँराइट-क्लिक संदर्भ मेनू
पैक को ZIP के रूप में निर्यात करेंविवरण विंडो की त्वरित क्रियाएँराइट-क्लिक → ZIP के रूप में निर्यात करें…
पैक फ़ाइलें सत्यापित करेंविवरण विंडो का उन्नत अनुभागसेटिंग्स → सुरक्षा → सभी गेम फ़ाइलों को सत्यापित करें (वैश्विक विकल्प)
वैनिला / लोडर संस्करण इंस्टॉल करेंब्राउज़ करें—
Microsoft खाता बदलेंसेटिंग्स → खाता → खातेसाइन आउट करें बटन (एक-खाता उपयोग)
भाषा बदलेंसेटिंग्स → रूप-रंग → भाषा—
RAM / JVM फ़्लैग समायोजित करेंसेटिंग्स → गेम / उन्नत—
सुझाव

लगभग हर पैक-विशिष्ट क्रिया का पैक के कार्ड पर राइट-क्लिक संदर्भ मेनू में शॉर्टकट होता है। अगर आप बार-बार सिर्फ़ उसी फ़ोल्डर तक पहुँचने के लिए विवरण विंडो से गुज़रते हैं, तो मुख्य मेनू पर कार्ड पर राइट-क्लिक करके देखें — वही आइटम एक क्लिक की दूरी पर हैं।
