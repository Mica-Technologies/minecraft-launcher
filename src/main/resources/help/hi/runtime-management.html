रनटाइम प्रबंधन

Mica Minecraft Launcher Java रनटाइम को अपने आप प्रबंधित करता है, इसलिए आपको Java को कभी भी खुद इंस्टॉल या कॉन्फ़िगर करने की ज़रूरत नहीं होती।

रनटाइम क्यों मायने रखते हैं

Minecraft और Forge को सही ढंग से चलने के लिए विशिष्ट Java संस्करणों की ज़रूरत होती है। अलग-अलग मॉडपैक और Minecraft संस्करणों को अलग-अलग Java रनटाइम चाहिए हो सकते हैं:

  • Minecraft 1.16 और उससे पहले — Java 8
  • Minecraft 1.17 - 1.20 — Java 17
  • Minecraft 1.21+ — Java 21 या बाद का

लॉन्चर पता लगाता है कि हर मॉडपैक या वैनिला संस्करण को कौन-सा रनटाइम चाहिए और पहली बार लॉन्च करने पर उसे अपने आप डाउनलोड कर लेता है।

स्वचालित डाउनलोड

जब आप किसी मॉडपैक या वैनिला संस्करण को पहली बार लॉन्च करते हैं, तो लॉन्चर जाँचता है कि ज़रूरी रनटाइम पहले से इंस्टॉल है या नहीं। अगर नहीं, तो वह सही संस्करण Mojang या Liberica के डिस्ट्रिब्यूशन सर्वर से डाउनलोड करता है। हर रनटाइम संस्करण के लिए यह एक बार का डाउनलोड है।

नोट

रनटाइम डाउनलोड आमतौर पर 40 - 80 MB के होते हैं और लॉन्चर की डेटा डायरेक्टरी में संग्रहीत होते हैं, जो आपके सिस्टम पर मौजूद किसी भी Java इंस्टॉलेशन से अलग है।

इंस्टॉल किए गए रनटाइम देखना

सेटिंग्स खोलें और रनटाइम प्रबंधन पर क्लिक करें, ताकि सभी इंस्टॉल किए गए Java रनटाइम की सूची देख सकें, जिसमें उनका संस्करण, पथ और उन्हें उपयोग करने वाले मॉडपैक शामिल हैं।

अप्रयुक्त रनटाइम हटाना

अगर आपने किसी विशेष Java संस्करण का उपयोग करने वाले मॉडपैक हटा दिए हैं, तो डिस्क स्थान खाली करने के लिए संबंधित रनटाइम को हटा सकते हैं। प्रबंधन स्क्रीन में कोई रनटाइम चुनें और हटाएँ पर क्लिक करें।

चेतावनी

किसी इंस्टॉल किए गए मॉडपैक को अभी भी ज़रूरी रनटाइम हटाने पर, लॉन्चर उस मॉडपैक के अगले लॉन्च पर उसे फिर से डाउनलोड करेगा।

रनटाइम समस्याओं का निवारण

अगर कोई मॉडपैक Java से संबंधित त्रुटियों के कारण लॉन्च नहीं होता, तो ये आज़माएँ:

  1. रनटाइम प्रबंधन खोलें और प्रभावित मॉडपैक द्वारा उपयोग किया जाने वाला रनटाइम हटाएँ।
  2. मॉडपैक को फिर से लॉन्च करें — लॉन्चर एक नई प्रति डाउनलोड करेगा।
  3. अगर समस्या बनी रहती है, तो अतिरिक्त चरणों के लिए समस्या निवारण देखें।
