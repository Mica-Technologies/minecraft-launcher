वैनिला संस्करण

Forge मॉडपैक के अलावा, लॉन्चर वैनिला (बिना मॉड वाले) Minecraft संस्करणों को भी सीधे इंस्टॉल करके चला सकता है।

संस्करण ब्राउज़ करना

वैनिला संस्करण स्क्रीन उपलब्ध Minecraft रिलीज़ और स्नैपशॉट की सूची दिखाती है। हर प्रविष्टि में संस्करण संख्या और रिलीज़ तिथि दिखती है। विवरण देखने के लिए कोई संस्करण चुनें।

इंस्टॉल करना और लॉन्च करना

  1. सूची से कोई Minecraft संस्करण चुनें।
  2. उस संस्करण का गेम क्लाइंट, लाइब्रेरी और एसेट डाउनलोड करने के लिए इंस्टॉल करें पर क्लिक करें।
  3. इंस्टॉल होने के बाद, लॉन्च करने के लिए खेलें पर क्लिक करें। लॉन्चर सभी फ़ाइलों का सत्यापन और रनटाइम सेटअप अपने आप संभालता है।
नोट

वैनिला संस्करण वही मेमोरी और JVM सेटिंग्स उपयोग करते हैं जो सेटिंग्स में कॉन्फ़िगर की गई हैं। अगर कोई संस्करण ठीक से नहीं चलता, तो अपना RAM आवंटन या JVM प्रीसेट बदलकर देखें।

रनटाइम प्रबंधन

अलग-अलग Minecraft संस्करणों को अलग-अलग Java रनटाइम की ज़रूरत हो सकती है। लॉन्चर हर संस्करण के लिए सही रनटाइम अपने आप डाउनलोड और प्रबंधित करता है — उदाहरण के लिए, Minecraft 1.17+ को Java 17 या बाद का संस्करण चाहिए, जबकि पुराने संस्करण Java 8 का उपयोग करते हैं।

आपको Java मैन्युअल रूप से इंस्टॉल करने की ज़रूरत नहीं है। रनटाइम को कैसे संभाला जाता है, इसके बारे में अधिक जानकारी के लिए रनटाइम प्रबंधन देखें।

सुझाव

बड़े मॉडपैक इंस्टॉल करने से पहले यह जाँचने का कि आपका सिस्टम बुनियादी आवश्यकताएँ पूरी करता है या नहीं, वैनिला संस्करण एक अच्छा तरीका हैं।
