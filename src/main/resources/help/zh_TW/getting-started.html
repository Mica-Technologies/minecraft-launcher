入門

歡迎使用 Mica Minecraft 啟動器：這是一款跨平台的 Minecraft Forge 模組包啟動器， 只要按一下，就能輕鬆安裝、更新並遊玩模組包。

快速入門

  1. 登入您的 Microsoft 帳號。啟動器會使用 Microsoft 官方驗證來確認您擁有 Minecraft。詳情請參閱登入。
  2. 選擇模組包：從主畫面左側的清單中選取。 如果尚未安裝任何模組包，請使用瀏覽新增一個。
  3. 按一下「遊玩」，啟動器就會自動下載所有必要的檔案、 安裝正確的 Forge 版本、驗證檔案完整性，然後啟動遊戲。

啟動器會替您處理的事項

  • 下載並更新模組包檔案（模組、設定檔、資源）
  • 為每個模組包安裝正確的 Forge 版本
  • 管理 Java 執行環境，不需要手動安裝 JDK
  • 以 SHA-1 雜湊檢查驗證檔案完整性
  • 掃描下載的檔案是否含有已知的惡意程式
提示
