鍵盤快速鍵

啟動器為您最常執行的動作提供了一小組鍵盤快速鍵。 在 macOS 上，輔助鍵是 ⌘ Command；在 Windows 與 Linux 上則是 Ctrl。 下方的快速鍵以 ⌘/Ctrl 表示輔助鍵，同時涵蓋兩種情況。

全域導覽

除了登入、啟動進度與遊戲內主控台視窗之外，所有畫面都可使用； 這些畫面刻意不接受導覽快速鍵，以免您在流程進行到一半時 不小心離開。

快速鍵動作
⌘/Ctrl + ,開啟設定（通用慣例）
⌘/Ctrl + L開啟「瀏覽」畫面（安裝與管理）
⌘/Ctrl + E開啟模組包編輯器
⌘/Ctrl + Shift + M返回主選單（首頁）
F1 / ⌘/Ctrl + ?開啟說明視窗並顯示目前畫面的主題
為什麼「首頁」是 Cmd+Shift+M？

單獨的 ⌘ + M 是 macOS 的「最小化視窗」系統快速鍵， 啟動器會避免覆寫它。⌘/Ctrl + Shift + M 則能在所有平台上 避開此衝突。
