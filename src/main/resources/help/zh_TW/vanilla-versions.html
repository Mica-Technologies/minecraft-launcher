原版版本

除了 Forge 模組包之外，啟動器也能直接安裝並遊玩原版（未安裝模組的） Minecraft 版本。

瀏覽版本

原版版本畫面會列出可用的 Minecraft 正式版與快照。 每個項目都會顯示版本號碼與發布日期。選取版本即可查看其詳細資料。

安裝與啟動

  1. 從清單中選取一個 Minecraft 版本。
  2. 按一下安裝，下載該版本的遊戲用戶端、程式庫與資源。
  3. 安裝完成後，按一下遊玩即可啟動。啟動器會自動處理所有檔案驗證 與執行環境設定。
附註

原版版本使用與設定中相同的記憶體與 JVM 設定。 如果某個版本執行效果不佳，請試著調整 記憶體配置或 JVM 預設組合。

執行環境管理

不同的 Minecraft 版本可能需要不同的 Java 執行環境。啟動器會自動 為每個版本下載並管理正確的執行環境；例如，Minecraft 1.17 以上版本 需要 Java 17 或更新版本，而較舊的版本則使用 Java 8。

您不需要手動安裝 Java。如需執行環境處理方式的詳細資訊，請參閱 執行環境管理。

提示

在安裝較大型的模組包之前，可以先用原版版本測試您的系統 是否符合基本需求。
