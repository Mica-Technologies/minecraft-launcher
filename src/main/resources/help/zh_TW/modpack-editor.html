模組包編輯器

模組包編輯器是內建的工具，可用來建立與編輯模組包的 JSON 定義檔。 它提供具備驗證、搜尋整合與差異追蹤功能的結構化介面。

工具列

  • 新增：從範本建立空白的模組包定義。
  • 開啟檔案：從磁碟載入現有的 JSON 定義。
  • 開啟網址：從遠端網址取得並載入定義。
  • 儲存：將目前的定義寫入本機檔案。
  • 驗證：檢查定義是否有錯誤（缺少欄位、無效的網址、雜湊不符）。
  • 差異：將目前狀態與上次儲存的版本比較，查看有哪些變更。

中繼資料欄位

上方區段包含模組包的核心資訊：名稱、版本、說明、作者、 Minecraft 版本與 Forge 版本。Forge 版本選擇器可讓您瀏覽 所選 Minecraft 版本可用的 Forge 組建。

檔案分頁

檔案會依類別整理到不同的分頁中：

模組放在 mods/ 資料夾中的 Forge 模組 JAR。
設定模組的設定檔，放在 config/ 中。
資源資源包與其他資源。
光影適用於 OptiFine 或 Iris 的光影包。
初始檔案僅在首次安裝時複製的檔案（例如預設的 options.txt）。

每個檔案項目都包含下載網址與 SHA-1 雜湊。編輯器可以下載檔案並計算其總和檢查碼， 自動計算雜湊。

Modrinth 搜尋

使用整合的 Modrinth 搜尋，依名稱尋找模組。選取搜尋結果後，會自動 填入正確版本的下載網址與雜湊欄位。

提升版本

提升版本按鈕會遞增模組包的版本號碼，讓您輕鬆 發布啟動器能自動偵測到的更新。

網址檢查

編輯器可以確認所有檔案的下載網址是否都能連線，協助您在發布前 找出失效的連結。

提示

儲存前請先使用驗證，及早發現問題。驗證程式會檢查 必要欄位、網址是否有效，以及雜湊格式是否正確。
