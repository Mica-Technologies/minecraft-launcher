設定

設定畫面可讓您自訂記憶體配置、外觀、JVM 行為、網路 組態等。變更會自動儲存。

遊戲記憶體

最小記憶體配置給遊戲 JVM 的初始堆積大小。除非模組包另有指定，通常維持預設值（512 MB）即可。
最大記憶體遊戲可使用的記憶體上限。大多數模組包在 4 - 8 GB 時表現最佳。配置超過系統所能負擔的量，可能會導致不穩定。
提示

一個實用的經驗法則：最大記憶體不要超過系統總記憶體的一半。 例如，在 16 GB 的電腦上，6 - 8 GB 是合理的上限。

主題

Automatic（自動）跟隨作業系統的淺色／深色模式偏好設定。
Dark（深色）深色背景搭配淺色文字，看起來不刺眼。
Light（淺色）傳統的淺色背景搭配深色文字。
Blue + Gray（藍＋灰）冷色調的強調色主題。
Orange + Purple（橙＋紫）暖色調的強調色主題。

進階選項

偵錯模式在啟動器主控台中啟用詳細的記錄輸出，以便診斷問題。
視窗大小調整允許自由調整啟動器視窗大小，超出其預設尺寸。
Discord 整合將您目前的模組包顯示為 Discord Rich Presence 動態狀態。
加強記錄將詳細的記錄檔寫入磁碟，供遊玩結束後分析。
遊戲內主控台在 Minecraft 旁開啟遊戲主控台視窗，檢視即時輸出。

JVM 預設

預先設定好的 JVM 旗標組合，會附加到遊戲的啟動命令中。如需進一步了解每個預設組合的作用、 您可能想加入哪些自訂旗標，以及預設組合的選擇如何與記憶體配置互相影響， 請參閱JVM 預設。

Performance (Aikar's Flags)建議使用。Minecraft 社群廣泛使用的最佳化垃圾回收旗標。對大多數模組包而言，整體效能最佳。
Low Memory（低記憶體）適用於記憶體有限之系統的保守旗標。以犧牲部分傳輸量為代價，降低 GC 額外負擔。
Debug（偵錯）啟用包含 GC 記錄在內的 JVM 偵錯輸出。有助於診斷崩潰或效能問題。
None（無）不加入額外旗標，使用 JVM 的預設值。請僅在您清楚自己在做什麼，或模組包有此要求時使用。

網路／Proxy

如果您的網路需要 Proxy（常見於公司或學校網路），請在此進行設定。

HTTP Proxy標準的網頁 Proxy。請輸入網路管理員提供的主機與連接埠。
SOCKS Proxy較底層的 Proxy 協定。如果您的網路特別要求使用 SOCKS，請選擇此項。
附註

大多數使用者可以將 Proxy 設定保留空白。只有在受限的網路上下載或 驗證失敗時，才需要設定這些項目。

惡意程式掃描

啟動器內建掃描程式，會檢查下載的 JAR 檔案是否含有 fractureiser 的特徵碼；這是一種專門針對 Minecraft 的惡意程式，曾於 2023 年透過遭入侵的模組散播。 每次啟動遊戲前都會自動執行掃描。

重設與執行環境選項

重設啟動器將所有設定還原為預設值，並清除快取資料。此動作無法復原。
執行環境管理開啟執行環境管理畫面，檢視、驗證或移除已安裝的 Java 執行環境。
警告

重設啟動器會移除所有設定、快取的權杖與模組包狀態。 磁碟上的模組包檔案會保留下來，但您需要重新加入它們。

匯入／匯出設定

使用匯出設定將目前的組態儲存到檔案，並使用匯入設定 載入先前儲存的組態。這在不同電腦之間分享設定， 或在重設後還原已知正常的組態時很有用。
