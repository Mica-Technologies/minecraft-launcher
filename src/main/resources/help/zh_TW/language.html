語言與在地化

Mica Minecraft 啟動器能以 17 種語言顯示介面，並在首次啟動時 自動選擇合適的語言。您也可以隨時從設定中覆寫 偵測到的語言。

啟動器如何選擇語言

每次啟動時，啟動器都會依照下列順序決定要使用的 語言：

  1. 您儲存的覆寫設定：如果您已在 設定 → 外觀 → 語言中設定過，就一律以此為準。
  2. 作業系統的語言：透過標準的 JVM 地區設定 偵測。在 Windows 上是「地區／語言」 設定；在 macOS 上是「系統設定」→「語言與地區」； 在 Linux 上則是 LANG / LC_* 環境變數。
  3. 英文（美國）：如果平台回報的是非語言的地區設定 （例如 POSIX 或 C），或作業系統語言不在我們 提供翻譯的 17 種語言之中，就會以此作為備援。
變更語言會在重新啟動後生效

在設定中切換覆寫語言會立即更新偏好設定， 但已經顯示的畫面仍會維持先前的語言， 直到重新啟動啟動器為止。當您變更下拉式選單時，設定頁面本身也會 提醒您這一點。

手動覆寫語言

  1. 從導覽列開啟設定 （或按下 Ctrl+, / Cmd+,）。
  2. 切換到外觀分頁。
  3. 從語言下拉式選單中選擇語言。 第一個項目（「使用作業系統語言」）會恢復上述的 自動偵測，並在括號中顯示作業系統會解析成 哪一種語言。
  4. 按一下儲存。重新啟動啟動器後，所有畫面 都會套用新的語言。

支援的語言

啟動器提供全球使用人數最多的 17 種 語言翻譯，外加英文：

  • 阿拉伯文 (عربي)
  • 簡體中文 (简体中文)
  • 繁體中文 (繁體中文)
  • 荷蘭文 (Nederlands)
  • 英文（原始語言）
  • 法文 (Français)
  • 德文 (Deutsch)
  • 印地文 (हिंदी)
  • 義大利文 (Italiano)
  • 日文 (日本語)
  • 韓文 (한국어)
  • 波蘭文 (Polski)
  • 巴西葡萄牙文 (Português do Brasil)
  • 俄文 (Русский)
  • 西班牙文 (Español)
  • 瑞典文 (Svenska)
  • 土耳其文 (Türkçe)

每種語言都以其 BCP-47 標記識別（例如 fr-FR、 pt-BR、zh-CN）。完整清單位於啟動器原始碼的 SupportedLocales.ENTRIES 中；對應的 屬性檔則以 DisplayStrings_<tag>.properties 的形式 存放在 src/main/resources/lang/ 下。

翻譯品質與問題回報

英文以外的語言翻譯，是由一個指令碼產生的： 它會以英文原始語言包呼叫 Google 翻譯，然後 對參數預留位置進行後續處理，讓 {0} 之類的內容 在翻譯後保持完整。產出的品質不錯，但並不完美 — 尤其是 簡短的介面標籤（單字按鈕、單一名詞）有時會 失去在英文中的上下文。

如果您發現翻譯不佳，最好的做法是在 GitHub 上建立 issue，附上鍵名（例如 browse.filter.type.label）、 您的地區設定、目前的顯示內容，以及建議的修正。 手動修正的內容在下次重新產生時會保留下來，因為 指令碼預設只會填入缺少的鍵。

新增語言

如果您的語言不在上方清單中，而您想貢獻 翻譯，貢獻流程如下：

  1. 在 SupportedLocales.ENTRIES （Java）以及 tools/i18n/translate-locales.js（Node）中的 TARGET_LOCALES 新增一個項目。
  2. 執行 cd tools/i18n && npm run translate — 指令碼會從英文原始檔產生初始的 DisplayStrings_<tag>.properties。
  3. 檢查產生的檔案，手動修正任何讀起來 不自然的地方，然後提出 pull request。

tools/i18n/translate-locales.js 指令碼是增量式的： 重新執行時只會翻譯目標檔案中尚不存在的鍵， 因此每次啟動器更新時，手動修正的內容都會保留下來。
