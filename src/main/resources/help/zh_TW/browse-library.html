瀏覽

「瀏覽」畫面是安裝與管理的地方。您可以在這裡從公開清單檔安裝新的模組包、 安裝純原版 Minecraft 版本、安裝空白的 Forge／NeoForge／ Fabric 入門包、編輯您已有的模組包，以及解除安裝不再需要的項目。

卡片與篩選列

每個項目都會以主打卡片呈現，包含標誌、標記、名稱、標籤（載入器／Minecraft 版本）、 狀態列與動作按鈕。您可以使用頂端的篩選列縮小顯示範圍。

  • 搜尋：以自由文字比對卡片標題。輸入時就會即時更新 （並設有短暫的延遲，避免版面頻繁重排）。
  • 類型：全部、模組包，或其中一種版本目錄： 原版（正式版／快照／舊 Beta 版／舊 Alpha 版）以及 Forge／NeoForge／Fabric 版本。 載入器版本篩選條件刻意不包含在「全部」中；合併後的清單 會多達數千個項目，並不是「顯示全部」搜尋想要的結果。
  • 狀態：全部、已安裝或可安裝。「可安裝」會顯示您 尚未安裝的項目；「已安裝」則顯示已在磁碟上的項目。
  • 排序：預設、名稱（A–Z／Z–A）、發布日期、上次遊玩、最常遊玩、 最近更新。依賴遊玩／更新紀錄的排序方式（上次遊玩、最常遊玩、 最近更新）會將非模組包項目排到最下方，而不是混在其中 造成混淆。

已安裝的模組包

已在磁碟上的模組包卡片會顯示兩個按鈕：

  • 解除安裝：詢問是否要一併刪除安裝資料夾。「解除安裝 （保留檔案）」會保留您的世界、設定檔與模組，即使啟動器不再 記得這個模組包；如果您打算之後重新安裝同一個模組包，這個選項很實用。
  • 編輯：以模組包的本機清單檔開啟模組包編輯器。 變更會寫入磁碟，並在下次啟動時套用。
提示

在已安裝的模組包卡片上按一下滑鼠右鍵，即可開啟與主選單相同的快顯功能表： 開啟安裝資料夾、開啟模組資料夾、建立桌面捷徑、檢視遊玩統計，以及 解除安裝。

可安裝的模組包

公開清單檔中您尚未擁有的模組包，其卡片會顯示安裝按鈕。 按下後會下載清單檔並安裝模組包，並在下次重建時將卡片移到「已安裝」 群組。安裝進行期間您仍可繼續使用篩選條件， 進行中的卡片會固定在格狀檢視的最上方，直到安裝完成為止。

原版版本

Mojang 完整的正式版／快照／Beta／Alpha 目錄。每張卡片都會將該確切的 Minecraft 版本安裝為合成的空白模組包，讓您直接從主選單遊玩。舊的 Beta 版與 Alpha 版也都能執行，啟動器會自動為每個版本取得 合適的 Java 執行環境。

Forge／NeoForge／Fabric 版本

載入器版本篩選條件會列出各專案版本服務所公布的每一個版本： Forge promotions、NeoForge maven 中繼資料，以及 Fabric meta API。在其中一個項目上按一下「安裝」， 會在您的設定資料夾下寫入一份合成的「空白模組包」清單檔，並將其註冊到 啟動器中；因此結果的行為就跟其他已安裝的模組包一樣：

  • 會出現在主選單的主打卡片中；
  • 可以在模組包編輯器中編輯（您可以在上面加入模組，打造自己的模組包）；
  • 可以像其他模組包一樣解除安裝；
  • 與一般模組包共用相同的自動更新機制。
附註

當啟動器已在本機快取各專案的官方標誌時，卡片就會顯示該標誌。 第一次造訪載入器篩選條件時，會先顯示品牌色的預留位置，同時在背景 下載真正的標誌；快取完成後，之後的造訪就會立即顯示。

從網址新增

底部列的從網址新增按鈕接受指向託管 installable.json 清單檔的直接網址，並以與可安裝模組包卡片相同的方式進行安裝。 請將此功能用於在公開清單檔以外發布的模組包：貼上連結、按一下按鈕， 清單檔的中繼資料就會先下載並驗證，然後才開始安裝。

模組包編輯器

底部列的模組包編輯器按鈕會以空白清單檔開啟 模組包編輯器，讓您從頭打造 新的模組包：設定載入器（Forge／NeoForge／Fabric／原版）、Minecraft 版本、 模組清單等。您也可以透過現有模組包卡片上的編輯 按鈕開啟編輯器。

產生託管清單檔

底部列的產生託管清單檔按鈕會為目前在編輯器中的模組包建立 installable.json，可直接託管在任何網頁 伺服器或檔案分享服務上。任何取得該網址的人，都能透過「從網址新增」 安裝您的模組包。

分頁

較長的清單會分頁顯示。使用分頁列（位於卡片上方）中的上一頁／下一頁 按鈕在頁面之間移動，並使用每頁 下拉式選單設定每頁大小：24、48、72 或 96。預設的 48 足以在一頁內容納一般的 已安裝模組包；提高到 96 則可讓載入器版本篩選條件在單一頁面中 捲動瀏覽。
